# 素材を入れる

決まりの本体は `CLAUDE.md` の「素材」。入れ方の見本は `assets/kaykit/*/README.md` と `assets/audio/*/README.md`。

## 選ぶ

- **CC0 を優先する。** CC BY などは、表記が要るので次点に回す（表記はクレジットの表 `game/credits.csv` に 1 行足せば出る。使うかは人間が決める）。
- 取れるホストから選ぶ（いま取れるのは環境が許したホスト。github.com、opengameart.org、kenney.nl など）。
  **取れないホストのために、ネットワークの許可を求めない。** 取れる所に代わりが無ければ、そう報告する。
- 使う分だけ入れる。パックを丸ごと入れない。増えた大きさを PR の本文に書く。

## ライセンスを確かめる

- 配布元のページを開いてライセンスを読む。zip の中のライセンスの文も読み、そのまま `LICENSE.txt` として同梱する。
- **CC0 以外、またははっきりしないもの（ページと zip で食い違う、作者が書いていない、まとめた人と元の作者が違って元が分からない）は入れずに報告する。**
  入れるなら、その PR は自分でマージしない（`CLAUDE.md` の「Git」）。

## 書き残す

`assets/<出どころ>/README.md`（作者や配布元ごとに 1 つ）に書く。

- 作者、配布元の URL（GitHub ならコミットとパスまで）、ライセンス、取ってきた日・ライセンスを確かめた日。
- 改変（形式の変換、切り出し、音量、色替え。無ければ「なし」）。
- ファイルごとの元の名前と使い道（使う側のコードの名前）。
- まとめたパックは、元の作者ごとのライセンスを表にする。
- **クレジットの表（`game/credits.csv`）に 1 行足す**（素材名・作者・出どころ・ライセンス・ライセンスの文の置き場所）。CC0 も載せる。
  タイトルのクレジットの窓と、書き出しに添える `CREDITS.txt` は、この表から作る（`docs/credits.md`）。表記の要るライセンス（CC BY など）も、ここに 1 行足せば表記が出る。

## PR に書く

- **音は聴けない。** 選んだ根拠（配布元の説明、波形の測り）と、聴いて確かめてほしい点（雰囲気、音量の釣り合い、ループのつなぎ目）を本文の先頭に書く。
  次点と、すぐ差し替えられる場所も書く。
- **絵はコンテナの描画でしか見られない**（ソフトウェア描画で、実機の Vulkan と違う）。スクリーンショットを貼り、最終は exe（`pj-legion-windows`）で見てもらう、と書く。
- 画面なし（CI）では音を鳴らさない作りを保つ。
