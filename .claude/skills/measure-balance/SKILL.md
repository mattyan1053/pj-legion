# 釣り合いを実測で決める

道具は `tools/cpu_matches.gd`。引数と出す欄の正は `docs/cpu-ai.md` の「集計の道具」（ここには写さない）。

    godot --headless --path . -s res://tools/cpu_matches.gd -- --games=216 --seed=1 --pairings=mixed --squads=random

## 道具の選び方

- **釣り合いは、両軍の部隊を局ごとに変えて測るのが標準**（`--squads=random`）。CPU の決まった編成どうしの数字は、
  決まった 2 つの編成の相性で、人が組む部隊の釣り合いとは違う（手で作った盤では MILITARY が 83〜100% 勝ち、ばらすと 50% 前後）。
  決まった編成どうし（`--decks=auto`）は、CPU の手を直したときの前後を比べる用に残す。
- 軍の釣り合いは `--pairings=mixed`（同じ局数で標本が倍）。局数は 12 の倍数（マップと軍の組み合わせが一巡する）。
- 人が CPU と戦うときの手応えは `--squads=one`（片方は変えた部隊、もう片方は CPU の編成）。どの駒・編成が強いかは、
  `--squads` のときに出る「部隊の中身ごとの勝率」を見る。予算の差の効き目は `--budget=M,F`（測るためだけ）。
- 1 つの盤だけ見るなら `--stage=<鍵か 1〜3>`、話の敵の強さは `--episode=<パス>`。
- CPU を直したら、直す前の版と `--rival=main` で対戦させる。人の手での悪用は、その手を狙う版を `tools/rivals/` に
  （`extends CpuPlayer` で上書き）作って `--rival` に渡し、勝ち越すかを見る。
- 要因を切り分ける: 駒を抜く `--without=<種類>`、試しの盤 `--map=<ファイル>`、聖遺物を外す `--no-reward=1`・始めから持たせる `--relic=`。
- 長く回すときは、シードの範囲を分けて並べて回し、`--list=1` の `GAME` などの行をあとで合わせる。

## 標本の取り方

- **同じ局を何度も数えない**（#157）。手で作った盤や湧き直しの無い話は、種を変えても同じ局になる。
  `--list=1` で「別々の局」（軍・勝者・終わり方・ターン・必殺技・中ボスのどれかが違う）を数え、少なければ部隊を変える（`--squads=random`）。
- 1 回の標本でも数ポイントぶれる。シードの範囲を変えて 2 回取り、「a / b」で並べる。めやすの外に出たら、まずぶれを疑って標本を足す。
- 候補どうしは、同じシード・同じ局数で比べる。

## めやす

- 軍の勝率 45〜55%（部隊を変えて、盤ごとに 400 局ほど。`docs/cpu-ai.md` の「部隊を変えた集計」）。決まった編成どうしの数字は、めやすに当てない。
- 手で作ったマップを対戦モードに出す: 部隊を変えて 200 局以上、MILITARY と先手がどちらも 40〜60%（`docs/map-select.md` の「選べる盤」）。
- ストーリーの話: `docs/story.md` の「敵の強さ」。CPU どうしの勝率は人の手応えと違う。最後は人間が遊んで決める。

## 決め方

- **仮説は 1 つずつ切り分ける。** 候補ごとに「何を変えたか → 結果」の表を作り、動かす数のいちばん少ない案を選ぶ。
- **変えるのは、実測で良くなったものだけ。** 良くならなければ変えずに「測って、いまのまま」とし、理由を機能の文書に、試した表を PR の本文に残す。
- 人間が決めていて触らないもの: 予算と駒のコスト、対戦モードのターンの上限。外れていても変えずに報告する。

## 残し方

- 実測の数字は `docs/cpu-ai.md` の「いまの集計」**だけ**に置き、測った日・版・局数・シードを添える。ほかの文書は理由だけ書いて、そこを指す。
- 数値か CPU を変えたら「いまの集計」を取り直す。取り直していない欄があれば、そう書く。
- ルールや CPU を変えて、対戦モードのふるまいは変えないつもりなら、`--list=1 --seed=1`（対戦モード 12 局。関わる話があればその話も）の
  `GAME` 行が main と同じことを確かめ、本文に書く。
- 集計の道具に欄や引数を足したら、`docs/cpu-ai.md` の「集計の道具」と `tests/tools/test_cpu_match.gd` もそろえる。
- PR の本文: 変えた値（前 / 後）、局数とシード、どう選んだか、めやすに届いていない点、人の手では崩れそうな点。
