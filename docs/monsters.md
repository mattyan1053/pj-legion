# 魔物だけの決まり（種類の特性と、倒れると何か起きる魔物）

コード: `rules/monsters.gd`（種類の特性、倒れたときのこと、結び目の立ち直り。調整値）、`rules/unit_kind.gd`（能力値）、
`rules/evolution.gd`（特性の種類 `Evolution.Trait`）、`rules/status.gd`（絡み）、`rules/events/rally_event.gd`、`rules/events/knot_placed_event.gd`、`rules/events/burst_event.gd`。
テスト: `tests/rules/test_monster_falls.gd`、`tests/rules/test_monster_threads.gd`、`tests/rules/test_monster_shells.gd`、`tests/rules/test_monsters.gd`。

魔物（`docs/unit-roster.md` の「魔物」）のうち、骸骨旗手・大蝙蝠・ほつれ・糸針・糸蜘蛛・糸喰い・殻蟹・糸茸は、**種類そのものが特性を持つ**（`Monsters.kind_traits`）。
進化先や持ち物の特性と同じ扱いで（`Unit.has_trait`）、情報の札に特性として出る。魔物はストーリーの話の敵だけなので、対戦モードには出ない。

| 魔物 | 特性 |
| --- | --- |
| 骸骨旗手 | 倒れると、周りの味方が奮起する（`RALLY_ON_FALL`） |
| 大蝙蝠 | 敵の支配領域で止まらない（`IGNORES_ZOC`）。森を平地と同じ移動力で飛ぶ（`FOREST_WALK`） |
| ほつれ | 倒れると、結び目が残る（`KNOT_ON_FALL`）。前衛なので支配領域を作る |
| 糸針 | 動けない（`ROOTED`） |
| 糸蜘蛛 | 当てた相手に絡みを付ける（`BINDS_ON_HIT`） |
| 糸喰い | 倒れると弾ける（`BURSTS_ON_FALL`）。前衛なので支配領域を作る |
| 殻蟹 | 離れた所からの攻撃では狙えない（`SHELLED`）。前衛なので支配領域を作る |
| 糸茸 | 周り 8 マスにいる敵の攻撃を弱める（`SPORES`） |

## いまの仕様

### 動けない（糸針）

- 移動力は 0。突撃などで移動力が上がっても 0 のまま（`Unit.move_range`、`Movement.budget`）。ポータルの上にいても転移しない（`WarpAction`。移動の探索も、脅威範囲も、ポータルを越えない）。
- 攻撃とスキル（持たない）はできる。ほかの駒のスキルで動かされる（入れ替わる）ことはある。

### 当てると絡める（糸蜘蛛）

- 糸蜘蛛の攻撃が当たると（煙幕に阻まれず、相手が倒れなければ。バリアに防がれても）、相手に絡み（`Status.Type.SNARE`。`docs/unit-statuses.md`）が付く。
  相手の次の番の終わりまで、動けない（移動力 0。突撃でも増えない。ポータルでも動かない）。攻撃とスキルと待機はできる。ほかの駒のスキルで動かされることはある。
- もう絡みが付いていれば、付け直す（重ねない）。中立の駒にも付く。
- だから、**前に出すぎた兵は、群れの中で足を止められる。** 糸蜘蛛を先に倒すか、絡まれても困らない駒（前衛、後衛）を前に出す。将が絡まれると、逃げられない。

### 倒れると弾ける（糸喰い）

- 糸喰いが倒れると、腹に溜めた糸が弾けて、周り 8 マス（盤の中）の駒すべて（敵・味方・中立。倒した駒も）に 10（`Monsters.BURST_DAMAGE`）のダメージ。
  起爆樽の爆発と同じく、固定の量で、攻撃力にも地形にもよらず、バリアには防がれる。全員に同時に当たる。
- 何で倒れても同じ（攻撃、スキル、樽の爆発、ほかの糸喰いが弾けたの）。弾けて倒れた駒が糸喰いなら、続けて弾ける。
- 弾けて倒れた駒は、糸喰いを倒した駒が倒したことにする（戦いの記録。経験値は入らない）。糸喰いを倒した駒が弾けて倒れることもある（そのときは、経験値も入らない）。
- だから、**隣から叩いて倒すと巻き込まれる。** 離れて撃って倒すか、相手の群れが寄り集まった所で倒す。

### 離れて狙えない（殻蟹）

- 距離 2（`Combat.RANGED_DISTANCE`。斜め隣も 2）以上からの攻撃では、殻蟹を狙えない（`Combat.can_attack` が `Monsters.shell_turns_away` を読む）。上下左右の隣からなら、ふつうに狙えて、ふつうに当たる。
  煙幕と違い、狙えないので、攻撃の手として選べない（行動を使い切らない）。
- 狙わずに範囲で当たるもの（起爆樽の爆発、糸喰いの弾けるの、スキルのダメージ）は、ふつうに受ける。
- 殻蟹の攻撃と、ほかの駒への攻撃には関わらない。
- だから、**後衛は殻蟹に手が出せない。** 前衛か奇襲が隣へ寄って叩くか、樽や弾けるのに巻き込む。前衛なので支配領域を作り、後衛の前の道を塞ぐ。

### 胞子（糸茸）

- 糸茸の周り 8 マス（斜めも）にいる、糸茸の敵の駒の攻撃は、ダメージが 4（`Monsters.SPORE_PENALTY`）減る（`Combat.hit` が `Monsters.spore_penalty` を読む）。
  森の軽減と隊列（部隊の特徴）のあとに引き、0 より下にはならない。何本の糸茸の隣にいても 1 回だけ。糸茸そのものへの攻撃も、隣からなら弱まる。
- 駒の攻撃だけ（盾・樽への攻撃、スキル、回復は変わらない）。味方の糸茸では弱まらない。中立の駒の攻撃も弱まる（中立はどちらの敵でもある）。
- だから、**糸茸の隣では殴り合いが鈍る。** 糸茸は脆いので、離れて撃って先に倒す。殻蟹の隣に糸茸が付くと、寄って叩くのも重くなる。

### 骸骨旗手が倒れると: 奮起

- 倒れた旗手から 2 マス（`Monsters.RALLY_RADIUS`。マンハッタン距離）以内の味方（旗手と同じ陣営）に、奮起（`Status.Type.RESOLVE`。攻撃 +4（`Monsters.RESOLVE_POWER`））が付く。
  次の自分のフェーズの終わりまで（自分のフェーズの途中で付いたら、そのフェーズの終わりまで）。
- 何で倒れても同じ（攻撃、スキル、樽の爆発）。周りに味方がいなければ何も起きない。
- だから、**群れから離れた旗手を先に倒すか、群れを減らしてから倒す。** 群れの中で倒すと、群れの次の一押しが重くなる。

### ほつれが倒れると: 結び目

- 倒れたマスに、結び目（`FieldEffect.Type.KNOT`）が残る。持ち主は倒れたほつれの陣営。そのマスに、もう結び目があれば残さない。
- 結び目は盤の上の効果の 1 つ（`docs/field-effects.md`）。1 マス。入れる。射線を遮らない。
- 持ち主のフェーズの始めに（聖域の回復のあと、煙幕と聖域の期間が進む前。`FieldEffects.start_phase` が `Monsters.start_phase` を呼ぶ）:
  1. **ほかの陣営の駒が乗っていれば、ほどけて消える。**
  2. そうでなければ、残りのターン数が 1 減る。2（`Monsters.KNOT_TURNS`）から始まる。
  3. 0 になったら、消えて、そこに**ほつれが立ち直る**（新しい駒。HP は満ちて、レベル 1。そのフェーズから動ける）。
     持ち主の駒が乗っていれば、空くまで残り 1 のまま待つ。
- だから、ほつれを倒したら、**相手の番が 2 回来る前に、だれかを結び目の上に立たせる。** 隣から叩いて倒した兵は動けないので、
  離れて撃って倒し、近くの兵で踏む、のように倒す場所と順を選ぶ。

### イベント

- 旗手: 倒れた `UnitDefeatedEvent` のあとに、`RallyEvent`（倒れた駒、そのマス、奮起した駒）と、奮起した駒ごとの `StatusAppliedEvent`（上の行から、左の列から）。
- ほつれ: 倒れた `UnitDefeatedEvent` のあとに、`KnotPlacedEvent`（`FieldEffectPlacedEvent` の子。残りのターン数、立ち直る種類）。
- 糸蜘蛛: 攻撃の `AttackDamagedEvent` のあとに、相手の `StatusAppliedEvent`（絡み）。
- 糸喰い: 倒れた `UnitDefeatedEvent` のあとに、`BurstEvent`（倒れた駒、倒した駒、そのマス、届いたマス、巻き込んだ駒）、
  巻き込んだ駒ごとの `ExplosionDamagedEvent`（起爆樽と同じ。上の行から、左の列から）、倒れた駒の `UnitDefeatedEvent`。
- 結び目: 持ち主のフェーズの始めに、`FieldEffectRemovedEvent`（`UNTIED`）、`FieldEffectTickedEvent`、
  または `FieldEffectRemovedEvent`（`REFORMED`）と続けて `UnitSpawnedEvent`（立ち直ったほつれ）。

### 予測・脅威範囲・ログ・再生

- **予測**（`docs/battle-forecast.md`）: 複製の上で同じ処理を走らせるので、倒す手の予測に、奮起する駒（`Forecast.UnitOutcome.rallied` と、付く状態）と、
  残る結び目（`Forecast.placed`）、弾けて巻き込まれる駒（起爆樽の爆発と同じダメージの見せ方）、絡みの付く相手が入る。
  胞子で弱まる攻撃は、相手の行の注に「胞子で弱まる」（`Forecast.UnitOutcome.spores`）。殻蟹は、離れた所からは攻撃の相手に選べない（予測も出ない）。
- **脅威範囲**（`docs/threat-range.md`）: 敵の全員の脅威範囲（`Threat.against`）は、次の番の始めに結び目から立ち直るほつれが、
  そこから動いて届くマスも含む（複製の上で番を進めて、新しく現れた駒の範囲を足す）。奮起の付いた駒は、上がった攻撃力で数える。
- **脅威範囲**: 絡みの付いた駒は動けないので、その場から届くマスだけ。
- **ログ**（`docs/battle-log.md`）: 「〜が倒れ、周りの N 体が奮起した」の行に、奮起をまとめる。結び目は、残った・ほどけた・立ち直った、を 1 行ずつ。
  「〜が倒れ、腹の糸が弾けた」の行に、巻き込んだ駒のダメージをまとめる。絡みは、状態が付いた行。胞子で弱まった攻撃は、ダメージの行の注に「胞子で弱まる」。
- **再生**: 旗の倒れたマスに「旗が倒れた」、結び目の置かれたマスに糸の輪（盤の上の効果として描く）、ほどけた・立ち直ったマスに一言。
  糸喰いの弾けたマスに、届いたマスを塗って糸の色の光と「弾けた」。

## CPU

- 倒す手の価値（`docs/cpu-ai.md` の「手の価値」）から、相手の旗手を倒して奮起する相手の駒 1 体につき 15（`CpuPlayer.RALLY_PENALTY`）、
  相手のほつれを倒して結び目が残るなら 40（`CpuPlayer.KNOT_PENALTY`）を引く。
- 相手の結び目の上に立って行動を終える価値に 45（`CpuPlayer.KNOT_STEP_VALUE`）を足す（踏みに行く）。
- 相手の駒に絡みを付ける価値に 12（`CpuPlayer.SNARE_VALUE`）を足す（糸蜘蛛は、まだ絡まっていない相手を選ぶ）。
- 糸喰いが弾けるダメージは、ほかのダメージと同じに、行動の結果の価値に入る（自分の駒が巻き込まれれば引く。隣から叩いて倒す手は、巻き込まれる分だけ下がる）。
- 殻蟹は、攻撃の相手の候補に入らない（離れた所からは狙えないので、`Combat.targets` に出ない）。
  CPU の殻蟹の危険の見積もり（`docs/cpu-ai.md` の「危険の見積もり」）は、自分の煙幕の中のマスと同じく、近くからの攻撃だけを数える。
- 胞子で弱まるダメージは、ほかのダメージと同じに、行動の結果の価値に入る（糸茸の隣から叩く手は、弱まる分だけ下がる）。
- 魔物の側を動かす CPU に、魔物のための判断は無い（役割と射程で動く。動けない糸針は、その場から撃つ）。

## 決めたこと

- 「倒すと周りに何か起きる」を、縫い目の世界に寄せて 2 つにした。亡者の群れの旗（あの日の旗が倒れると、周りの亡者が奮い立つ）と、
  仮縫いのほころびから湧く糸の塊（倒しても糸が残って結び直る）。前者は「どこで倒すか」、後者は「倒したあとどうするか」の判断になる。
- 新しい状態は作らず、奮起を使い回した（画面の見せ方、予測、脅威範囲の攻撃力が、そのまま効く）。
- 結び目は、盤の上の効果の層に置いた（マスの説明、ログ、描き方の受け皿がある）。立ち直ったほつれをすぐ動かすのは、
  放っておいた損をはっきりさせるため（行動済みで起きる骨起こしの骸骨兵と違う）。
- 立ち直るたびに倒して経験値を稼げるが、相手の番を 2 回待つので、話のターンの上限の中では稼ぎにならない。
- 骸骨でない魔物を 2 つ足した（人間の感想「ガイコツは受けが悪い」）。どちらも縫い目の糸に寄せた: 糸を張る蜘蛛（足を止める）と、糸を喰う小さな竜（割ると熱を出す結晶を腹に溜める）。
  前者は「だれを前に出すか」、後者は「どこから倒すか」の判断になる。
- 絡みは新しい状態にした（動けない特性は種類のものなので、期限のある状態として別に置き、駒の情報の札と予測にそのまま出す）。
  弾けるのは、起爆樽の爆発の決まり（周り 8 マス、固定の量、同時に当たる）を使い回した（予測・ログ・再生の受け皿がある）。
- さらに骸骨でない魔物を 2 つ足した（同じく）。どちらも、倒れたときでも当てたときでもなく、**いるあいだ**の決まりにした（いまの魔物と重ならないように）:
  離れた所から狙えない殻蟹（「だれで寄るか」）と、周りの敵の攻撃を弱める糸茸（「どこで殴り合うか」）。糸喰いは「離れて撃て」、殻蟹は「寄って叩け」で、
  同じ盤に置くと、寄り方の答えが魔物ごとに変わる。殻蟹は硬くせず（HP は糸喰いより低い）、狙える距離だけで手間を作る。
- 殻蟹は「離れた攻撃を 0 にする」（煙幕と同じ）ではなく「狙えない」にした。0 にする形では、狙ってから無駄だと分かる手が増え、CPU も無駄撃ちを避ける判断が要る。
- 胞子は状態にせず、立ち位置で決まる量にした（離れれば消え、予測の注とログの注で見える。状態の札が増えない）。何本いても重ねないのは、群れの中で攻撃が 0 になって手が無くなるのを避けるため。
