# システムメニューと設定

コード: `game/app.gd`（開く・並べる項目）、`game/system_menu.gd`（メニュー）、`game/settings_panel.gd`（設定の画面）、`game/settings.gd`（設定の項目と値）、
`game/save_store.gd`（取っておく仕組み）、`game/overlay_stack.gd`（重なる画面の積み上げ）。対戦の場面のつなぎは `game/battle_screen.gd` の「システムメニューと設定」。
テスト: `tests/game/test_settings.gd`、`tests/game/test_overlay_stack.gd`、`tests/game/test_orbit_camera.gd`、自動の対戦（`game/autoplay.gd` の `_queue_system_menu_scene`）。

## 開き方

- **画面の右上の「メニュー」のボタン**か、**Esc**。どの場面（`docs/scene-flow.md`）でも、対戦の途中でも、相手（CPU）の番や再生の途中でも、いつでも開ける（場面の切り替えの暗転の間だけは開かない）。
- タイトルとストーリーの会話の場面の Esc は、メニューを開く（会話の右クリックは、1 つ前の文へ戻る）。ステージ選択・対戦設定・部隊編成・話の一覧・出撃準備の場面の Esc は、1 つ前へ戻る（戻す。対戦設定ならステージ選択へ、話の一覧ならタイトルへ、出撃準備なら話の一覧へ）。
- **Esc は、戻すものがある間は「戻す」**（右クリックと同じ: 必殺技の確かめ → 駒を見ている → 対象を選ぶ途中 → 移動 → 選択・マスの情報・ターン終了の確かめ の順）。
  **戻すものが何も無いときに、メニューを開く。** 右クリックは「戻す」だけで、メニューは開かない（人間が気に入っている操作。`docs/battle-view.md`）。
- 対戦の途中で開いた対戦設定画面の上でも開ける（Esc は、まず設定画面を閉じる）。
- 開いている間の右クリックと Esc は「戻す」: 確かめ → 設定の画面 → メニュー の順に閉じる。

### 重なる画面

システムメニュー、ログ（`docs/battle-log.md`）、対戦設定画面は、場面の上に重なる画面。開いているものは `AppContext.overlays`（`game/overlay_stack.gd`）に、開いた順に積む。

- 開いたら積み、閉じたら降ろす（場面を抜けて消えるときも降ろす）。
- **Esc と右クリックは、いちばん上の重なる画面だけが受ける。** 後ろ（盤面、場面）へは通さない。
- 後ろの場面は、何かが開いているか（`is_open`）と、時間を止める重なり（システムメニューとログ）が開いているか（`pauses`）だけを見る。
  何かが開いている間は、盤面の操作を受け付けない。時間を止める重なりが開いている間は、時間・マウスの下のマスの追跡・視点の操作も止める。
- 重なる画面を足すときは、開く・閉じるで積み上げを通し、`_input` で `is_top` を見るだけでよい。

## 項目

| 項目 | 押すと |
| --- | --- |
| 対戦へ戻る | メニューを閉じる（文字は場面ごと: ステージ選択では「ステージ選択へ戻る」、対戦設定では「対戦設定へ戻る」、部隊編成では「部隊編成へ戻る」、話の一覧では「話の一覧へ戻る」、出撃準備では「出撃準備へ戻る」、タイトルと会話では「戻る」） |
| オプション | オプションの画面（下）へ |
| 対戦設定へ | 対戦モードの対戦の場面だけ（ストーリーの話の対戦では出さない。`docs/battle-source.md` の `can_open_setup`）。対戦設定画面を盤面の上に開く（`docs/battle-view.md` の「対戦設定」。開くだけでは対戦は変わらない）。CPU の番や再生の途中に選んだら、それが終わってから開く。設定画面の上で開いたときは出さない |
| タイトルへ戻る | タイトルの場面へ（タイトルでは出さない）。**抜けると失われるもの（決着していない対戦、取っておいていない部隊の変更）があれば確かめる**（下） |
| ゲーム終了 | アプリを終える。**抜けると失われるものがあれば、何が失われるかを書いて確かめる**（対戦なら「対戦の状態は失われます。」。「キャンセル」でメニューへ戻る） |

並べるのはアプリ（`app.gd` の `menu_items`）。共通の項目（戻る、オプション、タイトルへ戻る、ゲーム終了）の間に、いまの場面が足す項目（`menu_items`）を入れる。
確かめるかは、いまの場面の `in_progress` で決める。失われるものの文は、場面の `losing_note`（無ければ対戦の文。部隊編成は「組んでいる部隊の、取っておいていない変更は失われる」。`docs/scene-flow.md` の「場面の決まり」）。

## 開いている間

- 対戦の場面では、**時間を止める。** 再生も、CPU の番も、カメラの動きも、その場で止まり、閉じると続きから進む（`Engine.time_scale` を 0 にする）。
  進めたままにすると、メニューの後ろで盤面が変わっていき、閉じたときに何が起きたか分からないため。
- 画面の全体を覆い、クリック・ドラッグ・ホイールを後ろの盤面へ通さない。キー（Space、Enter、視点の Q・E・R・WASD など）も盤面には効かない。
- 後ろの盤面は暗くして、そのまま見せる。

## 設定

設定の画面は、メニューの「オプション」か、タイトルの「オプション」から開く（タイトルから開いたときは、閉じるとメニューを通らずにタイトルへ戻る）。値は**その場で効く**。行ごとに「初期値に戻す」、下に「すべて初期値に戻す」と「戻る」。

| 項目 | 区分 | 範囲 | 既定 | 効くところ |
| --- | --- | --- | --- | --- |
| マウスの感度 | 操作 | 25〜300%（5% 刻み） | 100% | ドラッグで視点を回す・傾ける速さ。100% が `OrbitCamera.DEFAULT_DRAG_SENSITIVITY`（1 px あたりのラジアン）で、それに掛ける。横と縦で同じ |
| 縦のドラッグを逆にする | 操作 | オフ / オン | オフ | オフは「下へ動かすと真上から見下ろす」（盤を手前へ引き倒す向き。`docs/battle-view.md`）。オンはその逆 |
| CPU の番の速さ | 再生 | ふつう（×1）/ 速い（×2）/ とても速い（×3） | ふつう | CPU の駒の行動（カメラを寄せる、歩く、攻撃する、間）を、その倍の速さで見せる。CPU が番を終えたあとの中立の番は、ふだんの速さのまま（速すぎると目で追えない） |
| 全体の音量 | 音 | 0〜100%（5% 刻み） | 80% | BGM と効果音の両方（`docs/sound.md` の「音量」） |
| BGM の音量 | 音 | 0〜100%（5% 刻み） | 70% | タイトル・会話・対戦・決着の曲 |
| 効果音の音量 | 音 | 0〜100%（5% 刻み） | 80% | 操作の音。スライダーを離すと、ボタンの音を 1 つ鳴らして大きさを聞かせる |
| 音を消す | 音 | オフ / オン | オフ | すべての音を止める（音量の値はそのまま） |
| 全画面 | 画面 | オフ / オン | オフ | オンで全画面、オフで窓（`docs/screen-size.md` の「窓と全画面」）。**Alt+Enter** でも切り替えられ、そのときも取っておく |
| ミニマップ | 画面 | オフ / オン | オン | 対戦の画面の右上のミニマップを出すか（`docs/minimap.md`） |

- 項目は `settings.gd` の `ITEMS` に並べ、画面はそれだけを見て行を作る。**項目を足すのは、`ITEMS` に 1 つ足し、効かせる側（操作と再生は `battle_screen.gd` の `_apply_settings`、音は `sound.gd` の `apply_settings`）に 1 行足すだけ。**
  種類は、スライダー（整数の範囲と刻み）、オン・オフ、選択肢。オン・オフも、押されているほうが色で分かるボタンを 2 つ並べる。
- 項目の並ぶ枠は、720 の高さに収まらなければ縦に送れる（ホイールか右の棒。`settings_panel.gd` の `ROWS_MAX_HEIGHT`）。
  見出しの「オプション」と、下の「すべて初期値に戻す」「戻る」は送らずに、いつも見える。いまは 9 つの項目で、少し送る。

## 取っておく

- 設定は `user://settings.json` に書き、次に起動したときに読む（Windows では `%APPDATA%\Godot\app_userdata\pj-legion\`）。
  書くのは、設定の画面を閉じたとき（戻る・右クリック・Esc・メニューごと閉じる、のどれでも）と、設定の画面を開いたままウィンドウを閉じたとき。
- 書き方は `save_store.gd`: まとまりごとに 1 つの JSON（`{"name", "version", "data"}`）。一時のファイルに書いてから置き換えるので、書きかけで止まっても前のファイルは壊れない。
  取っておいた部隊（`deck_library.gd`。`docs/deck-screen.md`）はまとまりの名前 `decks`、ストーリーの進み具合（`story.gd`。`docs/story.md`）は `story` で、同じ仕組みに乗る。
- **読めないときも起動できる。** ファイルが無い・JSON でない・形が違うときは、無いものとして既定の値で始める。
  読めたファイルの中の、知らない項目は捨て、型の違う値は既定の値にし、範囲の外の値は範囲に収める。
  項目が足りない古いファイルや、版の新しいファイルでも、知っている項目は読む（版ごとの読み替えは `settings.gd` の `_migrate` に足す）。
- 自動の対戦とスクリーンショットの道具は、遊ぶ人の設定を読まず、書かない（いつも既定の値で同じに動く）。
