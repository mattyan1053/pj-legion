# 対戦のログ

コード: `game/battle_log.gd`（ログ。ノードに依存しない）、`game/log_panel.gd`（ログの画面）。
テスト: `tests/game/test_battle_log.gd`。対戦の画面とのつなぎは `game/battle_screen.gd`。

対戦の中で起きたことを、あとから読める行の列にする。相手（CPU）の番や中立のフェーズで起きたことを見逃したときに、さかのぼって確かめる。
ルールの挙動には関わらない（読むだけ）。保存とリプレイは無い。

## 読み方

- `BattleLog.new(対戦, 陣営の名前)` で読み始める。盤上の駒（種類・陣営・進化先・マス）と盤面を控え、いまのフェーズの見出しを置く。
  あとは起きたこと（`BattleEvent`）を `feed()` で 1 つずつ食わせる。対戦の状態は読まない（`BattleStats` と同じ。`docs/battle-stats.md`）。
  駒の名前といまいるマスは、控えた駒をイベントで追いかけて知る（倒れた駒も、名前は残る）。
- 画面は、**再生した順**に食わせる（`_play`）。ルールが返した順と違うのは、中立のフェーズの、動くだけの駒をまとめて同時に流すところだけで、駒ごとの順は保たれる。
  なので、ログを開いても、まだ画面に出ていないことは書かれていない。
- **どのイベントをどう読むかは `BattleLog.readers()` の表に載せる。** `rules/events/` に種類が増えて表に無いと、テストが落ちる
  （画面の「全種類のイベントに再生するメソッドがある」検査と同じ考え方）。行にしない種類も、`_skip` として理由とともに載せる。

## 行

1 行（`Entry`）は、文、陣営（色を付ける。行の主の陣営）、続きの行（`details`）、出来事のあったマス、関わった駒を持つ。

- **駒は種類の名前で呼ぶ**（進化していれば進化先の名前）。プレイヤーの駒には陣営を前に付ける（「青のパラディン」「赤のマークスマン」。ストーリーでは「味方のパラディン」「敵のマークスマン」。`docs/wording.md` の「陣営の呼び方」）。中立の駒には付けない。
- **フェーズの区切り**: フェーズの始めに見出し（「ターン 3　CPU（赤）の番」。ストーリーでは「ターン 3　敵の番」）。何も起きなかった中立のフェーズの見出しは残さない。
- **始めのゲージ**: 対戦の始め（ターン 1 の先手の番の前）に必殺技のゲージがたまっている陣営は、最初の見出しのすぐ下に「青の必殺技のゲージは 60% から」と書く（ゲージの手前から始める話。対戦モードの先手は、いまは 0 から）。
- **移動**: 「青のパラディン が (1, 2) → (5, 6) へ移動」。巡航・ポータルを通ったことは括弧に書く。ポータルへの移動・転移・続きの移動は 1 行にまとめる。
  移動のあとに何もせずに行動を終えたら「…へ移動して待機」。動かずに待機したら「青の将 は待機」。**取り消した移動は、行を消す**（無かったことにする）。
- **攻撃**: 「青のパラディン が 赤のスナイパー を攻撃: 12 ダメージ、残り HP 8（森で軽減）」。倒したら「…、倒した」（倒れた行を別に足さない）。
  クリティカル・森の軽減は括弧に、バリアに防がれたら「バリアで防がれた」、煙幕に阻まれたら「煙幕に阻まれた」。盾を撃ったら、残りの耐久か「壊した」。
- **スキル・必殺技・樽の爆発**は 1 行にまとめ、続く効果を続きの行に書く: 当たった駒ごとのダメージ（倒れたら「倒れた」）、置いた盾・煙幕・聖域、
  付いた状態（状態ごとに 1 行。「突撃（2 ターン）: 青の将、青のパラディン…」。使った駒が自分に付けたなら「バリアが付いた（2 ターン）」）、
  入れ替わり・移った先、もう一度行動できること。
- **回復**: 回復役の回復（「A が B を 15 回復（HP 30）」）と、フェーズの始めの泉・再生・聖域の回復。
- **盤の効果**: 置いたとき（スキルの続き）と、消えた・壊れたとき（「青の煙幕が消えた」）。
- **倒れると何か起きる魔物**（`docs/monsters.md`）: 骸骨旗手が倒れて奮起した（「赤の骸骨旗手が倒れ、周りの 2 体が奮起した」。奮起は続きの行にまとめる）。
  ほつれの結び目が残った・踏まれてほどけた・立ち直った（立ち直ったほつれは、湧いた行を別に足さない）。
- **中立の駒**: 湧いた（続けて湧いた同じ種類は 1 行にまとめる）、動いた、攻撃した。中ボスが現れた・倒れた（「青 が左の中ボスを倒した」）、聖遺物を手に入れた。
- **成長**: レベルが上がった（伸びた能力値）、進化した（「赤のスナイパー が マークスマン に進化した」）。
- **陣営のこと**: 本陣の占拠の数（「青 が赤の本陣を占拠: 2 / 3」「…占拠が途切れた」）、必殺技が使えるようになった、決着（勝ち・引き分けと理由）。

### 行にしないもの

細かすぎるか、ほかの行で分かるもの。

| イベント | 省く理由 |
| --- | --- |
| 経験値（`ExperienceGainedEvent`） | 毎回の量は細かすぎる。レベルアップの行で足りる |
| 進化先を選べる（`EvolutionOfferedEvent`） | 選んだ進化先の行で足りる |
| 効果の残りのターン（`FieldEffectTickedEvent`） | 減るだけ。消えたときに書く |
| スキルが使えるようになった（`SkillReadyEvent`） | 毎フェーズのこと。駒の情報で分かる |
| 状態が外れた（`StatusRemovedEvent`） | 防いだことはダメージの行で、照準が外れたことは移動で分かる |
| 行動済み（`UnitActedEvent`） | 行にはしない。何もせずに終えたときだけ「待機」と書く |

イベントでない行は 1 つだけ: ストーリーの対戦の途中の会話の台詞（`BattleLog.say`。「話し手「文」」、話し手の陣営の色。`docs/story.md` の「対戦の途中の会話」）。
画面が台詞を出すときに書く。

### 戦績の集計とそろえたこと

- 樽の爆発のダメージは、樽を攻撃した駒の行の続きに書く（戦績も、樽を攻撃した駒のものにする）。
- 中ボスを倒した陣営は、イベントの「倒した陣営」（止めを刺した駒の持ち主）。戦績と聖遺物の決め方と同じ。

## 画面（`log_panel.gd`）

- **ふだんは場所を取らない。** 上の帯の「ログ」のボタンで開く（最新の数行を盤の上に出すことはしない。画面をごちゃつかせない）。
- 開くと、画面の右にパネルが出て、いちばん下（最新）を見せる。ホイールかスクロールの棒でさかのぼる。
  フェーズの見出しは陣営の色で、ターンの変わり目には線を引く。行の左の帯と文の色が、行の主の陣営の色。
- **行を押すと**、その出来事のあったマス（金）へカメラが移り、関わった駒のいまいるマス（白）を塗る。倒れた駒は塗らない。
  閉じると塗りを消し、いまの番の表示に戻る。
- **いつでも開ける**（CPU の番・中立のフェーズ・再生の途中でも）。**開いている間は時間を止める**（システムメニューと同じ。`docs/system-menu.md`）。
  閉じると続きから進む。
- 開いている間は、画面の全体を覆って、盤の操作（クリック・ドラッグ・ホイール・キー）を後ろへ通さない。
  **右クリック・Esc・「閉じる」・パネルの外のクリックで閉じる。** システムメニューを開くと、ログは閉じる。対戦設定のパネルの上では開かない。
- 開くたびに、前に開いてから増えた・書き換わった行だけを作り直す（長い対戦でも、開くたびに全部を作り直さない）。
- 行の文は `text_wrap.gd` で折り返す。

## 決めていないこと

- 同じ種類の駒が 2 体いると、名前では見分けられない（「青のスナイパー」が 2 つ）。行を押すと、どの駒かが盤の上で分かる。
