# 戦闘予測

コード: `rules/forecast.gd`（`Forecast`）。画面の文は `game/forecast_text.gd`。
テスト: `tests/rules/test_forecast.gd`、`tests/game/test_forecast_text.gd`。

ある行動をいま行ったら何が起きるかを、状態を変えずに返す問い合わせ。`Forecast.of(対戦, 行動)`。
攻撃、樽への攻撃、盾への攻撃、回復、スキル、必殺技のどれにも同じものを使う（`Battle.apply` に渡せる行動なら何でもよい）。

## いまの仕様

- **実際の解決と同じ処理を使う。** 複製（`Battle.clone()`）に `apply` し、出たイベントとあとの状態を読む。
  だから予測は、直後に同じ行動をしたときの結果（HP、倒れるか、経験値、ゲージ、決着）と一致する。テストで確かめている。
- **状態を変えない。** 元の対戦の駒、盤、ゲージ、乱数（`Battle.rng`）は進まない。確率で決まるルール（中立の駒の同点）も、複製の乱数で引く。
- 受け付けられない行動なら `accepted` が偽で、ほかは空（ゲージは、前もあとも、いまの値）。
- `Skills.preview` と `Ults.preview` は、これのイベントの列を返す。

## 読めるもの

- `units`: 何かが起きる駒ごとの `UnitOutcome`（イベントに出てきた順）。`outcome(駒の番号)` でも引ける。
  - 前とあとの HP、あとの最大 HP、受けるダメージの合計（防がれたぶんは 0）と当たる回数（防がれたもの・煙幕に阻まれたものも数える）、倒れるか。
  - ダメージの内訳: 確定クリティカルか（`critical`）、森で減るか（`forest`）、駒の状態に防がれるか（`blocked_by`。バリア）、
    煙幕に阻まれるか（`smoked`）、樽の爆発に巻き込まれるか（`exploded`）。攻撃した駒自身が爆発に入るなら、その駒も載る。
  - 回復で増える HP（最大 HP で切った量）。
  - 入る経験値、上がるレベルの数、進化先を選ぶことになるか。
  - 付く状態（残りのターン数つき）と外れる状態、スキルで移る先、もう一度行動できるようになるか。
  - 倒れた骸骨旗手の周りにいて奮起するか（`rallied`。`docs/monsters.md`）。倒れた糸喰いが弾けて巻き込まれるか（樽の爆発と同じ `exploded`）。
- `barricades`: 攻撃する盾の、前とあとの耐久力と、壊れるか。
- `placed`: 盤に置かれる効果（盾、煙幕、聖域、倒れたほつれの残す結び目）。
- `gauge_before` / `gauge_after`: プレイヤーごとの必殺技のゲージ。
- `relics`: 受け取る聖遺物（中ボスを倒すとき）。
- `winner` / `drawn`: 決着するか。
- `events` と `after`（行動のあとの複製）: まとめ方が足りないときは、これを直に読む。

`forest` は、ダメージの解決（`Hit`）とダメージのイベント（`UnitDamagedEvent`）が持つ、森の軽減が掛かったかを読む。

## 画面

- 対戦の画面は、見込みを対象のそばの予測のパネルに出す（`forecast_panel.gd`。中身は `forecast_text.gd` の `summarize` が
  `Forecast` をそのまま読んで、駒ごとの行と駒に属さない行にまとめたもの。倒せる・自分も巻き込まれるは目立たせる）。樽の爆発が届くマスは塗る。
  どちらも `docs/battle-view.md` の「戦闘予測のパネル」。

ノックバックと身代わり（隣の味方が肩代わり）は、ルールに無いので、予測にも無い。
