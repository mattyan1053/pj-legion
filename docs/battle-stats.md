# 戦績の集計

コード: `rules/battle_stats.gd`（`BattleStats`）。テスト: `tests/rules/test_battle_stats.gd`。
決着の画面の見せ方は `docs/battle-view.md`。

## 数え方

- `BattleStats.new(対戦)` で数え始める（ふつうは始まる前）。そのとき盤上にいる駒の戦績を作る。
  あとから湧いた中立の駒は、湧いたとき（`UnitSpawnedEvent`）に足す。倒れた駒の戦績も残る。
- `Battle.apply()` が返したイベントを、返った順に `feed(イベント)`（`feed_all(列)`）で食わせる。
  **対戦の途中でも読める**（食わせたところまでの数）。
- 対戦の状態は読まない（数え始めに盤上の駒を控えることと、ターンの数を読むことだけ）。ルールの挙動には関わらない。
- ターンは、食わせた時点の `Battle.turn`（行動を適用したあとのターン）。

## 駒ごとの戦績（`UnitRecord`）

| 値 | 中身 |
| --- | --- |
| `damage` | 敵のプレイヤーの駒（将を含む）に与えたダメージ |
| `neutral_damage` | 中立の駒（中ボスを含む）に与えたダメージ |
| `damage_taken` | 敵のプレイヤーの駒から受けたダメージ |
| `kills` | 倒した敵のプレイヤーの駒（将を含む） |
| `neutral_kills` / `boss_kills` | 倒した中立の駒（中ボスを含む）と、そのうちの中ボス |
| `healing` | 味方を回復した量（回復役の回復と、自分の置いた聖域の回復） |
| `skill_uses` | スキルを使った回数 |
| `level` / `evolution` / `evolved_turn` | いまのレベル、進化先、進化したターン（進化していなければ 0） |
| `defeated` | 倒されたか |

- ダメージは、駒の攻撃・スキル・樽の爆発を数える。**樽の爆発は、樽を攻撃した駒のもの**にする（撃破もその駒のもの。
  中ボスを倒した陣営の決め方 `docs/neutral-mid-boss.md` と同じ）。量はイベントの量（残りの HP より多くてもそのまま。バリアに防がれたら 0）。
- 撃破は、その駒にいちばん最後にダメージを与えた駒のもの。
- **味方へのダメージと、味方の撃破は数えない**（爆発やファイアボールで巻き込んだもの）。中立の駒の戦績は作るが、数えない。
- **受けたダメージは、与えたダメージの裏返し**（`damage` を数えるときに、受けた駒にも同じ量を足す）。だから数え方も同じ:
  樽の爆発は、樽を攻撃した駒が敵なら数え、味方や自分なら数えない。量はイベントの量（バリアに防がれたら 0）。
  **中立の駒から受けたダメージは数えない**（中立の駒の与えたダメージを数えないのと同じ）。中立の駒が受けたダメージも数えない。
  HP を減らすのはこの 3 つ（攻撃・スキル・樽の爆発）だけで、反動（アドレナリン注射）などの状態は HP を減らさない。
  陣営の `damage_taken` は、相手の陣営の `damage` といつも同じになる（テストが確かめる）。

## 陣営ごとの戦績（`SideRecord`）

駒の戦績の合計（`damage`、`neutral_damage`、`damage_taken`、`kills`、`neutral_kills`、`boss_kills`、`healing`、`skill_uses`）に加えて:

| 値 | 中身 |
| --- | --- |
| `level_ups` / `evolutions` | レベルアップの回数、進化した駒の数 |
| `losses` | 倒された駒（将を除く） |
| `ult_uses` / `first_ult_turn` | 必殺技を使った回数、最初に使ったターン（使わなければ 0） |
| `relics` | 受け取った聖遺物（受け取った順。`docs/relic-buff.md`） |

## 対戦全体

| 値 | 中身 |
| --- | --- |
| `ending` | 決着の理由（`NONE` = まだ、`KING_DEFEATED`、`HQ_CAPTURED`、`TURNS_HELD`、`ROUTED`、`DRAW`） |
| `winner` | 勝った陣営（決着していないか、引き分けなら -1） |
| `turns` | 決着したターン（決着していなければ、いまのターン） |
| `mid_bosses` | 倒れた中ボスの `[ターン, 中ボスの番号, 倒した陣営（いなければ -1）]` |

ステージの名前（決着の画面の「作戦領域」）は対戦の設定が持つ（`MatchSetup.stage_name`。`docs/match-setup.md`）。

## MVP

`mvp(陣営)`: その陣営の、**将を除く**駒のうち、`damage`（敵のプレイヤーの駒に与えたダメージ）がいちばん多い駒。
同じなら `kills` が多いほう、それも同じなら番号の小さいほう。ダメージを与えた駒がいなければ `null`。

- 将でなければ、どの種類でも候補になる（回復役も、ダメージを与えていれば候補）。
- 陣営ごとに選べる。どちらを見せるかは画面が決める（リザルトの画面は、CPU 戦は人の側、人どうしは勝った側。詳しい戦績には両方）。
- 称号は無い。

## 使うところ

- リザルトの画面（`docs/result-screen.md`）が、戦績の要点と MVP を段階的に出し、両方の陣営の詳しい戦績を畳んで持つ。
- 集計の道具（`tools/cpu_match.gd`。`docs/cpu-ai.md`）が、駒の種類ごとの表、レベルアップ、進化、撃破、必殺技、中ボスをここから写す。
  道具が自前で数えるのは、ここに無いもの（イベントの数、スキルごとの回数、経験値の入り方、プレイヤーの駒と中ボスの倒され方）だけ。
