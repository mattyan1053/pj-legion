# 駒のアイコン

コード: `game/unit_icons.gd`（読み出し）、`game/item_icon.gd`（持ち物の印）、`tools/unit_icons.gd` と `tools/unit_icons.sh`（写す道具）。
絵: `assets/unit_icons/`（出どころとライセンスは、その中の `README.md`）。テスト: `tests/game/test_unit_icons.gd`。

## 作り方

**絵は描かない。** 盤の上の駒の 3D の形（駒の見た目の組（`game/unit_looks.gd`。`docs/battle-view.md` の「駒の見た目の組」）が組む形と持ち物、陣営の色、進化の金の輪）を、
道具が SubViewport で正面から少し見下ろして写し、透明な地の正方形の PNG（大きさは `UnitIcons.ICON_SIZE`）にして、組ごとのディレクトリ（組の定義の `icon_dir`）に置く。
読み出すのは、いま使っている組の絵（組を替えると、アイコンもその組の絵になる）。

- 組ごとのディレクトリ: `kaykit`（いまの組）は `assets/unit_icons/` に直に。組を足したら、その組は `assets/unit_icons/<組の名前>/`。
- 写す組み合わせ（`UnitIcons.variants()`）: 人の駒（将と雇える駒）と魔物は青と赤、進化する駒（将と魔物を除く）は進化の前後。中立の駒は中立の色だけ。
  将の別の姿（`unit_looks.gd` の `KING_LOOKS`。ストーリーの敵の将の骸骨の将）も青と赤（ファイル名は `king_<姿>_<陣営>.png`）。
- 陣営の色は対戦の画面の色（`battle_screen.gd` の `TEAM_COLORS`）と同じ（テストが確かめる）。
- 駒の形や陣営の色を変えたら、`tools/unit_icons.sh <godot> [組の名前]` で書き直す（組の名前を省くと全部の組）。どの組にも全部の絵があることを、テストが確かめる。画面の描画が要るので、画面の無いコンテナでは Xvfb の上で回す（`--headless` では写らない）。
- 起動のたびに写さない（実行の時間を使わず、検査（`--headless`）でも同じ絵が出る）。

持ち物の印は、写さずにコードで描く単純な形（`item_icon.gd`。アイアンシールドは鉄色の盾、スピードブーツは靴と流れる線）。

## 出すところ

| 場所 | 中身 |
| --- | --- |
| 駒の札（`game/unit_card.gd`） | 名前の左に駒（対戦設定の「編成確認」、部隊編成の一覧の中身）。持ち物の行に持ち物の印 |
| 部隊編成の組む画面 | 雇える駒・部隊の駒の行、将の行、選んだ駒の札の見出し、軍を選ぶ札（その軍の駒の並び）。持ち物の欄に持ち物の印 |
| 対戦の駒の情報の枠（`battle_hud.gd`） | 名前の左に、その駒の陣営の色で、進化していれば進化後の形。マスの情報のときは出さない |
| 決着の画面（`result_screen.gd`） | MVP の名前の左と、詳しい戦績の表の各行に、その駒（陣営の色、進化後の形。表で倒れた駒は薄く） |
| ストーリーの出撃準備（`sortie_screen.gd`） | 敵の部隊（赤）と出撃する部隊（青）の駒の並び（将から）。初期位置の縮図（`deploy_map.gd`）の味方の駒 |
| 駒の詳細（`unit_detail.gd`） | アイコンは使わない（左に、盤の駒と同じ 3D の姿。`unit_portrait.gd`） |
| ストーリーの解放の知らせ（`talk_screen.gd`） | 知らせの文の左に、解放した駒（会話の行の `kind`） |
| ストーリーの物語を選ぶ場面（`campaign_list_screen.gd`） | カードの顔: その物語の軍の、将と最初から雇える駒（青） |
| ストーリーの話の一覧（`episode_list_screen.gd`） | カードの縮図の右下に、敵の話し手の姿（話のファイルの `[cast]` の姿。赤） |
| ストーリーの対戦の途中の台詞（`battle_talk.gd`） | 名前の札の左に、話し手の姿（話のファイルの `[cast]` の姿）の胸から上（`UnitIcons.bust`）。話し手の陣営の色 |

- 陣営の決まっていない場所（部隊編成、出撃準備の味方、解放の知らせ）は青。対戦設定の「編成確認」は、その行の陣営の色。
- 絵が無い（読めない）ときは、空の四角を出して並びを崩さない（`UnitIcons.rect`）。
