# マップ選択

コード: `game/map_select_screen.gd`（場面）、`game/versus_fields.gd`（選べる盤の一覧）、`game/map_card.gd`（カードの縮図。ノードに依存しない）。
テスト: `tests/game/test_versus_fields.gd`、`tests/game/test_map_card.gd`、`tests/game/test_match_choice.gd`、`tests/game/test_scene_flow.gd`、
自動の対戦（タイトル → マップ選択 → 対戦設定と戻る道。カードが画面に収まるか。手で作ったマップでの対戦の始め）。
盤の形は `docs/game-board.md`（生成）と `docs/hand-map.md`（手で作ったマップ）、置かれるものは `docs/map-objects.md`。

画面と文書では、遊ぶ人が選ぶ盤を「マップ」と呼ぶ（`docs/wording.md`）。コードの名前は、場面（`SceneFlow.MAP_SELECT`）、カードの縮図（`MapCard`）、
対戦設定のボタン（`press_map`）など遊ぶ人が選ぶ盤を指すものは `map` にした。次のものは前の名前のまま: 一覧の鍵（`field`。`versus_fields.gd`）、
生成の番号（`BoardGenerator.Stage` と戦いの定義の `stage`）、見た目（`stage_look.gd`）、生成のマップの名前の鍵（`stage.<id>`）、集計の道具の `--stage=`。
どれもコードの中だけの名前で、替えると変更が広く散るため。

## 選べる盤

対戦モードで選べる盤は、`game/versus_fields.gd` の `FIELDS` に並べる。盤は**鍵**（`StringName`。`plain`、`ridge_path` など）で持つ。
ストーリーの話（`game/story/episodes/` のファイルの名前）や見た目（`stage_look.gd` の名前）と同じ持ち方。

| 出どころ | 形 | 見た目 |
| --- | --- | --- |
| 生成のマップ（`BoardGenerator.Stage`） | 対戦を始めるたびに、種から作り直す（毎回ちがう形） | `StageLook.OF_STAGE` |
| 手で作ったマップ（`game/maps/` のファイルの id） | 種によらず、いつも同じ形 | 項目の `LOOK` |

- どちらも、対戦モードの決まりのまま: 勝ち方は将の撃破と本陣の占拠、初期位置は本陣の前の 2 行から選べる（対戦設定の「初期位置」。`docs/player-loadout.md`）、部隊は両方とも対戦設定で選ぶ（コスト上限と駒の数の上限は対戦の決まり）。
  戦いの定義は `VersusFields.scenario_of(鍵)`（生成は `Scenario.versus`、手で作ったマップは `Scenario.on_map`）。
- 項目が持つもの: 鍵、出どころ、ひとことの特徴（`TAGS`。カードに載せる）、説明（`NOTE`。マウスを乗せると出す）、手で作ったマップの見た目（`LOOK`）。名前は戦いの定義の名前（生成は画面の文の表の `stage.<id>`、手で作ったマップはファイルの `title`）。
- **盤を 1 つ足すのは、`FIELDS` に 1 項目**（手で作ったマップなら、`game/maps/` のファイルと）。画面（カード、対戦設定のパネル、番号のキー）と集計の道具は一覧から作る。
- 並びが画面の並びと番号。生成のマップを先に並べる（F1〜F3 と番号 1〜3 は、生成のマップのまま）。
- **対戦モードの画面に出すのは、CPU どうしの釣り合いがめやすに入る盤だけ。** めやすは、軍の違う対戦（先手・後手を入れ替える）で、両軍の部隊を局ごとに変えて、MILITARY の勝率と先手の勝率がどちらも 40〜60%（`tools/cpu_matches.gd -- --pairings=mixed --squads=random --stage=<鍵>` で 200 局以上）。
  部隊を変えるのは、手で作ったマップは種を変えても盤が同じで、CPU の決まった編成どうしだと、ほとんど同じ局を何度も数えることになるため（中立の駒の湧き直しのほかに乱数が無い）。
  外れる盤は `HIDDEN` を立てて一覧に残す（画面には出ず、番号も付かない。集計の道具では測れる）。
  いまは、どの盤もめやすに入っていて、出していない盤は無い（実測は `docs/cpu-ai.md` の「いまの集計」）。
  ストーリーの話が使うマップは、話の難しさが変わるので、対戦モードのために形を変えない。変えるなら、別のマップとして足す。

## 場面

タイトルの「対戦」のあと、対戦設定の前（`docs/scene-flow.md`）。

- 見出し「マップ選択」（SELECT MAP）と、カードの段。
- **カードは 2 段**: 上の段が生成のマップ（見出し「ランダム生成 ─ 対戦のたびに形が変わる」）、下の段が手で作ったマップ（「固定マップ ─ いつも同じ形」）。出す盤の無い段は作らない。段は上下の真ん中に寄せる。
  段の幅（3 枚）に収まらないほど増えたら、その段を横に送れる（つまみとホイール）。
- カードには、そのマップの**盤の縮図**（左）、番号と名前、置かれているもの（`TAGS`）、形の札（生成のマップは「ランダム」で青緑、手で作ったマップは「固定」で金）を載せる。
- マウスを乗せたカードは明るくなり（金の縁）、少し大きくなって、下の欄に「番号 名前 特徴（形）」と説明が出る。乗せていなければ、選び方の案内を出す。
  下の欄の大きさは、いちばん長い説明が収まる大きさに固定する（`game/steady_box.gd`。説明の長さで欄が伸び縮みすると、カードの段まで動いて揺れる）。
  自動の対戦が、どのカードに乗せても、ほかの部品の位置と大きさが変わらないことを確かめる（対戦設定の選び替え、部隊編成で駒に乗せる・選ぶ、出撃準備の部隊の選び替えも同じ）。
- カードをクリック（1〜9 のキーでも。番号のカード）すると、選んだ盤の鍵を対戦設定（`context.match_choice` の `field`）に入れて、対戦設定へ進む。
- 「部隊編成」で、対戦用の部隊を組む（寄り道。「マップ選択へ戻る」で、ここへ戻る）。取っておいた部隊は、対戦設定の人の行で選ばれている。
- 「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ。対戦設定の「マップ選択へ戻る」（右クリック・Esc でも）で、ここへ戻る（対戦設定で選んだものは残る）。
- 背景はタイトルと同じ景色（`backdrop.gd`）。曲もタイトルと同じ（途切れない）。

マップを選ぶのはここだけ。対戦設定のパネルは、選んだマップの名前を出すだけで、「マップ選択へ戻る」でここへ戻る（対戦の途中で開いたパネルからは「マップ変更」で。`docs/battle-view.md` の「対戦設定」）。

## 手で作ったマップでの対戦

- 決着の画面の「新しい盤面（○○）」と F1〜F3 は、**生成のマップだけ**（`MatchChoice.new_board_fields()`）。手で作ったマップは種を替えても同じ形なので、「新しい盤面」に入れない。
  手で作ったマップの対戦でも、ほかの行き先はいつもと同じ（同じ盤面で再戦、新しい盤面（生成のマップ）、対戦設定へ、マップ選択へ）。ほかのマップへは対戦設定から。
- 「同じ盤面で再戦」は、どの盤でも同じ種で始め直す。

## カードの縮図

絵は描かず、ルールが作る盤（`VersusFields.card_board`。生成のマップは種 `MAP_SEED` で固定）を、マスごとに色で塗る（1 マス `CELL` px。表示は拡大）。

| もの | 色 |
| --- | --- |
| 平地・森・岩（障害物）・結晶泉 | マップの見た目（`stage_look.gd`）の地面の色。岩は暗くする |
| 本陣 | 陣営の色。周りの 8 マスは暗い陣営の色 |
| 中ボス | 紫 |
| 起爆樽・回復の泉・ポータル | マスの真ん中の点（橙・水色・明るい紫） |

生成のマップの対戦の盤は、始めるときに種を決めて作り直すので、縮図と同じ形にはならない（マップの性格が分かればよい）。手で作ったマップは縮図のとおり。
