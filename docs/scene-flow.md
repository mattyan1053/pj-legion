# 場面の流れ

コード: `game/scene_flow.gd`（場面の種類と並び）、`game/run.gd`（流れ）、`game/app.gd`（入口。場面を切り替える）、`game/app_context.gd`（場面どうしで共有するもの）。
場面: `game/title_screen.gd`、`game/stage_select_screen.gd`、`game/setup_screen.gd`、`game/battle_screen.gd`（対戦）、`game/episode_list_screen.gd`（ストーリーの話の一覧）、`game/sortie_screen.gd`（出撃の準備）、`game/talk_screen.gd`（ストーリーの会話。`docs/story.md`）。背景は `game/backdrop.gd`。
テスト: `tests/game/test_scene_flow.gd`、`tests/game/test_run.gd`、自動の対戦（`game/autoplay.gd`。人と同じ道で対戦に入り、最後にタイトルと対戦の設定を往復する）。

## いまの流れ

```
起動 → タイトル ─「対戦」→ ステージ選択 ─カード→ 対戦の設定 ─「対戦を始める」→ 対戦 ─ 決着の画面 ─「同じ盤面でもう一度」「新しい盤面」→ 対戦（同じ場面のまま）
          ↑            │  ↑                          │                               │            ├─「対戦の設定へ」→ 対戦の設定
          ├「タイトルへ戻る」┘  └──「ステージ選択へ戻る」─────┘                               │            └─「タイトルへ」→ タイトル
          ├─「部隊の編成」→ 部隊の編成 ─「タイトルへ戻る」→ タイトル
          ├─「ストーリー」→ 話の一覧 ─話→ 会話（前）→ 出撃の準備 → 対戦 ─ 決着の画面 ─「次へ」（勝ったとき）→ 会話（後）→ 話の一覧
          │            ↑ └「タイトルへ戻る」→ タイトル      ↑↓          ├─「同じ盤面でもう一度」→ 対戦（同じ場面のまま）
          │            │                          部隊の編成          ├─「部隊を選び直す」→ 出撃の準備
          │            │                                             └─「タイトルへ」→ タイトル
          └──────────── システムメニューの「タイトルへ戻る」（どの場面からでも）
```

- 起動するとタイトルから始まる。タイトルは、題名と「対戦」「ストーリー」「部隊の編成」「設定」「終える」だけ。
- 「ストーリー」は、話の一覧へ進む。話を選ぶと、その話の流れ（会話 → 対戦 → 会話）を始め、終えたら話の一覧へ戻る（`docs/story.md`）。全部の話をクリアしていたら「ストーリー（クリア済み）」と出す。
- 「部隊の編成」は、部隊を組んで取っておく場面（`game/deck_screen.gd`。`docs/deck-screen.md`）。「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ戻る。
  取っておいた部隊は、対戦の設定で選ぶ。
- ステージ選択は、3 枚のカードからステージを選ぶ場面（`docs/stage-select.md`）。選ぶと対戦の設定へ進む。「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ。
- 対戦の設定（ステージ・相手・手番・軍・部隊）は、対戦の途中で開く設定画面と同じもの（`docs/battle-view.md` の「対戦の設定」）。選んだものは次に開いたときも残る（アプリが起動している間）。「ステージ選択へ戻る」（右クリック・Esc でも）でステージ選択へ戻る。
- 決着の画面（リザルト）は、対戦の場面の上に重ねて、段階的に出す（`docs/result-screen.md`）。出そろうまで行き先は選べない。
- 場面の切り替えは、短い暗転（`App.FADE_TIME` 秒ずつ、暗くして明ける）だけ。暗くなる間、抜ける場面は止めておく。
- 場面ごとの BGM は `SCENES` の `music` に書く。曲が替わるときは暗転と同じころにフェードでつなぎ、同じ曲の場面どうしでは途切れない（`docs/sound.md`）。
- タイトル・ステージ選択・対戦の設定・部隊の編成・話の一覧の背景は、対戦と同じ景色（盤と盤の外の景色。駒は置かない）を、ゆっくり回して見せる。素材は足していない。

## 場面の足し方

場面の種類と並びは `scene_flow.gd` の `SCENES` の表だけにある。**場面を 1 つ足すのは、`SCENES` に 1 行（スクリプトと、終わり方ごとの次の場面）足すだけ**。
アプリ（`app.gd`）は表のとおりに進め、場面の名前を決め打ちしない（検査の道を除く）。どの場面からでも行ける行き先（タイトル）は `COMMON` に置く。
モードの選択は、ここへ足す（Issue #49）。

## 流れ

表は「場面 + 終わり方 → 次の場面」なので、同じ場面を、違うものを渡して順に使えない（ストーリーの 1 話の「会話 → 対戦 → 会話」）。
それは**流れ**（`run.gd`）で並べる。流れは「場面の名前と、その場面に渡すもの」の列と、いま何番目か。

- 場面が `context.start_run(流れ)` で始める。アプリは、流れを `context.run` に置いて、最初の場面へ切り替える。
- 流れの中の場面は、渡すものを `context.run_data(自分の場面の名前)` で受け取る。流れの外から置かれたら null（場面は自分の既定で始める）。
- 流れの中の場面が `Run.NEXT` で終わったら、流れの次の場面へ。列を終えたら、流れの `exit`（既定はタイトル）へ。
- 流れの中の場面が `Run.PREVIOUS` で終わったら、流れの 1 つ前の場面へ戻る（ストーリーの決着の画面の「部隊を選び直す」→ 出撃の準備）。
- 場面は、流れのいまの場面の前に、別の場面を差し込める（`run.insert` のあと `context.start_run(流れ)`）。差し込んだ場面が `Run.NEXT` で終わると、もとの場面へ戻る
  （出撃の準備の「部隊を編成する」→ 部隊の編成 →「出撃の準備へ戻る」）。
- ほかの終わり方は表で進む。流れの外の場面へ切り替えたら（タイトルへ戻る、対戦の設定へ、など）、流れは捨てる。
- 流れの中の場面にも、`SCENES` の 1 行（スクリプトと、流れの外へ出る終わり方）は要る。
- いま流れを作るのは、対戦の設定の「対戦を始める」（選んだものの写しを渡す、対戦の場面 1 つの流れ。`match_choice.gd` の `run`）と、
  話の一覧で選んだ話（会話 → 出撃の準備 → 対戦 → 会話。`story.gd` の `run_of`。`exit` は話の一覧）。
  対戦の場面は、渡されたもので対戦を作る（`docs/battle-source.md`）。対戦の場面が `Run.NEXT` で終わるのは、決着の画面の「次へ」だけ。
- 会話の場面（`talk`）は、流れの中でだけ使う（表の `next` は空。流れの外へは、システムメニューの「タイトルへ戻る」だけ）。
  出撃の準備（`sortie`）も流れの中でだけ使う（「話の一覧へ戻る」で流れの外へ）。

### 場面の決まり

- `extends Node`（3D の場面も 2D の場面もよい）。アプリが作り、木に入れる前に `context`（`app_context.gd`）を入れる。
- `signal finished(outcome: StringName)` を持ち、終わるときに出す。outcome は、その場面の `next` か `COMMON` にある名前か、流れの中なら `Run.NEXT`。表に無い終わり方は進まない（エラーを出す）。
- あれば使うもの: `resume_label()`（システムメニューの「戻る」の文字）、`menu_items()` と `on_menu_item(id)`（システムメニューに足す項目）、
  `in_progress()`（抜けると失われるものがあるか。あれば、タイトルへ戻る・ゲームを終える前に確かめる）。`losing_note()`（確かめの文に書く、失われるもの。無ければ対戦の文）。
- 場面からアプリへの頼みごと（システムメニューを開く、設定の画面を開く）は `context.open_menu()` と `context.open_settings()`。場面はアプリを知らない。
  音は `context.play_sound(名前)`、決着の曲は `context.play_jingle(名前)`・`context.resume_scene_music()`、アプリを終えるのは `context.quit()`（音を止めてから終える）。
- 場面を抜けるとノードは消える。再生の待ち時間は、場面の子の Timer で測る（`battle_playback.gd` の `after`）。木の時計で待つと、消えた場面の続きが走ってしまう。

## 共有するもの（`app_context.gd`）

| もの | 中身 |
| --- | --- |
| `settings` | 遊ぶ人ごとの設定（`docs/system-menu.md`） |
| `system_menu` | システムメニュー（場面をまたいで 1 つ） |
| `sound` | 音を鳴らすところ（`game/sound.gd`。場面をまたいで 1 つ。`docs/sound.md`）。アプリを通さずに置いた場面では無い |
| `match_choice` | 対戦の設定の場面で選んだもの。次に対戦の設定を開いたときも、これを出す。流れの外から置かれた対戦の場面は、これで始める |
| `run` | いま進めている流れ（`run.gd`）。流れの外の場面にいるときは null |
| `story` | ストーリーの進み具合（`game/story.gd`。クリアした話。`docs/story.md`）。検査とスクリーンショットでは、ファイルを読み書きしない |
| `decks` | 取っておいた部隊（`game/deck_library.gd`。`docs/deck-screen.md`）。検査とスクリーンショットでは、ファイルを読み書きしない |
| `checking` | 検査（`autoplay`）か、スクリーンショットの道具（`shots`）として動いているか |

## 検査とスクリーンショット

- 自動の対戦（`-- --autoplay`）とスクリーンショットの道具（`-- --shots`）も、タイトルから入る。アプリが、タイトルの「始める」、ステージ選択のカード（いまの設定のステージ）、対戦の設定の「相手: 人」と「対戦を始める」を押して対戦に入る（最初の 1 回だけ）。種は決まった値（`AppContext.CHECK_SEED`）。
- 自動の対戦は暗転を待たない。最後に、相手（CPU）の番の途中でシステムメニューから「タイトルへ戻る」を選び（確かめが出ることも見る）、消えた対戦の続きが走らない（エラーが出ない）ことを確かめ、タイトル → ステージ選択 → 対戦の設定 → ステージ選択 → タイトルと往復する。
  そのあと、タイトルの「ストーリー」から 1 話を通す（`docs/story.md` の「検査」）。
- 自動の対戦（`autoplay.gd`）は、最初の対戦の場面が 1 つだけ作る（`context.autoplay`）。あとから入る対戦の場面（ストーリーの通し）は作らない。
