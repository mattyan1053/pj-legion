# 場面の流れ

コード: `game/scene_flow.gd`（場面の種類と並び）、`game/run.gd`（流れ）、`game/app.gd`（入口。場面を切り替える）、`game/app_context.gd`（場面どうしで共有するもの）。
場面: `game/title_screen.gd`、`game/slot_screen.gd`（ストーリーのセーブデータ選択。`docs/save-slots.md`）、`game/map_select_screen.gd`、`game/setup_screen.gd`、`game/battle_screen.gd`（対戦）、`game/campaign_list_screen.gd`（ストーリーの物語を選ぶ）、`game/episode_list_screen.gd`（ストーリーの話の一覧）、`game/sortie_screen.gd`（出撃準備）、`game/talk_screen.gd`（ストーリーの会話。`docs/story.md`）、`game/deck_screen.gd`（部隊編成）。背景は `game/backdrop.gd`（タイトルは `game/title_backdrop.gd`）。
テスト: `tests/game/test_scene_flow.gd`、`tests/game/test_run.gd`、自動の対戦（`game/autoplay.gd`。人と同じ道で対戦に入り、最後にタイトルと対戦設定を往復する）。

## いまの流れ

```
起動 → タイトル ─「対戦」→ マップ選択 ─カード→ 対戦設定 ─「対戦開始」→ 対戦 ─ 決着の画面 ─「同じマップで再戦」「新しいマップ」→ 対戦（同じ場面のまま）
          ↑            │  ↑                          │ ↑↓                            │            ├─「対戦設定へ」→ 対戦設定
          ├「タイトルへ戻る」┘  └「マップ選択へ戻る」─────┘ 部隊編成（対戦用）              │            └─「マップ選択へ」→ マップ選択
          │                    ↑ システムメニューの「マップ選択へ戻る」（対戦の途中）─────────┘
          ├─「ストーリー」→ セーブデータ選択 → 物語を選ぶ → 話の一覧 ─話→ 出撃準備 ─「出撃」→ 会話（前。1 度だけ）→ 対戦 ─ 決着の画面 ─「次へ」（勝ったとき）→ 会話（後）─┬「次の話へ」→ 次の話の出撃準備
          │            ↑ └「物語選択へ戻る」→ 物語を選ぶ ↑   ↑↓                        ├─「同じマップで再戦」→ 対戦（同じ場面のまま）  └「話の一覧へ」→ 話の一覧
          │            │                        │  部隊編成                     ├─「部隊変更」→ 出撃準備（会話は飛ばして対戦へ）
          │            │                        │                               └─「話の一覧へ」→ 話の一覧
          │            │                        └── システムメニューの「話の一覧へ戻る」（出撃準備・会話・対戦の途中）
          └──────────── システムメニューの「タイトルへ戻る」（どの場面からでも）
```

- 起動するとタイトルから始まる。タイトルは、題名と「ストーリー」「対戦」「オプション」「終了」だけ。「オプション」は、オプションの画面（`docs/system-menu.md` の「オプション」）を開く。「終了」は、ウィンドウの × と同じ確かめを出す（`docs/save-slots.md` の「ウィンドウを閉じるとき」）。
- 「ストーリー」は、セーブデータ選択（スロットを選ぶ。空きなら「はじめから」。`docs/save-slots.md`）へ進み、選ぶと物語を選ぶ場面へ進む。物語選択の「タイトルへ戻る」はタイトルへ。物語を選ぶと、その物語の話の一覧へ。話を選ぶと、その話の流れ（出撃準備 → 会話 → 対戦 → 会話）を始め、終えたら「次の話へ」か話の一覧へ（`docs/story.md`）。遊べる物語の話を全部クリアしていたら「ストーリー（クリア済み）」と出す。
- 部隊編成（部隊を組んで取っておく場面。`game/deck_screen.gd`。`docs/deck-screen.md`）は、タイトルからは開かない。各モードに入ったところから寄り道で開き、戻ると開いた場面:
  対戦はマップ選択と対戦設定の「部隊編成」（`match_choice.gd` の `deck_run`。編成 → もとの場面 の流れ）、
  ストーリーは物語選択（物語ごと）・話の一覧（`story.gd` の `deck_run`）と出撃準備の「部隊編成」。
  取っておいた部隊は、対戦用は対戦設定で、ストーリー用は出撃準備で選ぶ。
- マップ選択は、カード（生成のマップと手で作ったマップの 2 段）からマップを選ぶ場面（`docs/map-select.md`）。選ぶと対戦設定へ進む。「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ。
- 対戦設定（相手・手番・軍・部隊。マップは選んだものを出すだけ）は、対戦の途中で開く対戦設定のパネルと同じもの（`docs/battle-view.md` の「対戦設定」）。選んだものは次に開いたときも残る（アプリが起動している間）。「マップ選択へ戻る」（右クリック・Esc でも）でマップ選択へ戻る。
- 決着の画面は、対戦の場面の上に重ねて、段階的に出す（`docs/result-screen.md`）。出そろうまで行き先は選べない。
- 場面の切り替えは、短い幕（`App.FADE_TIME` 秒ずつ、覆って明ける）だけ。幕は、夜の藍が左上から斜めに拭き取るように覆い、同じ向きへ抜ける（`game/wipe.gdshader`。縁はやわらかくにじみ、真鍮の細い光が走る）。
  覆われる間、抜ける場面は止めておく。新しい場面も、幕が明けきるまで止めておき、入力を渡さない（切り替えの途中の操作は、行き先が捨てられるため）。
- 場面ごとの BGM は `SCENES` の `music` に書く。曲が替わるときは暗転と同じころにフェードでつなぎ、同じ曲の場面どうしでは途切れない（`docs/sound.md`）。
- タイトルの背景は、裂けた空の下の、いろいろな話のマップの景色（`game/title_backdrop.gd`）。世界（「空の縫い目」。`docs/story.md`）を 1 枚で見せる。
  景色は、起動のたびと 40 秒ごと（`TitleScreen.SCAPE_SECONDS`）に、13 の景色（`StageLook.THEMES`）からランダムに選ぶ（いまと違うもの。替えるときは幕をいちど沈める）。
  盤は、その景色を使う話のマップ（無ければ対戦モードのマップ。`TitleScreen.title_scapes`）。検査とスクリーンショットでは、いつも最初の景色（草原）で替えない。
  入ったときは、幕が明けるのと重ねて題字が浮かび、メニューが上から順に現れる（明けきるのを待たない。明けてから動き出すと、空だけの間ができる）。
  幕が明けたあとは、動きの終わりを待たずに押せる。
  - 空は `game/rift_sky.gdshader` が描く（絵は使わない）: 夜の藍、縦に走る裂け目（縫い目）の光と、それをまたぐ縫い糸、星、たなびく雲。
    縫い目の左は機械の国ベルク連邦の煙る琥珀、右は魔法の国リュエル騎士領の菫。
  - 地面は対戦の画面の部品（選んだ景色の盤と、盤の外の景色。マス目は隠す）。霞とまわりの光に、その景色の空気の色を少し残す（`SCAPE_AIR`）。光は裂け目の側から低く差し、岩山と結晶と木立が影になる。
  - カメラは盤の端に低く構えて、ゆっくり左右に振る。入ったとき、裂け目の光が差してくる。
  - 題字とメニューは、板に載せず、景色の上に直に置く（題字の下に飾りの線 `game/ui_ornament.gd`、メニューは `UiTheme.BUTTON_MENU`）。
- **ストーリーの背景は、物語ごとの景色**（タイトルと同じ裂けた空の下。`TitleBackdrop.show_story`）。物語ごとに、次の 3 つが替わる:
  空の向き（その国の側の空へ向く。`map_view_of(軍)`。ベルク連邦は縫い目の左の琥珀、リュエル騎士領は右の菫。縫い目は画面の端に見える）、
  空の色（左右の色を、その国の色へ寄せる。`NATION_SKY`、`NATION_SKY_SHARE`）、地面と遠景（その物語の話のマップの盤と見た目。高く構えて少し見下ろす）。
  - 話の一覧: 開いたときは次に遊ぶ話のマップ。カードにマウスを乗せる（矢印で選ぶ）と、その話のマップに替わる（まだ遊べない話では替えない）。
  - 物語を選ぶ場面: 開いたときは、縫い目を真ん中に、少し高く空を広く見た結晶の森（`VIEW_STORY`。左のカードが琥珀、右のカードが菫の空の下）。
    物語のカードに乗せると、その物語の景色（地面は、その物語でまだクリアしていない最初の話のマップ。`Story.scape_episode_in`）に替わる。
  - セーブデータ選択: 開いたときは、いまのデータの物語の景色（地面は、クリアしたいちばん先の話の次の話のマップ。`Story.scape_episode`）。
    カードに乗せると、そのデータのものに替わる。物語の無いデータ（空きなど）は、`VIEW_STORY` の結晶の森。
  - 替えるときは、マップ選択と同じく、通り過ぎるだけでは替えず（`SWAP_DELAY` 秒とどまったら）、幕をいちど沈めて替える（`queue_story`）。
  - 国の紋は、見出し（話の一覧）とカードの帯（物語のカード・セーブデータのカード）に出す（いままでどおり）。
- **マップ選択と対戦設定の背景も、同じ裂けた空の下**（`VIEW_VERSUS`。高く構えて少し見下ろす）。地面と景色は、**選んでいるマップのもの**
  （盤の形と見た目。`TitleBackdrop.show_scape`）。光は同じ裂け目の光で、霞とまわりの光にだけ、マップの空気の色を少し残す（`SCAPE_AIR`）。
  - マップ選択は、カードにマウスを乗せる（矢印で選ぶ）と、そのマップの景色に替わる。通り過ぎるだけでは替えず（`SCAPE_DELAY` 秒とどまったら）、
    幕をいちど沈めて、その間に替える（景色を作り直す 1 コマの引っ掛かりを見せない）。入ったときは、前に選んだマップ（無ければ中央平原）。
  - 対戦設定は、選んだマップの景色。板が画面のほとんどを覆うので、四隅だけ沈める（板の左右に空と景色が見える）。
- 部隊編成の背景は、対戦と同じ景色（盤と盤の外の景色。駒は置かない）を、ゆっくり回して見せる（`game/backdrop.gd`）。会話と出撃準備は、その話の盤を同じように見せる。素材は足していない。

## 場面の足し方

場面の種類と並びは `scene_flow.gd` の `SCENES` の表だけにある。**場面を 1 つ足すのは、`SCENES` に 1 行（スクリプトと、終わり方ごとの次の場面）足すだけ**。
場面の名前は `SceneFlow.TITLE`・`SceneFlow.BATTLE` などの定数で指す（ほかのスクリプトに文字で書かない。`tests/game/test_scene_flow.gd` が確かめる）。
アプリ（`app.gd`）は表のとおりに進め、場面の名前を決め打ちしない（検査の道を除く）。どの場面からでも行ける行き先（タイトル）は `COMMON` に置く。

## 流れ

表は「場面 + 終わり方 → 次の場面」なので、同じ場面を、違うものを渡して順に使えない（ストーリーの 1 話の「会話 → 対戦 → 会話」）。
それは**流れ**（`run.gd`）で並べる。流れは「場面の名前と、その場面に渡すもの」の列と、いま何番目か。

- 場面が `context.start_run(流れ)` で始める。アプリは、流れを `context.run` に置いて、最初の場面へ切り替える。
- 流れの中の場面は、渡すものを `context.run_data()` で受け取る（場面は自分の名前を書かない。アプリが、場面を作る前に `context.scene` へ入れる）。
  流れの外から置かれたら null（場面は自分の既定で始める）。
- 流れの中の場面が `Run.NEXT` で終わったら、流れの次の場面へ。列を終えたら、流れの `exit`（既定はタイトル）へ。
- 流れの中の場面が `Run.PREVIOUS` で終わったら、流れの 1 つ前の場面へ戻る（ストーリーの決着の画面の「部隊変更」→ 出撃準備）。
- 場面を `once`（`run.add` の 3 つ目）で足すと、1 度 `Run.NEXT` で通り過ぎたあとは、前後へ動くときに飛ばす
  （ストーリーの対戦の前の会話。「部隊変更」で出撃準備へ戻って出撃し直しても、もう出さない。見たければ話の一覧から入り直す）。
- 流れは、システムメニューに足す流れの外への行き先を持つ（`menu_exits`。ストーリーの話は「話の一覧へ戻る」、対戦モードの対戦は「マップ選択へ戻る」）。
  アプリが「タイトルへ戻る」の上に並べ、抜けると失われるものがあれば確かめる（タイトルへ戻るのと同じ）。
- 場面は、流れのいまの場面の前に、別の場面を差し込める（`run.insert` のあと `context.start_run(流れ)`）。差し込んだ場面が `Run.NEXT` で終わると、それを列から外して、もとの場面へ戻る（寄り道を何度しても列は伸びない）
  （出撃準備の「部隊編成」→ 部隊編成 →「出撃準備へ戻る」）。
- ほかの終わり方は表で進む。流れの外の場面へ切り替えたら（タイトルへ戻る、対戦設定へ、など）、流れは捨てる。
- 流れの中の場面にも、`SCENES` の 1 行（スクリプトと、流れの外へ出る終わり方）は要る。
- いま流れを作るのは、対戦設定の「対戦開始」（選んだものの写しを渡す、対戦の場面 1 つの流れ。`match_choice.gd` の `run`）、
  マップ選択・対戦設定の「部隊編成」（部隊編成 → もとの場面。`match_choice.gd` の `deck_run`）、物語選択・話の一覧の「部隊編成」（`story.gd` の `deck_run`）と、
  話の一覧で選んだ話（出撃準備 → 会話 → 対戦 → 会話。`story.gd` の `run_of`。`exit` は話の一覧）。
  対戦の場面は、渡されたもので対戦を作る（`docs/battle-source.md`）。対戦の場面が `Run.NEXT` で終わるのは、決着の画面の「次へ」だけ。
- 会話の場面（`talk`）は、流れの中でだけ使う（表の `next` は空。流れの外へは、システムメニューの「話の一覧へ戻る」「タイトルへ戻る」）。
  あとの会話を読み終えると「次の話へ」（次の話の流れを、`context.start_run` で始める）か「話の一覧へ」（`Run.NEXT`）を選ぶ（次の話が無ければ選ばずに話の一覧へ）。
  出撃準備（`sortie`）も流れの中でだけ使う（「話の一覧へ戻る」で流れの外へ）。

### 場面の決まり

- `extends Node`（3D の場面も 2D の場面もよい）。アプリが作り、木に入れる前に `context`（`app_context.gd`）を入れる。
- `signal finished(outcome: StringName)` を持ち、終わるときに出す。outcome は、その場面の `next` か `COMMON` にある名前か、流れの中なら `Run.NEXT`。表に無い終わり方は進まない（エラーを出す）。
- あれば使うもの: `resume_label()`（システムメニューの「戻る」の文字）、`menu_items()` と `on_menu_item(id)`（システムメニューに足す項目）、
  `in_progress()`（抜けると失われるものがあるか。あれば、タイトルへ戻る・ゲームを終える前に確かめる）。`losing_note()`（確かめの文に書く、失われるもの。無ければ対戦の文）。
- 場面からアプリへの頼みごと（システムメニューを開く、オプションの画面を開く）は `context.open_menu()` と `context.open_settings()`。場面はアプリを知らない。
  音は `context.play_sound(名前)`、決着の曲は `context.play_jingle(名前)`・`context.resume_scene_music()`、アプリを終えるのは `context.quit()`（音を止めてから終える）。
- 場面を抜けるとノードは消える。再生の待ち時間は、場面の子の Timer で測る（`battle_playback.gd` の `after`）。木の時計で待つと、消えた場面の続きが走ってしまう。

## 共有するもの（`app_context.gd`）

| もの | 中身 |
| --- | --- |
| `settings` | 遊ぶ人ごとの設定（`docs/system-menu.md`） |
| `system_menu` | システムメニュー（場面をまたいで 1 つ） |
| `sound` | 音を鳴らすところ（`game/sound.gd`。場面をまたいで 1 つ。`docs/sound.md`）。アプリを通さずに置いた場面では無い |
| `match_choice` | 対戦設定の場面で選んだもの。次に対戦設定を開いたときも、これを出す。流れの外から置かれた対戦の場面は、これで始める |
| `run` | いま進めている流れ（`run.gd`）。流れの外の場面にいるときは null |
| `story` | ストーリーの進み具合（`game/story.gd`。クリアした話。`docs/story.md`）。検査とスクリーンショットでは、ファイルを読み書きしない |
| `decks` | 取っておいた部隊（`game/deck_library.gd`。`docs/deck-screen.md`）。検査とスクリーンショットでは、ファイルを読み書きしない |
| `overlays` | 開いている重なる画面（システムメニュー、ログ、対戦設定のパネル）の積み上げ（`game/overlay_stack.gd`）。Esc と右クリックは、いちばん上だけが受ける |
| `checking` | 検査（`autoplay`）か、スクリーンショットの道具（`shots`）として動いているか |
| `autoplay` | 自動の対戦（`game/autoplay.gd`）。最初の対戦の場面が作る |

## 検査とスクリーンショット

- 自動の対戦（`-- --autoplay`）とスクリーンショットの道具（`-- --shots`）も、タイトルから入る。アプリが、タイトルの「対戦」、マップ選択のカード（いまの設定のマップ）、対戦設定の「相手: 人」と「対戦開始」を押して対戦に入る（最初の 1 回だけ）。種は決まった値（`AppContext.CHECK_SEED`）。
- 自動の対戦は暗転を待たない。最後に、相手（CPU）の番の途中でシステムメニューから「タイトルへ戻る」を選び（確かめが出ることも見る）、消えた対戦の続きが走らない（エラーが出ない）ことを確かめ、タイトル → マップ選択 → 対戦設定 → マップ選択 → タイトルと往復する。
  そのあと、タイトルの「ストーリー」から 1 話を通す（`docs/story.md` の「検査」）。
- 自動の対戦（`autoplay.gd`）は、最初の対戦の場面が 1 つだけ作る（`context.autoplay`）。あとから入る対戦の場面（ストーリーの通し）は作らない。
