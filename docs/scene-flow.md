# 場面の流れ

コード: `prototype/scene_flow.gd`（場面の種類と並び）、`prototype/app.gd`（入口。場面を切り替える）、`prototype/app_context.gd`（場面どうしで共有するもの）。
場面: `prototype/title_screen.gd`、`prototype/setup_screen.gd`、`prototype/board_prototype.gd`（対戦）。背景は `prototype/backdrop.gd`。
テスト: `tests/prototype/test_scene_flow.gd`、自動の対戦（`prototype/autoplay.gd`。人と同じ道で対戦に入り、最後にタイトルと対戦の設定を往復する）。

## いまの流れ

```
起動 → タイトル ─「始める」→ 対戦の設定 ─「対戦を始める」→ 対戦 ─ 決着の画面 ─「同じ盤面でもう一度」「新しい盤面で対戦する」→ 対戦（同じ場面のまま）
          ↑                    │                              │            ├─「対戦の設定へ」→ 対戦の設定
          ├─「タイトルへ戻る」──┘                              │            └─「タイトルへ」→ タイトル
          ├─「部隊の編成」→ 部隊の編成 ─「タイトルへ戻る」→ タイトル
          └──────────── システムメニューの「タイトルへ戻る」（どの場面からでも）
```

- 起動するとタイトルから始まる。タイトルは、題名と「始める」「部隊の編成」「設定」「終える」だけ。
- 「部隊の編成」は、部隊を組んで取っておく場面（`prototype/deck_screen.gd`。`docs/deck-screen.md`）。「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ戻る。
  取っておいた部隊は、対戦の設定で選ぶ。
- 対戦の設定（ステージ・相手・手番・軍・部隊）は、対戦の途中で開く設定画面と同じもの（`docs/battle-view.md` の「対戦の設定」）。選んだものは次に開いたときも残る（アプリが起動している間）。
- 決着の画面（リザルト）は、対戦の場面の上に重ねて、段階的に出す（`docs/result-screen.md`）。出そろうまで行き先は選べない。
- 場面の切り替えは、短い暗転（`App.FADE_TIME` 秒ずつ、暗くして明ける）だけ。暗くなる間、抜ける場面は止めておく。
- 場面ごとの BGM は `SCENES` の `music` に書く。曲が替わるときは暗転と同じころにフェードでつなぎ、同じ曲の場面どうしでは途切れない（`docs/sound.md`）。
- タイトルと対戦の設定の背景は、対戦と同じ景色（盤と盤の外の景色。駒は置かない）を、ゆっくり回して見せる。素材は足していない。

## 場面の足し方

場面の種類と並びは `scene_flow.gd` の `SCENES` の表だけにある。**場面を 1 つ足すのは、`SCENES` に 1 行（スクリプトと、終わり方ごとの次の場面）足すだけ**。
アプリ（`app.gd`）は表のとおりに進め、場面の名前を決め打ちしない（検査の道を除く）。どの場面からでも行ける行き先（タイトル）は `COMMON` に置く。
後で、ストーリーモード（会話の場面と戦闘を順に並べる）、モードの選択を、ここへ足す（Issue #49）。

### 場面の決まり

- `extends Node`（3D の場面も 2D の場面もよい）。アプリが作り、木に入れる前に `context`（`app_context.gd`）を入れる。
- `signal finished(outcome: StringName)` を持ち、終わるときに出す。outcome は、その場面の `next` か `COMMON` にある名前。表に無い終わり方は進まない（エラーを出す）。
- あれば使うもの: `resume_label()`（システムメニューの「戻る」の文字）、`menu_items()` と `on_menu_item(id)`（システムメニューに足す項目）、
  `in_progress()`（抜けると失われるものがあるか。あれば、タイトルへ戻る・ゲームを終える前に確かめる）。
- 場面からアプリへの頼みごと（システムメニューを開く、設定の画面を開く）は `context.open_menu()` と `context.open_settings()`。場面はアプリを知らない。
  音は `context.play_sound(名前)`、決着の曲は `context.play_jingle(名前)`・`context.resume_scene_music()`、アプリを終えるのは `context.quit()`（音を止めてから終える）。
- 場面を抜けるとノードは消える。再生の待ち時間は、場面の子の Timer で測る（`battle_playback.gd` の `after`）。木の時計で待つと、消えた場面の続きが走ってしまう。

## 共有するもの（`app_context.gd`）

| もの | 中身 |
| --- | --- |
| `settings` | 遊ぶ人ごとの設定（`docs/system-menu.md`） |
| `system_menu` | システムメニュー（場面をまたいで 1 つ） |
| `sound` | 音を鳴らすところ（`prototype/sound.gd`。場面をまたいで 1 つ。`docs/sound.md`）。アプリを通さずに置いた場面では無い |
| `match_choice` | 対戦の設定の場面で選んだもの。対戦の場面は、これで始める |
| `decks` | 取っておいた部隊（`prototype/deck_library.gd`。`docs/deck-screen.md`）。検査とスクリーンショットでは、ファイルを読み書きしない |
| `checking` | 検査（`autoplay`）か、スクリーンショットの道具（`shots`）として動いているか |

## 検査とスクリーンショット

- 自動の対戦（`-- --autoplay`）とスクリーンショットの道具（`-- --shots`）も、タイトルから入る。アプリが、タイトルの「始める」、対戦の設定の「相手: 人」と「対戦を始める」を押して対戦に入る（最初の 1 回だけ）。種は決まった値（`AppContext.CHECK_SEED`）。
- 自動の対戦は暗転を待たない。最後に、相手（CPU）の番の途中でシステムメニューから「タイトルへ戻る」を選び（確かめが出ることも見る）、消えた対戦の続きが走らない（エラーが出ない）ことを確かめ、タイトル → 対戦の設定 → タイトルと往復する。
