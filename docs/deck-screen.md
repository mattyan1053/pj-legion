# 部隊編成（画面と、取っておく部隊）

コード: `game/deck_screen.gd`（編成の場面。一覧・組む画面・駒の札などは `game/deck_screen/` に分けてある）、`game/deck_library.gd`（取っておく部隊の一覧と、ファイルの読み書き）、
`game/deck_text.gd`（出せない理由、持ち物の文）、`game/unit_card.gd`（駒の札）、`game/deck_preview.gd`（編成確認）、`game/match_choice.gd` と `game/match_setup_panel.gd`（対戦設定で選ぶ）。
テスト: `tests/game/test_deck_library.gd`、`tests/game/test_match_choice.gd`、`tests/game/test_match_setup_panel.gd`、`tests/game/test_unit_sheet.gd`（駒の詳細）、自動の対戦（`game/autoplay/title_checks.gd` の `_visit_decks`）。

編成のルール（軍、ロスター、持ち物、コスト上限）は `docs/player-loadout.md`。
**初期位置は部隊では決めない**（マップとその戦いの定義が置けるマスを決め、マップを選んだあとに出撃準備・対戦設定で決める。`docs/story.md`、`docs/battle-view.md`）。部隊は駒と持ち物の組だけ、検査と編成の決まりは `docs/deck-building.md`。

## 流れ

- 各モードに入ったところの「部隊編成」から開く（どれも寄り道で、戻ると開いた場面。タイトルからは開かない）。部隊は、名前を付けて、いくつでも取っておける。
  - 対戦用: マップ選択（マップを選ぶ前）と対戦設定（選んだあと）。`match_choice.gd` の `deck_run`。
  - ストーリー用（その物語の部隊）: 物語選択（カードの下。物語ごと）、話の一覧、出撃準備。物語選択と話の一覧は `story.gd` の `deck_run`、出撃準備は話の流れに差し込む。
- 一覧は、**対戦用**か**物語ごとのストーリー用**の、1 つの決まりの部隊だけを出す。対戦設定から開けば対戦用、出撃準備から開けばその物語のストーリー用。一覧に並ぶのも、「新規編成」で組むのも、その決まりの部隊だけ。
  一覧の見出しの横に、決まりの名前（対戦用は「対戦用」、ストーリー用は物語の名前）を出す。切り替えのボタンは置かない（決まりは開いたもとが決める）。
  流れの外で置いたとき（スクリーンショットの道具など）は対戦用で始まり、道具が `set_mode` で替える。
  対戦用の部隊がストーリーに、ストーリー用の部隊が対戦やほかの物語に混ざることは無い（決まりの名前で分ける。`docs/deck-building.md`）。
- 対戦用の部隊は、対戦設定で選んで出撃する（下の「対戦設定で選ぶ」）。ストーリー用の部隊は、ストーリーの出撃準備で選ぶ（`docs/story.md`）。
- 組む画面の決まり（`DeckRules`）は、一覧の決まりと同じ（`deck_screen.gd` の `rules`）。対戦用は対戦の決まり、ストーリー用は、その物語のいまの進み具合の決まり
  （軍は物語の軍だけ。雇える駒は、いま解放した駒だけ）。選べない軍の札は出さない。
- 寄り道（`docs/scene-flow.md` の「流れ」）では、いちばん外の戻る（ボタン・右クリック・Esc）は
  開いた場面へ戻る（「マップ選択へ戻る」「対戦設定へ戻る」「物語選択へ戻る」「話の一覧へ戻る」「出撃準備へ戻る」）。開いたときは、もとの画面で選んでいる部隊を一覧で選んでおく。
  寄り道の間に最後に取っておいた部隊は、出撃準備（対戦用なら対戦設定の、「部隊編成」を押した行。マップ選択からなら人の行）で選ばれている。

## 見た目の決まり

- 画面の文は短い名前のボタンと見出しにする（説明の文で操作を教えない）。スキルや必殺技など、中身の説明は読める場所に出す。
- 画面の上に `TOP_ROOM` だけ空け、右上のシステムメニューのボタンを、ほかの場面と同じく背景の上に置く（枠に埋もれないように）。
- 駒は**札**で見せる（`game/unit_card.gd`。名前、役割、コスト、能力値、持ち物）。一覧の中身、対戦設定の「編成確認」が同じ札を使う。
- 駒のアイコンは額に入れて役割の印を付け、コストは宝石で、能力値は幅のそろった欄で見せる。軍は国の色と紋で見せる（部品と決まりは `docs/ui-theme.md` の「駒と軍の部品」）。
  コスト / コスト上限は、棒ではなく宝石の目盛り（上限が違う軍・物語でも、同じ幅に収める）。

## 駒の詳細

コード: `game/unit_detail.gd`（窓）、`game/unit_sheet.gd`（中身。ノードに依存しない）、`game/unit_portrait.gd`（姿）、`game/stat_meter.gd`（能力値の行）、`game/ability_mark.gd`（札の印）。
テスト: `tests/game/test_unit_sheet.gd`。

駒 1 体のステータスの窓。文の段落では並べず、欄で見せる。開く所:

- 編成確認（対戦設定と、対戦の途中の設定パネルの「編成確認」。`game/deck_preview.gd`）の札。見出しの下に「クリック: 詳細」。
- 出撃準備の部隊の駒の額（味方も敵も。魔物も）。マウスを乗せると名前・持ち物と「クリック: 詳細」。
- 部隊編成で、部隊の駒を選んでいるときの右の札の「詳細」（雇える駒にマウスを乗せている間は出さない。場所は保つ）。
- 対戦の、左下の情報の枠の「詳細」（クリックして見ている駒か、選んでいる駒がいるときだけ出る。開いている間は時間を止める）。

並び:

- **左**: 駒の姿（盤の駒と同じ 3D の形を、陣営の色の縁の額に大きく。後ろに軍の国の紋）、レベルと経験値の棒（育つ駒だけ。最大のレベルは「最大」）、
  コスト（雇う駒だけ。宝石）、**持ち物の欄**（持てる数だけの枠。1 個が枠 1 つで、印・名前・効果。空きは沈める。持てない将・魔物は欄ごと出さない）。
- **右**: 役割の印と名前（明朝）、札（役割、軍。将は「本陣に配置」、魔物は「魔物」。回復役は回復役の攻撃「攻撃 4」も）、役割の説明（ほかの軍から雇った駒は「FANTASY の駒（この部隊では MILITARY として戦う）」）。
  - **能力値の行**（HP、攻撃か回復、移動、射程）: 名前、いまの値、増減、目盛り。HP と攻撃は目盛り線つきの棒、移動と射程は菱形の粒。
    **値は、いつも持ち物込みの 1 つだけ**を出し、持ち物での増減を色と矢印で添える（増えたら良い知らせの色で「▲ +30」、減ったら危険の色で「▼ -1」。棒と粒も、増えたぶん・減ったぶんを同じ色で塗り分ける）。
    素の値（種類の値 + レベルアップ + 進化）と増減の分け方は `UnitSheet`。対戦中は、聖遺物と状態のぶんも増減に入る。
    目盛りの端は `UnitSheet.SCALES`（超える駒は、その駒の値が端）。
    **HP の棒は、枠の長さが最大 HP、塗りがいまの HP**（枠に対する塗りの割合が、いまの HP の割合。減ったぶんは沈んだ赤）。
    枠は、最大 HP が小さい駒でも棒の欄の半分弱（`stat_meter.gd` の下駄）はあり、残りを最大 HP の大小で伸ばす（全駒共通の目盛りにそのまま比例させると、HP が減った駒の塗りが数 px になって読めない）。
  - 状態（対戦中だけ。名前、残りのターン数、効果）。
  - **スキルと必殺技の札**（横に並べる）: 印、名前、右にクールダウンの長さ（対戦中は、いまの状態「使用可」「あと 2 ターン」）、説明。必殺技は部隊の軍のもの（軍なしの魔物・中立は出さない）。スキルを持たない駒は、沈めた「スキルなし」。
  - **進化先の札**（選べる 2 つ。能力値の増減と特性）。進化した駒は、その進化先だけを「進化済み」として出す。進化しない駒は欄ごと出さない。
- 始めのレベルが 1 でない駒（出撃準備）は、そのレベルと、伸びた能力値で出す（伸びたぶんは素の値。対戦の始めの値と同じ）。
- **窓の幅は、どの駒でも同じ**（右の列は、スキルの名前とクールダウンの札がいちばん長い札が 2 枚並べて収まる幅。`unit_detail.gd` の `RIGHT_WIDTH`。
  テストが全部の駒で幅をそろえて確かめる）。高さは、持ち物・状態・進化先の行の数で変わってよい。
- どの駒・持ち物でも、1280×720 の論理の画面に収まる（テストが確かめる）。
- 「閉じる」・右クリック・Esc・枠の外のクリックで閉じる（窓だけが閉じ、編成確認や出撃準備は残る）。
- 枠・札・ボタンの見た目は UI のテーマ（`docs/ui-theme.md`）。札の形のボタン（雇える駒、部隊の駒、一覧の部隊、軍）はカード、「編成完了」はいちばん大事なボタン、「削除」は危険なボタン。

部隊編成の右の札（選んだ駒・乗せた駒）は、**小さなステータスの札**（`game/unit_summary.gd`）。窓と同じ部品（`game/sheet_parts.gd`、`game/stat_meter.gd` の詰めた行）を、札の幅に詰めて並べる:

- 頭: 駒のアイコンの額、役割の印と名前（部隊の駒は「4. コマンドー」）、札（役割・軍。回復役は「攻撃 4」も）とコスト（宝石）、役割の説明。その下の飾りの線の右に「詳細」。
- 能力値の行（HP、攻撃か回復、移動、射程）: いまの値、持ち物での増減、棒か粒。HP は満タンなので、値を 1 つだけ出す。
- スキルの札（印、名前、クールダウン、説明）。必殺技は、雇える駒の一覧の下に出しているので、ここには出さない。持ち物は、下の持ち物の欄。
- 進化先の札（2 つを横に。名前と、能力値の増減・特性）。
- 幅は中身で変わらない（テストが、全部の駒で確かめる）。持ち物の欄に押されて低いときは、札の中で送る（能力値とスキルが先に見える）。

編成確認と一覧の駒の札（`unit_card.gd`）と、初期位置の駒の欄（`deploy_note.gd`）の役割も、同じ小さな札（`PANEL_TAG`）で出す。

## 一覧

- 取っておいた部隊を、取っておいた順に並べる。1 行に、名前、軍、駒の数、コスト / コスト上限。出せない部隊は行を赤くし「出撃不可」。
- 部隊が無ければ「編成なし」とだけ出す。下に「新規編成」。
- 押して選ぶと、右に名前、軍・駒の数・コスト（決まった幅の欄）とコストのゲージ（軍略のある部隊は、ゲージの後ろに軍略の印と名前。ゲージの位置は、どの部隊でも同じ）、駒の札（将から並びの順。多ければ欄の中で送る）、出せない理由、操作のボタンが出る。
  - 「編集」: 組む画面で開く。「編成完了」を押すまで、一覧の部隊は変わらない（`Deck.copy()` を直す）。
  - 「複製」: すぐ後ろに「〜 の写し」を足す。
  - 「名前変更」: 名前を入れる窓（長さの上限は `deck_library.gd` の `MAX_NAME_LENGTH`。空なら変えない）。
  - 「削除」: 確かめてから消す（元に戻せない）。
- 「新規編成」: **まず軍を選ぶ**（軍の札: 名前、コスト上限、雇える駒、必殺技）。選ぶと、その軍の空の部隊（名前は「部隊 N」）を組む画面で開く。
  選べる軍が 1 つ（ストーリー用）なら、選ばずにその軍で開く。「戻る」（右クリック・Esc でも）で一覧へ。
- **出せない部隊も一覧に残る**（決まりが変わった、ファイルを手で書き換えた、知らない駒がある）。組み直して「編成完了」すれば、出せるようになる。

## 組む画面

いつも見えるもの（上の帯）: 部隊の名前（取っておいていない変更があれば「*」）と「名前変更」、軍、コスト / コスト上限（宝石の目盛り。超えたら赤）、駒の数 / 上限。
出せない理由（`Deck.problems()` を文にしたもの。出せるなら何も出さない）は、下の「編成完了」の左に出す（上の帯は名前と数で埋まり、理由が切れるため）。

| 場所 | 中身と操作 |
| --- | --- |
| 左: 雇える兵 | 決まりの、その軍のロスターの札（名前、役割、コスト、能力値。回復役は「HP 20　回復 15　攻撃 4　移動 4　射程 1」の 5 項目を、ほかの駒の 4 項目と同じ行の幅に詰める）。押すと部隊の最後に入り、その駒が選ばれる。上限に達したら押せない。下にその軍の必殺技 |
| 左の下: 軍略 | 対戦用の部隊と、軍略を教わったストーリー用の部隊（`docs/troop-traits.md`。まだ教わっていない札は押せない）。決まった大きさの欄（`TRAIT_BOX_HEIGHT`）に、見出し「軍略」と札 3 枚（印と名前）。押した札がその軍略（もう一度押しても外れない。選ばないことはできない）。下に、選んだ軍略の文（条件 → 効果の 1 文。効果の所だけ目立つ色。2 行まで。札に乗せている間は、その札のもの）。誓いを選んだ部隊だけ、部隊の行の「外す」の左に「誓い」のボタン（決まった幅。結んでいれば「誓い 1」「誓い 2」）と、部隊の並びの下に誓いの組の 1 行 |
| 中: 部隊 | 将と、雇った駒の札（名前、コスト、持ち物）。押して選ぶ（もう一度押すとやめる）。「外す」で外す。持ち物の文が収まらなければ「…」で切り、マウスを乗せると全部出す |
| 右の上: 駒の札 | マウスを乗せている雇える駒か、選んでいる部隊の駒: 役割、コスト、役割の説明、能力値（持ち物込みの値も）、スキル（クールダウンと説明）、進化先 2 つ（能力値の増減と特性）。ほかの軍の駒（ストーリーで解放したもの）は、先頭に「FANTASY の駒（この部隊では MILITARY として戦う）」。どちらも無ければ出さない |
| 右の下: 持ち物 | 札と別の枠。**右の駒の札と持ち物の枠は、いつも同じ大きさで場所を取る**（`docs/ui-theme.md` の「枠の大きさ」）: 部隊の駒を選んでいない間は持ち物の枠の中身を、駒を選びも乗せもしていない間は駒の札の中身を、透かすだけ（枠は出したまま）（出たり消えたりで、札が伸び縮みしない）。並ぶ持ち物が多い（ストーリーで増えた）ときは、右上の駒の札が `DETAIL_MIN_HEIGHT` を割らないよう、持ち物の欄の中で縦に送る（`_fit_equip`。欄の高さは画面の高さから決め直すので、窓を縦に広げてから縮めても元に戻る。自動の対戦が、どの物語でも、窓を広げて縮めても駒の札が縮まないことを確かめる）。選んだまま雇える駒に乗せても消さない（消すと札の大きさが変わって揺れる。自動の対戦が、乗せても選び替えても部品が動かないことを確かめる）。見出しに持っている数 / 上限。並ぶのは決まりが並べる持ち物（`DeckRules.shown_items()`。対戦は持たせられるものだけ、ストーリーはその物語でいずれ持たせられるもの）。持ち物ごとに、印（`game/item_icon.gd`）、名前、コスト、効果（能力値、特性の短い名前、持てる駒の限り「後衛専用」「前衛以外」）、持っている数、−（外す）と＋（持たせる）。上限に達したら＋は押せない。決まりが許さない持ち物（ストーリーで、まだ解放していない）は、灰色で効果の行の頭に「未解放」。選んでいる駒が持てない持ち物は灰色で、重ねられない持ち物の 2 個目は効果の行の頭に「1 体 1 個まで」、役割の限りは効果の文の括弧（「後衛専用」など）が理由になる。どちらも＋は押せない（持っていれば −で外せる）。理由を名前の行に足さないのは、長い名前（「試作ジェットパック」）で「…」に切れて読めなくなるため。名前・コスト・理由は切れない（自動の対戦が、どの物語・駒・持ち物でも確かめる）。効果の文は欄の幅で「…」で切り、行にマウスを乗せると、効果の全文と特性の説明を出す |

- 誓いを結ぶ（軍略が誓いの部隊）: 「誓い」を押すと、その駒の結ぶ相手を選び始め（部隊の並びの下に「誓い: 〜の相手を選択」）、ほかの駒の「誓い」を押すと 2 体が結ばれる。同じ駒をもう一度押すとやめる。
  結んだ駒の「誓い」を押すと、ほどける。駒を外すと、その誓いもほどける。組は 2 つまで（`Traits.MAX_OATHS`）。軍略を替えても、結んだ組は残る（誓いに戻すと、また効く）。
- 軍は、組む画面では変えない（新規編成のときに選ぶ）。
- コスト上限を超える駒や持ち物も足せる（外せば戻る）。理由に出る。
- **出せない部隊は「編成完了」できない**（ボタンが押せない。理由はその左）。
- 「編成完了」で取っておいて一覧へ戻り、その部隊を選ぶ。
- 取っておかずに一覧へ戻る（「戻る」、右クリック、Esc）ときは、変更があれば確かめる（「変更を破棄しますか？」）。
  タイトルへ戻る・ゲーム終了（システムメニュー）ときも、変更があれば確かめる（場面の `in_progress` と `losing_note`）。

## 操作

- マウスだけで使える（名前を変えるときだけ、文字を打つ）。
- 右クリックと Esc は「戻す」: 確かめ・名前の窓 → 誓いの相手選び → 駒の選択 → 組む画面・軍の選択（一覧へ）→ 一覧（戻り先へ）。
- 文は `game/text_wrap.gd` で折り返す。駒の札の欄は、長ければ欄の中で送れる。

## 対戦設定で選ぶ

- 対戦設定（`docs/battle-view.md` の「対戦設定」）で、どちらのプレイヤーも、軍を選んだあと「部隊」を選ぶ（人の行も CPU の行も、人どうしでも同じ欄・同じ選び方）。
- 選択肢は、既定の編成（`MatchSetup.default_deck`。CPU の行では「CPU の編成」と呼ぶ。中身は同じ）、「ランダム編成」（`docs/match-setup.md` の「ランダム編成」）、
  対戦の決まりで組んだ、その軍の取っておいた部隊。出せない部隊は「出撃不可: 理由」と書き、選べない。
- 取っておいた部隊を選んでから軍を変えると、既定の編成に戻る（ランダム編成は、ランダム編成のまま）。
- 選んだ部隊の中身は、パネルには書かない。「編成確認」で、駒ごとの札にして開く（`docs/battle-view.md` の「対戦設定」）。
- 対戦設定を開くたびに、一覧に合わせ直す: 選んでいた部隊が消えた・出せなくなったら既定の編成に戻し、組み直していれば新しい中身にする。
- 対戦設定そのもの（選んだ部隊を含む）は、アプリが起動している間だけ残る（ファイルには書かない）。

## ストーリー用の部隊の読み方

- ストーリーの決まりは進み具合で変わるので、`DeckRules.by_id` は知らない。取っておいた部隊の一覧（`deck_library.gd`）は、
  決まりを引くもの（`rules_lookup`）を外から受け取る。アプリ（`app_context.gd` の `rules_of`）が、物語の決まりの名前（`story` など）ならその物語のいまの進み具合の決まりを返すものを入れる。
- 起動したときは、ストーリーの進み具合を先に読み、そのあと部隊を読む。話をクリアして雇える駒が増えたら、部隊の決まりを引き直す（`refresh_rules`）。
- まだ解放していない駒を含むストーリー用の部隊は、「出撃不可」（この軍で雇えない駒あり）で一覧に残り、解放すると出せるようになる。
- 決まりを引くものを渡さない一覧（検査など）では、`story` は知らない決まり（理由つきで、対戦の決まりとして読む）。

## 取っておく形式

`game/save_store.gd` の仕組みで、対戦用の部隊は `user://decks.json` に置く（`{"name": "decks", "version": 版, "data": 中身}`）。
ストーリー用の部隊（決まりが物語の決まりのもの）は、いまのセーブデータ（スロット）のまとまり `decks` に、同じ形で置く（`docs/save-slots.md`）。
どちらに書くかは部隊の決まりで決め（`DeckLibrary.is_slot_rules`）、部隊を変えた側のファイルだけを書く。`next_id` は両方に書く。
いまの版は 1（`deck_library.gd` の `FORMAT_VERSION`）。中身:

```json
{
  "next_id": 3,
  "decks": [
    {
      "id": "1",
      "name": "狙撃の布陣",
      "rules": "versus",
      "army": "MILITARY",
      "units": [
        {"kind": "SHIELD_TROOPER", "equipment": ["IRON_SHIELD", "IRON_SHIELD"]},
        {"kind": "SNIPER", "equipment": []}
      ]
    }
  ]
}
```

| 値 | 中身 |
| --- | --- |
| `next_id` | 次に付ける id の番号 |
| `id` | 一覧の中で変わらない名前（文字列） |
| `name` | 部隊の名前（長さの上限は `MAX_NAME_LENGTH`） |
| `rules` | どの決まりで組んだか（`DeckRules.id`。`versus` か、物語の決まりの名前（MILITARY の物語は `story`））。対戦用とストーリー用（物語ごと）を分ける |
| `army` | 軍（`UnitKind.Army` の名前） |
| `trait` | （あれば）軍略（`docs/troop-traits.md`）。`Traits.Id` の名前の小文字（`focus` など）。無いか、その軍の軍略でなければ、軍の既定（理由には書かない） |
| `oaths` | （あれば）誓いの組（軍略の誓い。`docs/troop-traits.md`）。`units` の添字の組の列（`[[0, 1], [2, 4]]`）。読めない組と結べない組は捨てる（部隊は出せるので、理由には書かない） |
| `units` | 雇った駒の並び（初期位置を決めないときの、おまかせの置き方の順にもなる）。知らない欄（`placement` など）は読み飛ばす（書き直すと消える）。`kind` は `UnitKind.Id` の名前、`equipment` は `Equipment.Id` の名前の列（持たせた順） |
| `load_issues` | （あれば）読み込みで外した・読み替えたものの理由。書き直しても残り、組み直して取っておくと消える（それまで出せない） |

- 駒・持ち物・軍は、列挙の**名前**で書く（番号は、列挙に足したり並べ替えたりすると変わるため）。将は書かない。
- 形を変えたら版を上げ、`DeckLibrary._migrate` に読み替えを足す。

### 読めないとき

起動は止めない。読めたぶんだけ一覧に残す。

| 中身 | 扱い |
| --- | --- |
| ファイルが無い・JSON でない・形が違う（`data` が辞書でない、`decks` が列でない） | 空の一覧（`save_store.gd`） |
| 部隊の形でない（辞書でない）もの | 読み飛ばす |
| 知らない駒・持ち物 | 外して読み、「知らない駒（名前）を外した」を理由に付ける（取っておき直すまで出せない） |
| 知らない決まり | 対戦の決まりとして読み、「知らない決まり（名前）で組んである」を理由に付ける |
| 読めない軍 | 軍なしとして読み、理由に付ける（駒は「この軍で雇えない駒あり」になる） |
| 名前・id が無い、id が重なる | 「名前の無い部隊」、新しい id を付ける |
| 検査を通らない（コスト上限を超えた、多すぎる、など） | そのまま読み、`Deck.problems()` の理由を出す |
| 新しい版 | 版 1 と同じ形として読めるところを読む。知らない欄は残し、書くときも読んだ版で書く（`docs/save-slots.md` の「版と、知らない欄」） |

- 検査・自動の対戦・スクリーンショットでは、ファイルを読み書きしない（`DeckLibrary.store` が `null`）。
