# 部隊編成（画面と、取っておく部隊）

コード: `game/deck_screen.gd`（編成の場面）、`game/deck_library.gd`（取っておく部隊の一覧と、ファイルの読み書き）、
`game/deck_text.gd`（出せない理由、駒と持ち物の中身の文）、`game/unit_card.gd`（駒の札）、`game/deck_preview.gd`（編成確認）、`game/match_choice.gd` と `game/match_setup_panel.gd`（対戦設定で選ぶ）。
テスト: `tests/game/test_deck_library.gd`、`tests/game/test_match_choice.gd`、`tests/game/test_match_setup_panel.gd`、自動の対戦（`game/autoplay.gd` の `_visit_decks`）。

編成のルール（軍、ロスター、持ち物、コスト上限、配置）は `docs/player-loadout.md`、検査と編成の決まりは `docs/deck-building.md`。

## 流れ

- 対戦設定の「部隊編成」と、ストーリーの出撃準備の「部隊編成」から開く（どちらも流れに差し込む寄り道。タイトルからは開かない）。部隊は、名前を付けて、いくつでも取っておける。
- 一覧は、**対戦用**か**物語ごとのストーリー用**の、1 つの決まりの部隊だけを出す。対戦設定から開けば対戦用、出撃準備から開けばその物語のストーリー用。一覧に並ぶのも、「新規編成」で組むのも、その決まりの部隊だけ。
  一覧の見出しの横に、決まりの名前（対戦用は「対戦用」、ストーリー用は物語の名前）を出す。切り替えのボタンは置かない（決まりは開いたもとが決める）。
  流れの外で置いたとき（スクリーンショットの道具など）は対戦用で始まり、道具が `set_mode` で替える。
  対戦用の部隊がストーリーに、ストーリー用の部隊が対戦やほかの物語に混ざることは無い（決まりの名前で分ける。`docs/deck-building.md`）。
- 対戦用の部隊は、対戦設定で選んで出撃する（下の「対戦設定で選ぶ」）。ストーリー用の部隊は、ストーリーの出撃準備で選ぶ（`docs/story.md`）。
- 組む画面の決まり（`DeckRules`）は、一覧の決まりと同じ（`deck_screen.gd` の `rules`）。対戦用は対戦の決まり、ストーリー用は、その物語のいまの進み具合の決まり
  （軍は物語の軍だけ。雇える駒は、いま解放した駒だけ）。選べない軍の札は出さない。
- 寄り道（`docs/scene-flow.md` の「流れ」）では、いちばん外の戻る（ボタン・右クリック・Esc）は
  「出撃準備へ戻る」か「対戦設定へ戻る」。開いたときは、もとの画面で選んでいる部隊を一覧で選んでおく。
  寄り道の間に最後に取っておいた部隊は、戻った出撃準備（対戦設定なら、「部隊編成」を押した行）で選ばれている。

## 見た目の決まり

- 画面の文は短い名前のボタンと見出しにする（説明の文で操作を教えない）。スキルや必殺技など、中身の説明は読める場所に出す。
- 駒は**札**で見せる（`game/unit_card.gd`。名前、役割、コスト、能力値、持ち物）。一覧の中身、対戦設定の「編成確認」が同じ札を使う。
- 画面の上に `TOP_ROOM` だけ空け、右上のシステムメニューのボタンを、ほかの場面と同じく背景の上に置く（枠に埋もれないように）。
- 枠・札・ボタンの見た目は UI のテーマ（`docs/ui-theme.md`）。札の形のボタン（雇える駒、部隊の駒、一覧の部隊、軍）はカード、「編成完了」はいちばん大事なボタン、「削除」は危険なボタン。

## 一覧

- 取っておいた部隊を、取っておいた順に並べる。1 行に、名前、軍、駒の数、コスト / コスト上限。出せない部隊は行を赤くし「出撃不可」。
- 部隊が無ければ「編成なし」とだけ出す。下に「新規編成」。
- 押して選ぶと、右に名前、軍・駒の数・コスト、駒の札（将から並びの順。多ければ欄の中で送る）、出せない理由、操作のボタンが出る。
  - 「編集」: 組む画面で開く。「編成完了」を押すまで、一覧の部隊は変わらない（`Deck.copy()` を直す）。
  - 「複製」: すぐ後ろに「〜 の写し」を足す。
  - 「名前変更」: 名前を入れる窓（長さの上限は `deck_library.gd` の `MAX_NAME_LENGTH`。空なら変えない）。
  - 「削除」: 確かめてから消す（元に戻せない）。
- 「新規編成」: **まず軍を選ぶ**（軍の札: 名前、コスト上限、雇える駒、必殺技）。選ぶと、その軍の空の部隊（名前は「部隊 N」）を組む画面で開く。
  選べる軍が 1 つ（ストーリー用）なら、選ばずにその軍で開く。「戻る」（右クリック・Esc でも）で一覧へ。
- **出せない部隊も一覧に残る**（決まりが変わった、ファイルを手で書き換えた、知らない駒がある）。組み直して「編成完了」すれば、出せるようになる。

## 組む画面

いつも見えるもの（上の帯）: 部隊の名前（取っておいていない変更があれば「*」）と「名前変更」、軍、コスト / コスト上限（棒。超えたら赤）、駒の数 / 上限。
出せない理由（`Deck.problems()` を文にしたもの。出せるなら何も出さない）は、下の「編成完了」の左に出す（上の帯は名前と数で埋まり、理由が切れるため）。

| 場所 | 中身と操作 |
| --- | --- |
| 左: 雇える駒 | 決まりの、その軍のロスターの札（名前、役割、コスト、能力値）。押すと部隊の最後に入り、その駒が選ばれる。上限に達したら押せない。下にその軍の必殺技 |
| 中: 部隊 | 将と、雇った駒の札（名前、コスト、持ち物）。押して選ぶ（もう一度押すとやめる）。▲▼ で並べ替え、「外す」で外す。持ち物の文が収まらなければ「…」で切り、マウスを乗せると全部出す |
| 中の下: 配置 | 本陣と、その前の 2 行。並びの何番目がどこに置かれるか（`Deployment.open_field_slots`）。選んでいる駒は明るく |
| 右の上: 駒の札 | マウスを乗せている雇える駒か、選んでいる部隊の駒: 役割、コスト、役割の説明、能力値（持ち物込みの値も）、スキル（クールダウンと説明）、進化先 2 つ（能力値の増減と特性）。ほかの軍の駒（ストーリーで解放したもの）は、先頭に「FANTASY の駒（この部隊では MILITARY として戦う）」。どちらも無ければ出さない |
| 右の下: 持ち物 | 部隊の駒を選んでいるときだけ、札と別の枠に出す。見出しに持っている数 / 上限。並ぶのは決まりが並べる持ち物（`DeckRules.shown_items()`。対戦は持たせられるものだけ、ストーリーはその物語でいずれ持たせられるもの）。持ち物ごとに、印（`game/item_icon.gd`）、名前、コスト、効果（能力値、特性の短い名前、持てる駒の限り「後衛専用」「前衛以外」）、持っている数、−（外す）と＋（持たせる）。上限に達したら＋は押せない。決まりが許さない持ち物（ストーリーで、まだ解放していない）は、灰色で効果の行の頭に「未解放」。選んでいる駒が持てない持ち物は灰色で、重ねられない持ち物の 2 個目は効果の行の頭に「1 体 1 個まで」、役割の限りは効果の文の括弧（「後衛専用」など）が理由になる。どちらも＋は押せない（持っていれば −で外せる）。理由を名前の行に足さないのは、長い名前（「試作ジェットパック」）で「…」に切れて読めなくなるため。名前・コスト・理由は切れない（自動の対戦が、どの物語・駒・持ち物でも確かめる）。効果の文は欄の幅で「…」で切り、行にマウスを乗せると、効果の全文と特性の説明を出す |

- 軍は、組む画面では変えない（新規編成のときに選ぶ）。
- コスト上限を超える駒や持ち物も足せる（外せば戻る）。理由に出る。
- **出せない部隊は「編成完了」できない**（ボタンが押せない。理由はその左）。
- 「編成完了」で取っておいて一覧へ戻り、その部隊を選ぶ。
- 取っておかずに一覧へ戻る（「戻る」、右クリック、Esc）ときは、変更があれば確かめる（「変更を破棄しますか？」）。
  タイトルへ戻る・ゲーム終了（システムメニュー）ときも、変更があれば確かめる（場面の `in_progress` と `losing_note`）。

## 操作

- マウスだけで使える（名前を変えるときだけ、文字を打つ）。
- 右クリックと Esc は「戻す」: 確かめ・名前の窓 → 駒の選択 → 組む画面・軍の選択（一覧へ）→ 一覧（戻り先へ）。
- 文は `game/text_wrap.gd` で折り返す。駒の札の欄は、長ければ欄の中で送れる。

## 対戦設定で選ぶ

- 対戦設定（`docs/battle-view.md` の「対戦設定」）で、人が動かすプレイヤーは、軍を選んだあと「部隊」を選ぶ。
  人どうしなら、両方が選ぶ。CPU は、軍ごとの CPU の編成（`CpuDeck`）。
- 選択肢は、既定の編成（`MatchSetup.default_deck`）と、対戦の決まりで組んだ、その軍の取っておいた部隊。出せない部隊は「出撃不可: 理由」と書き、選べない。
- 部隊を選んでから軍を変えると、既定の編成に戻る。
- 選んだ部隊の中身は、パネルには書かない。「編成確認」で、駒ごとの札にして開く（`docs/battle-view.md` の「対戦設定」）。
- 対戦設定を開くたびに、一覧に合わせ直す: 選んでいた部隊が消えた・出せなくなったら既定の編成に戻し、組み直していれば新しい中身にする。
- 対戦設定そのもの（選んだ部隊を含む）は、アプリが起動している間だけ残る（ファイルには書かない）。

## ストーリー用の部隊の読み方

- ストーリーの決まりは進み具合で変わるので、`DeckRules.by_id` は知らない。取っておいた部隊の一覧（`deck_library.gd`）は、
  決まりを引くもの（`rules_lookup`）を外から受け取る。アプリ（`app_context.gd` の `rules_of`）が、物語の決まりの名前（`story` など）ならその物語のいまの進み具合の決まりを返すものを入れる。
- 起動したときは、ストーリーの進み具合を先に読み、そのあと部隊を読む。話をクリアして雇える駒が増えたら、部隊の決まりを引き直す（`refresh_rules`）。
- まだ解放していない駒を含むストーリー用の部隊は、「出撃不可」（この軍で雇えない駒あり）で一覧に残り、解放すると出せるようになる。
- 決まりを引くものを渡さない一覧（検査など）では、`story` は知らない決まり（理由つきで、対戦の決まりとして読む）。

## 取っておく形式

`game/save_store.gd` の仕組みで、`user://decks.json` に置く（`{"name": "decks", "version": 版, "data": 中身}`）。
いまの版は 1（`deck_library.gd` の `FORMAT_VERSION`）。中身:

```json
{
  "next_id": 3,
  "decks": [
    {
      "id": "1",
      "name": "狙撃の布陣",
      "rules": "versus",
      "army": "MILITARY",
      "units": [
        {"kind": "SHIELD_TROOPER", "equipment": ["IRON_SHIELD", "IRON_SHIELD"]},
        {"kind": "SNIPER", "equipment": []}
      ]
    }
  ]
}
```

| 値 | 中身 |
| --- | --- |
| `next_id` | 次に付ける id の番号 |
| `id` | 一覧の中で変わらない名前（文字列） |
| `name` | 部隊の名前（長さの上限は `MAX_NAME_LENGTH`） |
| `rules` | どの決まりで組んだか（`DeckRules.id`。`versus` か、物語の決まりの名前（MILITARY の物語は `story`））。対戦用とストーリー用（物語ごと）を分ける |
| `army` | 軍（`UnitKind.Army` の名前） |
| `units` | 雇った駒の並び（配置の順）。`kind` は `UnitKind.Id` の名前、`equipment` は `Equipment.Id` の名前の列（持たせた順） |
| `load_issues` | （あれば）読み込みで外した・読み替えたものの理由。書き直しても残り、組み直して取っておくと消える（それまで出せない） |

- 駒・持ち物・軍は、列挙の**名前**で書く（番号は、列挙に足したり並べ替えたりすると変わるため）。将は書かない。
- 形を変えたら版を上げ、`DeckLibrary._migrate` に読み替えを足す。

### 読めないとき

起動は止めない。読めたぶんだけ一覧に残す。

| 中身 | 扱い |
| --- | --- |
| ファイルが無い・JSON でない・形が違う（`data` が辞書でない、`decks` が列でない） | 空の一覧（`save_store.gd`） |
| 部隊の形でない（辞書でない）もの | 読み飛ばす |
| 知らない駒・持ち物 | 外して読み、「知らない駒（名前）を外した」を理由に付ける（取っておき直すまで出せない） |
| 知らない決まり | 対戦の決まりとして読み、「知らない決まり（名前）で組んである」を理由に付ける |
| 読めない軍 | 軍なしとして読み、理由に付ける（駒は「この軍で雇えない駒あり」になる） |
| 名前・id が無い、id が重なる | 「名前の無い部隊」、新しい id を付ける |
| 検査を通らない（コスト上限を超えた、多すぎる、など） | そのまま読み、`Deck.problems()` の理由を出す |
| 新しい版 | 版 1 と同じ形として読めるところを読む（書くときは版 1 で書く） |

- 検査・自動の対戦・スクリーンショットでは、ファイルを読み書きしない（`DeckLibrary.store` が `null`）。
