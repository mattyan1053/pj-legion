# 部隊の編成（画面と、取っておく部隊）

コード: `game/deck_screen.gd`（編成の場面）、`game/deck_library.gd`（取っておく部隊の一覧と、ファイルの読み書き）、
`game/deck_text.gd`（出せない理由、駒と装備の中身の文）、`game/match_choice.gd` と `game/match_setup_panel.gd`（対戦の設定で選ぶ）。
テスト: `tests/game/test_deck_library.gd`、`tests/game/test_match_choice.gd`、自動の対戦（`game/autoplay.gd` の `_visit_decks`）。

編成のルール（軍、ロスター、装備、予算、配置）は `docs/player-loadout.md`、検査と編成の決まりは `docs/deck-building.md`。

## 流れ

- タイトルの「部隊の編成」で開く。部隊は、名前を付けて、いくつでも取っておける。
- 取っておいた部隊は、対戦の設定で選んで出撃する（下の「対戦の設定で選ぶ」）。
- 組む画面は、決まり（`DeckRules`）を外から受け取る（`deck_screen.gd` の `rules`）。いまは対戦の決まりだけ。
  後で、ストーリーの進み具合に応じた決まりを渡す（Issue #49）。

## 一覧

- 取っておいた部隊を、取っておいた順に並べる。1 行に、名前、軍、駒の数、コスト / 予算、出撃できるか（出せないなら最初の理由）。
- 押して選ぶと、右に中身（決まり、軍、コスト、駒と装備の並び、出せない理由の全部）と、操作のボタンが出る。
  - 「組み直す」: 組む画面で開く。取っておくまで、一覧の部隊は変わらない（`Deck.copy()` を直す）。
  - 「写す」: すぐ後ろに「〜 の写し」を足す。
  - 「名前を変える」: 名前を入れる窓（20 文字まで。空なら変えない）。
  - 「消す」: 確かめてから消す（元に戻せない）。
- 「新しく組む」: 空の部隊（決まりの最初の軍。名前は「部隊 N」）を組む画面で開く。
- **出せない部隊も一覧に残る**（決まりが変わった、ファイルを手で書き換えた、知らない駒がある）。行を赤くし、理由を出す。
  組み直して取っておけば、出せるようになる。

## 組む画面

いつも見えるもの（上の帯）: 部隊の名前（取っておいていない変更があれば「変更あり」）、軍、コスト / 予算（棒。超えたら赤）、駒の数 / 上限、
出撃できるか、出せない理由（`Deck.problems()` を文にしたもの）。

| 場所 | 中身と操作 |
| --- | --- |
| 左: 雇える駒 | 決まりの、その軍のロスター。名前、役割、コスト、能力値。押すと部隊の最後に入り、その駒が選ばれる。上限に達したら押せない。その軍の必殺技の説明も出す |
| 中: 部隊 | 将（自動で加わる）と、雇った駒の並び。押して選ぶ（もう一度押すとやめる）。▲▼ で並べ替え、「外す」で外す。装備の文が行に収まらなければ「…」で切り、マウスを乗せると全部出す |
| 中の下: 配置の図 | 本陣と、その前の 2 行。並びの何番目がどこに置かれるか（`Deployment.open_field_slots`。入れないマスは飛ばす、と書く）。選んでいる駒は明るく |
| 右: 駒の中身 | マウスを乗せている雇える駒か、選んでいる部隊の駒の中身: 役割とその説明、コスト、能力値（装備込みの値も）、スキル（クールダウンと説明）、進化先 2 つ（能力値の増減と特性） |
| 右の下: 装備 | 部隊の駒を選んでいるときだけ。装備ごとに、コスト、効果、持っている数、−（外す）と＋（持たせる）。1 体の上限に達したら＋は押せない |

- 軍を変えると、駒は外れる（雇える駒が違う）。駒がいれば確かめる。
- 予算を超える駒や装備も足せる（外せば戻る）。理由に出る。
- **出せない部隊は取っておけない。** 「取っておく」が押せず、「出せない部隊は取っておけない」と出る（理由は上の帯）。
- 取っておくと一覧へ戻り、その部隊を選ぶ。
- 取っておかずに一覧へ戻る（「一覧へ戻る」、右クリック、Esc）ときは、変更があれば確かめる。
  タイトルへ戻る・ゲームを終える（システムメニュー）ときも、変更があれば確かめる（場面の `in_progress`）。

## 操作

- マウスだけで使える（名前を変えるときだけ、文字を打つ）。
- 右クリックと Esc は「戻す」: 確かめ・名前の窓 → 駒の選択 → 組む画面（一覧へ）→ 一覧（タイトルへ）。
- 文は `game/text_wrap.gd` で折り返す。駒の中身の欄は、長ければ欄の中で送れる。

## 対戦の設定で選ぶ

- 対戦の設定（`docs/battle-view.md` の「対戦の設定」）で、人が動かすプレイヤーは、軍を選んだあと「部隊」を選ぶ。
  人どうしなら、両方が選ぶ。CPU は、軍ごとの CPU の編成（`CpuDeck`）。
- 選択肢は、既定の編成（`MatchSetup.default_deck`）と、対戦の決まりで組んだ、その軍の取っておいた部隊。出せない部隊は「出せない: 理由」と書き、選べない。
- 部隊を選んでから軍を変えると、既定の編成に戻る。
- 対戦の設定を開くたびに、一覧に合わせ直す: 選んでいた部隊が消えた・出せなくなったら既定の編成に戻し、組み直していれば新しい中身にする。
- 対戦の設定そのもの（選んだ部隊を含む）は、アプリが起動している間だけ残る（ファイルには書かない）。

## 取っておく形式

`game/save_store.gd` の仕組みで、`user://decks.json` に置く（`{"name": "decks", "version": 版, "data": 中身}`）。
いまの版は 1（`deck_library.gd` の `FORMAT_VERSION`）。中身:

```json
{
  "next_id": 3,
  "decks": [
    {
      "id": "1",
      "name": "狙撃の布陣",
      "rules": "versus",
      "army": "MILITARY",
      "units": [
        {"kind": "SHIELD_TROOPER", "equipment": ["IRON_SHIELD", "IRON_SHIELD"]},
        {"kind": "SNIPER", "equipment": []}
      ]
    }
  ]
}
```

| 値 | 中身 |
| --- | --- |
| `next_id` | 次に付ける id の番号 |
| `id` | 一覧の中で変わらない名前（文字列） |
| `name` | 部隊の名前（20 文字まで） |
| `rules` | どの決まりで組んだか（`DeckRules.id`。いまは `versus` だけ）。対戦用とストーリー用を分ける |
| `army` | 軍（`UnitKind.Army` の名前） |
| `units` | 雇った駒の並び（配置の順）。`kind` は `UnitKind.Id` の名前、`equipment` は `Equipment.Id` の名前の列（持たせた順） |
| `load_issues` | （あれば）読み込みで外した・読み替えたものの理由。書き直しても残り、組み直して取っておくと消える（それまで出せない） |

- 駒・装備・軍は、列挙の**名前**で書く（番号は、列挙に足したり並べ替えたりすると変わるため）。将は書かない。
- 形を変えたら版を上げ、`DeckLibrary._migrate` に読み替えを足す。

### 読めないとき

起動は止めない。読めたぶんだけ一覧に残す。

| 中身 | 扱い |
| --- | --- |
| ファイルが無い・JSON でない・形が違う（`data` が辞書でない、`decks` が列でない） | 空の一覧（`save_store.gd`） |
| 部隊の形でない（辞書でない）もの | 読み飛ばす |
| 知らない駒・装備 | 外して読み、「知らない駒（名前）を外した」を理由に付ける（取っておき直すまで出せない） |
| 知らない決まり | 対戦の決まりとして読み、「知らない決まり（名前）で組んである」を理由に付ける |
| 読めない軍 | 軍なしとして読み、理由に付ける（駒は「雇えない駒」になる） |
| 名前・id が無い、id が重なる | 「名前の無い部隊」、新しい id を付ける |
| 検査を通らない（予算を超えた、多すぎる、など） | そのまま読み、`Deck.problems()` の理由を出す |
| 新しい版 | 版 1 と同じ形として読めるところを読む（書くときは版 1 で書く） |

- 検査・自動の対戦・スクリーンショットでは、ファイルを読み書きしない（`DeckLibrary.store` が `null`）。
