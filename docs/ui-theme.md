# UI のテーマ

UI の見た目（ボタン、板、帯、札、文字、色）は、1 つのテーマにまとめてある。画面の側は、色や枠を直に書かず、ここを引く。

- 色: `game/ui_palette.gd`（役割ごとの色に名前を付けて、1 か所に置く）
- テーマ: `game/ui_theme.gd`（Godot の `Theme`。色は上だけを引いて、スクリプトで組む。絵は使わない）
- 文字: `assets/fonts/zen/`（出どころとライセンスは、その中の `README.md`）
- 小さな動き: `game/ui_feel.gd`（下の「小さな動き」）

テスト: `tests/game/test_ui_theme.gd`（文字と地の濃淡の差）、`tests/game/test_ui_feel.gd`、`tests/game/test_steady_frames.gd`（枠の大きさ）。

アプリの入口（`app.gd`）が、起動してすぐ `UiTheme.install()` で Godot の既定のテーマに重ねる。
だから、ふつうに作った `Button`、`PanelContainer`、`Label`、`HSlider`、ツールチップなどは、何もしなくてもこの見た目になる。

## 方向

夜の藍の地に、くすんだ真鍮の縁と、生成りの文字。

- 盤（明るい低ポリ）の上に重ねるので、UI の地は彩度を落とした暗い藍にして、盤の色（範囲の青・黄・赤、足元の印、HP の棒）とぶつけない。
- 色を持つのは「意味のある所」だけ（強調の金、危険の朱、陣営の青と赤、勝ち方の金）。飾りのための色は足さない。
- 文字は、本文が角ゴシック（小さくても読める）、題字と画面の見出しだけ明朝（ファンタジー寄りの音と絵柄に合わせる）。

## 色の役割

`Palette.<名前>` で引く。値はコードにある。

| 役割 | 名前 | 使う所 |
| --- | --- | --- |
| 地 | `INK` | 沈んだ所（入力欄、スライダーや棒の溝） |
| 地 | `PANEL`（`OVERLAY` / `SOLID`） | 板。盤の上に重ねるものは半透明の `OVERLAY`、ダイアログはほぼ不透明の `SOLID` |
| 地 | `RAISED` / `RAISED_HOVER` | 浮いた所（ボタン、カード）と、マウスが乗ったとき |
| 地 | `WASH` | 板の上の薄い塗り（マウスが乗った行、区切り） |
| 地 | `SHADE` | ダイアログの後ろを沈める幕 |
| 地 | `SHADOW` | ダイアログの板の影 |
| 枠 | `BORDER` / `BORDER_BRIGHT` | ふつうの枠と、目立たせる枠（乗った、選ばれている） |
| 文字 | `TEXT` / `TEXT_DIM` / `TEXT_OFF` | 本文、補足、押せない |
| 文字 | `TEXT_ON_GOLD` | 金の地の上（いちばん大事なボタン） |
| 文字 | `OUTLINE` | 文字の縁取り |
| 強調 | `ACCENT` | 見出し、選んでいるもの、予測、クリア済み |
| 強調 | `GOLD` / `GOLD_HOVER` / `GOLD_PRESSED` | いちばん大事なボタンの地、棒の中身 |
| 強調 | `CHOSEN` | 選ばれている（押し込まれたままの）ボタンの地 |
| 知らせ | `GOOD` / `WARN` / `DANGER` / `INFO` | 良い、注意、危険・だめ、新しい・状態 |
| 危険 | `DANGER_FILL` | 危険なボタンの地 |
| 進める | `GO` / `GO_READY` | ターン終了のボタンの地（未行動の駒が残っている / いない） |
| 陣営 | `TEAM_BLUE` / `TEAM_RED` / `TEAM_NEUTRAL` | 盤の駒と同じ色。文字にするときは `team_text()` で明るくする |
| 国 | `NATION_MILITARY` / `NATION_FANTASY` | 物語のカードの帯と紋、話の一覧の飾りの線（機械の国ベルク連邦の琥珀、魔法の国リュエル騎士領の菫。タイトルの空の左右と同じ） |
| 勝ち方 | `GOAL` / `GOAL_BORDER` / `GOAL_URGENT` | 勝ち方の札（ふつうと、最後のターン） |
| HP | `HP_HIGH` / `HP_MID` / `HP_LOW`（`hp(割合)`） | HP の棒 |

**盤の上の色（移動範囲、脅威範囲、足元の印など。`battle_screen.gd`）は、ここに入れない。** あれは盤の情報で、UI の色ではない。

文字と地の濃淡の差（コントラスト比）は、`tests/game/test_ui_theme.gd` が下限を確かめる（本文 4.5 以上、押せない文字 3 以上。
半透明の板は、後ろが真っ白でも本文が読める）。色を足したり変えたりしたら、そこに通す。

## 新しい画面を作るとき

何もしなければ「ふつう」になる。違う種類にするときは、`theme_type_variation` に `UiTheme` の定数を入れる。

    const UiTheme := preload("res://game/ui_theme.gd")
    button.theme_type_variation = UiTheme.BUTTON_PRIMARY

| 部品 | 種類 | いつ使う |
| --- | --- | --- |
| `Button` | （ふつう） | たいていのボタン。`toggle_mode` で押し込まれたままのものは、金の縁と濃い金の地で「選ばれている」になる |
| `Button` | `BUTTON_PRIMARY` | その画面で次に押す、いちばん大事なボタン（「対戦開始」「出撃」「次へ」）。**1 画面に 1 つ** |
| `Button` | `BUTTON_DANGER` | 取り返しのつかないこと（「削除」「破棄」、対戦を終える） |
| `Button` | `BUTTON_ROW` | 板の上に並ぶ行（一覧の行、メニューの項目）。枠が無く、乗ると薄く塗る |
| `Button` | `BUTTON_MENU` | タイトルのメニュー。景色の上に直に並ぶ、角を落とした大きな札（景色が透ける暗い地。乗ると金の縁と金の文字） |
| `Button` | `BUTTON_GHOST` | 控えめなボタン（薄い地と縁だけ）。大事なボタンの横に並ぶ、たまに使う操作（対戦の「おまかせ」「早送り」「スキップ」） |
| `Button` | `BUTTON_ACTION` | 駒のそばのメニューの項目。板の上の行で、乗ると左に金の線と薄い金の塗り |
| `Button` | `BUTTON_CARD` | カード（マップ、物語、話）。乗ると金の縁 |
| `PanelContainer` | （ふつう） | 盤の上に重ねる板（情報の枠、案内）。半透明 |
| `PanelContainer` | `PANEL_SOLID` | ダイアログ、メニュー、オプション。ほぼ不透明で、太い縁と影 |
| `PanelContainer` | `PANEL_BAND_TOP` / `PANEL_BAND_BOTTOM` | 画面の上の帯と下の帯 |
| `PanelContainer` | `PANEL_CARD` | 板の中の区切り |
| `PanelContainer` | `PANEL_TAG` | 小さな札（名前の札、印） |
| `PanelContainer` | `PANEL_NONE` | 縁も地も無い入れ物 |
| `Label` | （ふつう） | 本文 |
| `Label` | `LABEL_TITLE` | 題字（明朝、金） |
| `Label` | `LABEL_HEADING` | 画面の見出し（明朝） |
| `Label` | `LABEL_SECTION` | 板の中の小見出し（太字、金） |
| `Label` | `LABEL_DIM` | 補足の文 |

- 景色の四隅を沈める幕は `UiTheme.vignette()`、ダイアログの板は `UiTheme.solid_box(余白)`、盤の上の板は `UiTheme.overlay_box(余白)`。
- **色だけ違う板**が要るとき（陣営の色の札など）は、`UiTheme.box(地, 縁, …)` で形を作り、色は `Palette` から渡す。
  `StyleBoxFlat.new()` から組まない（角の丸さや縁の太さが、画面ごとにずれるため）。
- **状態で色が変わる文字**（出せる / 出せない、など）は、`add_theme_color_override("font_color", Palette.GOOD)` のように `Palette` を渡す。
- 盤の上に直に置く文字（板の無いところ）は、縁取り（`outline_size`）を付ける。縁取りの色はテーマが持っている。
- スイッチ（`CheckButton`）、スライダー、送りの棒、進み具合の棒、入力欄、選択肢（`OptionButton`）、ツールチップは、そのまま使えばテーマの見た目になる。
- 選択肢（`OptionButton`）の欄は、入力欄と同じ沈んだ地に真鍮の縁、右端に真鍮の山形。開いた選択肢（`PopupMenu`）は、上の縁が太い真鍮の板（透けない）で、
  乗った行は左に金の線と薄い金の塗り（駒のそばのメニューの項目と同じ）。

## 枠の大きさ

**枠の大きさは、中身で変えない。** 枠（パネル、窓、札、欄、帯、ボタンの並び）は決まった大きさで出し、中身をその中に収める。
選んだもの、マウスを乗せたもの、文の長さ、数の桁、駒の種類、持ち物の数、試しの決まりの入・切、言葉の長さで、枠が伸び縮みしたり、
まわりの部品が動いたりしないこと（カーソルを動かすたびに画面が揺れる）。

収め方（上から順に試す）:

1. **決まった幅の欄に分ける**（`game/stats_row.gd` の能力値の欄のように、項目ごとの幅を決める）。枠には `custom_minimum_size` で大きさを与える。
2. **折り返す**（`game/text_wrap.gd`。語の途中で切らない）。行の数の上限を決め、その行の数ぶんの高さを、いつも取っておく。
3. **いちばん大きい中身に合わせて固定する**（`game/steady_box.gd`。出しうる中身が、作るときに全部分かるとき）。
4. **字を小さくする**。下限つき（12 px より小さくしない）。
5. **長いものは、枠の中で送る**（`ScrollContainer`。枠は動かさない）。
6. **「…」で切る**のは最後の手（`text_overrun_behavior`）。切れる中身が実際には無いことを、テストで確かめる。

- **空のとき・選んでいないときも、同じ大きさの枠を出したままにする**（出たり消えたりで、まわりが動かない）。中身だけを替える。
- 中身の数だけ行が並ぶもの（駒のそばのメニューの項目、一覧）は、行の数で高さが変わってよい。幅と、1 行の大きさは変えない。
- 置き場所がまわりの都合で動くもの（駒のそばのメニュー、戦闘予測のパネル）も、大きさは変えない。

**枠を作ったら、印を付ける**（`game/steady.gd`）:

    const Steady := preload("res://game/steady.gd")
    Steady.mark(panel, "sortie.unit_note", Steady.RECT)

- 名前は `画面.枠`（英字。画面の文ではないので、表には置かない。検査が落ちたとき、この名前で出る）。`Steady.SIZE`（既定）は大きさだけ、`Steady.RECT` は置き場所も見る（画面の決まった所に出る枠）、
  `Steady.WIDTH` は幅だけ（行の数で高さが変わる並び）。
- **同じ名前の枠は、同じ大きさ**（並んだ札に同じ名前を付ければ、札がそろっていることも見る。選び直しで作り直す欄も、前と同じ大きさ）。
- 検査のあいだ（自動の対戦、通しの点検）、枠の見張り（`game/steady_probe.gd`。アプリの入口が持つ）が、印の付いた枠の四角を毎コマ控え、
  動いたら失敗にする（`autoplay: 枠が動いた: sortie.unit_note（前の四角 → あとの四角）`）。窓の大きさか場面（`scene_flow.gd`）が替わったら、控えを捨てる。
  `tools/check.sh` の自動の対戦が、そのまま検査になる。
- 自動の対戦が中身を替えない枠は、見張りに掛からない。枠を足したら、自動の対戦（`game/autoplay.gd`）で中身を替える手（マウスを乗せる、選び替える）を通すか、
  `tests/game/test_steady_frames.gd` に、中身を次々当てて大きさを比べるテストを足す（大きさは、木に入れて 1 コマ待って測る。`docs/README.md`）。
- **洗い出し**: `godot --headless --path . --fixed-fps 60 -- --autoplay --only ui --frames`（`--story-all`、`--versus-all` でも）。
  印の無い板（`PanelContainer`、`Panel`、`ScrollContainer`）も全部控え、終わりに、大きさが変わったものを並べる（失敗にはしない）。

## 駒と軍の部品

駒を札で見せる画面（部隊編成、編成確認）が使う。どれも絵は使わず、スクリプトで描く。**大きさは中身で変わらない。**
テスト: `tests/game/test_ui_parts.gd`。

| 部品 | コード | 使い方 |
| --- | --- | --- |
| 駒の額 | `game/unit_frame.gd` | 駒のアイコンは、沈んだ地に真鍮の縁の額に入れる。右下の隅に役割の印。選ばれている駒は、縁が金（`chosen`） |
| 役割の印 | `game/role_mark.gd` | 前衛は盾、後衛は照準、奇襲は短剣、回復は十字。**色は付けず、形で見分ける**（色は陣営・国・危険の意味に取ってある） |
| コストの宝石 | `game/cost_gems.gd` | コストの 1 を菱形の宝石 1 個で見せる。駒や持ち物のコストは「並び」、部隊のコスト / コスト上限は「目盛り」（上限ぶんの溝に、使ったぶんの金の宝石。5 個ごとに切れ目。超えたら、みな危険の色）。数の文（「コスト 19 / 24」）は消さず、その横に置く |
| 能力値の欄 | `game/stats_row.gd` | 「HP 44　攻撃 6　移動 3　射程 1」の 1 行を、項目ごとに幅のそろった欄に分ける。名前は補足の色で小さく、数は太く。札を並べると、数が縦にそろう。文は表の 1 行のまま（言葉は変えない） |
| 能力値の行 | `game/stat_meter.gd` | 駒の詳細の窓と、部隊編成の右の札（詰めた行）。名前・いまの値・増減（▲ は良い知らせの色、▼ は危険の色）・目盛り（棒か、菱形の粒）。素の値は金、増えたぶんは良い知らせの色、減ったぶんは危険の色の抜き。HP の棒は、枠の長さが最大 HP、塗りがいまの HP |
| ステータスの札の部品 | `game/sheet_parts.gd` | 小さな札（役割・軍・クールダウン）と、スキル・必殺技・進化先の札。駒の詳細の窓と、部隊編成の右の札（`game/unit_summary.gd`）が共に使う |
| 札の印 | `game/ability_mark.gd` | スキルは四つ角の星（生成り）、必殺技は八方の光（金）、進化は上向きの山形（良い知らせの色）。暗い丸い札に描く |
| 駒の姿の額 | `game/unit_portrait.gd` | 盤の駒の 3D の形を、小さい 3D の枠に立たせる（会話の話し手と同じ）。縁は陣営の色、後ろに国の紋 |
| 軍の飾り | `game/nation_decor.gd` | 板やカードの上の縁に国の色の帯と淡い光、右下に薄く大きな国の紋。板の**最初の子**にする |

- **軍らしさ**は、国の色と紋で出す: 組む画面の枠の上の縁の帯、見出しの紋、軍の名前の色。一覧の行は左の縁に国の色の線と紋。軍を選ぶ札は、物語のカードと同じ向き（帯と地紋、名前は明朝）。
- 欄の小見出しは `UiTheme.section_head(文)`（金の太字と、右へ伸びる細い線）。
- **出撃不可**の理由は、危険の色の帯（`UiTheme.danger_strip_box()`）に載せる。一覧の出せない部隊は、左の線・紋・文字が危険の色。
- 並びの番号は、小さな丸い札（`UiTheme.number_box()`）。選んでいる駒は、番号・額の縁・名前が金。
- 札の中の「外す」のような軽い操作は、行のボタン（`BUTTON_ROW`）にして、札より目立たせない。

## 出撃準備

- **初期位置の縮図は作戦図**（`game/deploy_map.gd`。対戦設定の「初期位置」の窓も同じ）: マスの境の細い方眼、真鍮の縁と四隅の鉤、盤の外の目盛り（1 マスごと。5 マスごとに長く。入れ物の余白に描く）、本陣に陣営の色の旗。
- 見出しの下に、人の軍の国の色の飾りの線。「勝ち方」の欄は、対戦の上の帯の勝ち方の札と同じ色（`GOAL` を混ぜた地と `GOAL_BORDER`）。
- 「敵の部隊」「出撃する部隊」の欄は、上の縁にその軍の国の色の帯（軍なしの敵は陣営の赤）、小見出しの頭に国の紋。駒は額（縁は陣営の色）に入れる。
- 「出撃」は、明朝の大きな字にして、左右へ飾りの線を伸ばす。
- **高さは増やさない。** 敵の駒が多い話（魔物の群れ）で、部隊の選択肢の欄が 1 行ぶん残る高さに収めてある。

## 対戦設定

- パネルの頭に、対戦の組み合わせの帯（`game/versus_banner.gd`。左右に両軍の国の紋と名前、真ん中にマップの縮図。地は陣営の色が端から真ん中へ消える）。
- プレイヤーごとの行（軍・部隊）は、左の縁に陣営の色の太い線を持つ薄い板で囲む。手番がランダムの間は、どちらも枠の真鍮（陣営が決まっていないため）。

## 窓（重なる画面）

オプション、編成確認、初期位置、駒の詳細、ログ、会話のログ、システムメニュー、確かめの窓（システムメニューの確かめ、部隊編成の確かめと名前の入力）。

- 見出しは明朝（`UiTheme.style_window_title(label)`）で真ん中に置き、その下に飾りの線（`UiTheme.window_rule()`）。ログは右の端の細い板なので、見出しの右へ線を伸ばす。
- 後ろは幕（`Palette.SHADE`）で沈め、板は `PANEL_SOLID`。閉じるボタンは下の真ん中（ログだけ右上で、控えめな `BUTTON_GHOST`）。
- 板の中の区分は `UiTheme.section_head(文)`（オプションの「操作」「再生」「音」…）。
- **駒の詳細**はステータスの窓（`docs/deck-screen.md` の「駒の詳細」）。見出しは置かず、駒の名前（明朝）が頭。上の縁に軍の国の色の帯。
  左に駒の姿の額（`game/unit_portrait.gd`）、右に能力値の行（`game/stat_meter.gd`）と、スキル・必殺技・進化先の札（頭に印 `game/ability_mark.gd`。必殺技の札は金の縁）。
- 初期位置の窓は、作戦図の額（目盛りと鉤）が縮図の外に出るぶん、縮図のまわりに余白を取る。
- **システムメニュー**の項目は、タイトルのメニューと同じ札（`BUTTON_MENU`）。確かめを挟む項目（抜けると失われるものがある行き先）の前に、区切りの線を 1 本。
- **確かめの窓**は、1 行目（何をするか）を窓の見出しにし、飾りの線を危険の色（`UiTheme.window_rule(Palette.DANGER)`）にする。
  新しい画面で削除・上書きを確かめるときは、部品 `game/confirm_window.gd`（`ConfirmWindow.ask(見出し, 失われるもの, ボタンの文字, すること)`）を使う。
  幕・板・線・ボタンの並び・右クリックと Esc でキャンセル・重なる画面の積み上げまで持っている（セーブデータ選択が使う）。
  失われるものの文は、線の下に注意の色で。名前の入力は、線が枠の真鍮で、「決定」がいちばん大事なボタン。

## テーマを直すとき

- 種類を足すときは、`ui_theme.gd` に定数と形を足し、上の表に 1 行足す。
- 見え方は、スクリーンショット（`docs/screenshots.md`）を 1280×720 と 960×540（文字がいちばん小さくなる）で撮り、
  草原・石畳・暗い結晶の森の上で、半透明の板の文字が読めることを確かめる。
- コンテナのソフトウェア描画では、半透明の重なり・細い縁・影のぼかしが実機と少し違って見える。最終の見え方は exe で確かめる。

## 小さな動き

- ボタンにマウスが乗ると一瞬だけ明るく光って落ち着き、押すと一瞬だけ沈む（`game/ui_feel.gd`。アプリの入口が 1 つ持ち、木に入るボタンの全部に付く）。
  画面の側は何もしなくてよい。入力は止めないので、待ち時間は増えない。
- 大きさは変えない（入れ物が並べ直すたびに戻るのと、文字が拡大でぼやけるため）。
- 画面の側が `self_modulate` で色を付けているボタン（必殺技の READY の明滅など）には重ねない。

## 景色の上に置く画面

- セーブデータ選択は、景色の上に `UiTheme.scene_shade()`（景色の全体を夜の藍へ沈め、四隅をさらに沈める幕）を敷いてから、カードを置く。
- **マップ選択**は、物語選択と同じ `UiTheme.vista_shade()`（裂けた空の色を残す）。対戦設定は、四隅だけ沈める（`UiTheme.vignette`）。
- **物語選択と話の一覧**は、タイトルと同じ裂けた空の景色（`game/title_backdrop.gd` の構え。`docs/scene-flow.md`）の上に `UiTheme.vista_shade()`（空の色を残し、上と下だけを夜の藍へ沈める幕）を敷く。
  物語選択は縫い目が真ん中で、左のカード（ベルク連邦）が琥珀の空、右のカード（リュエル騎士領）が菫の空の下に来る。話の一覧は、その物語の国の側の空へ向く。
  大きな見出しは字の間を空けた明朝（`UiTheme.spaced_heading()`）。話の一覧の見出しは、国の紋で左右から挟む。
- **話のカード**は、上の縁に国の色の帯と淡い光（`game/nation_decor.gd`）。次に遊ぶ話は帯が金。まだ遊べない話は帯の色を抜き、縮図のかわりに封をした札（暗い地、斜めの細い線、薄い国の紋。`episode_list_screen.gd` の `Sealed`）に「？？？」。話の名前は明朝。
  タイトルは `UiTheme.vignette()`（四隅だけを沈める）。
- カード（`BUTTON_CARD`）は、落ちる影で浮かせ、乗ると金の縁と金の光のにじみ。
- カードの盤の縮図（マップ選択、話の一覧）は、真鍮の縁と四隅の明るい鉤の額に入れる（`game/map_frame.gd`。縮図の TextureRect の子にする。ミニマップ・対戦設定の帯の縮図と同じ向き）。
- マップ選択・物語選択・話の一覧の見出しの下には、飾りの線を置く。
- **物語のカード**は、その国らしさを出す: 上の縁に国の色の帯、地紋に薄く大きな国の紋（`game/crest.gd`。スクリプトで描く。ベルク連邦は歯車と山形、リュエル騎士領は結晶の菱形と星）、
  物語の名前は明朝。準備中の物語は色を抜く。話の一覧の見出しの下の飾りの線は、その物語の国の色。
- 景色の上に直に置く見出し（`LABEL_HEADING`）は、縁取りを太くする（`outline_size` 10）。
- タイトルは、題字（ロゴ）とメニューを、板に載せずに景色の上へ直に置く。
  ロゴは 2 段: 上に、小さく字の間を広げた語（生成り）を左右の細い線で挟み、下に大きな主の語（`LABEL_TITLE`。明朝、太い縁取り）、その下に金の飾りの線。
  主の語の金は、字の上から下への移ろいと細い照り返し（`game/title_gold.gdshader`。色は `Palette` から渡す）。**読みのかなは添えない。** 語は `game/text/menus.csv` の `title.logo.*`。
- 飾りの線（`game/ui_ornament.gd`。真ん中に菱形、左右へ細くなる線）は、題字や見出しの下に置く。色は `Palette` から（既定は `BORDER_BRIGHT`）。
- 対戦の上の帯と下の帯は `UiTheme.band_box(上か)` の形（角を丸めず、内側の辺にだけ縁）。

## 対戦の HUD

- **番の陣営の色**を、上の帯に出す: 番の文字の後ろの札（陣営の色を混ぜた暗い地と、陣営の色の縁）と、帯の下の縁。並びの幅は変えない（札は文字の枠の外へはみ出させて描く）。
- **情報の枠**の上の縁は太く、駒を出しているときは陣営の色、マスを出しているときは枠の真鍮。
- **画面の中央の知らせ**（番の切り替わり、聖遺物、必殺技）は、帯（`game/banner_band.gd`）で出す: 画面の幅いっぱいに、真ん中が濃く、両端へ消える陣営の色の帯。上と下の縁に細い線。
  文字は明朝。帯が上下に開き（`BannerBand.OPEN_TIME`）、文字が横から滑り込む。出ている長さは開く動きを含めて `BannerBand.HOLD_TIME`、そのあと `BannerBand.FADE_TIME` で消える（開く動きのぶん、待ち時間は増やさない）。
  必殺技（強い知らせ）は、帯を高く、縁の線と文字を金にする。
- **必殺技のゲージ**の中身は、陣営の色の角丸の棒。
- **下の帯のボタンの重み**は 3 段: 「ターン終了」（緑の地、太字、いちばん大きい）＞ 必殺技（押せるときだけ金の縁と金の文字。押せない間は沈み、中に陣営の色でゲージの溜まり具合）＞「おまかせ」「早送り」「スキップ」（`BUTTON_GHOST`）。
  案内の頭に、金の細い線。
- **情報の枠**（駒）: 駒の額（縁は陣営の色、役割の印）と名前 → 所属 → HP の棒 → HP の数（太字）とレベル → 攻撃・移動・射程の欄（`stats_row.gd`）→ 区切りの線 → 状態・持ち物・スキル・特性・行動の状態。
  文は表の文のまま（`info_text()` は変わらない）。マスの情報は、欄を出さず本文だけ。
- **戦闘予測のパネル**: 上の縁が太い金。見出しの下に区切りの線。「倒せる！」「自分も巻き込まれる！」は色の札（`UiTheme.alert_box(色)`）。
  HP の棒は溝に入れ、変わる境に明るい線。駒の名前と HP の行は太字。板は `UiTheme.box` から作る。
- **駒のそばのメニュー**: 上の縁が太い真鍮の板に、行の項目（`BUTTON_ACTION`）。項目の幅は決まっていて、言葉の長さで変わらない（`docs/battle-view.md` の「大きさを変えない枠」）。
- **ミニマップ**は、真鍮の縁と、四隅の明るい鉤で額に見せる。
