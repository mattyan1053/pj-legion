# 縫い目の様子

コード: `rules/seam.gd`（`Seam`。札、めくり方、効果の計算）。テスト: `tests/rules/test_seam.gd`、`tests/game/test_seam_view.gd`、`tests/game/test_episode_data.gd`（話のファイルの `signs`）。

**その対戦のマップに付く、気候のような効果**（人間の決定。Issue #47 の 11/23:「その戦闘マップの現在の状態を示すパラメータ」「マップに付与する効果みたいな扱い」）。
1 つの対戦に 0〜2 つ付き、対戦のあいだずっと、どちらのプレイヤーにも同じに効く。**対戦中に切る操作は無い。** 部隊を選び直す窓も無い（見てから部隊を替えられるなら、前の画面で出すことになるため）。

- **対戦モード**: 選べる決まり（`OptionalRules.SEAM`。`docs/match-setup.md` の「選べる決まり」）。対戦設定の行は「縫い目の様子: ランダム / なし」で、**既定はランダム**。
  ランダムなら、対戦ごとに 0〜2 つ（`Seam.DRAWN`）がめくられる（数も様子も対戦の種で決まる。下の「めくり方」）。
- **ストーリー**: 話のファイルの `[episode]` の `signs` で、その話の様子を決める（`docs/story.md`）。書けば、その話にいつも付く。書かなければ付かない。
  いまの話には入れていない（入れると難しさが変わる）。
- **見せ方**: 対戦の始めの「対戦ルール」（勝利条件と並べて。`docs/battle-view.md` の「対戦ルール」）と、対戦中の上の帯の下の札。札の名前をクリックすると、効果が読める。
- 世界（`docs/world.md`）: 対戦の場は縫い代。仮縫いの縫い代は、日によって様子が違う（霞が残る、糸がゆるむ、ほころびがずれる）。様子は、だれかが切るものではない。
- 様子は数値を足すだけにせず、**どう動くか**の判断を変えるものにしてある。先手・後手のどちらか、片方の軍だけが得をする様子は作らない
  （軍の得意・不得意に差が出るのはよい）。
- 様子の無い対戦（`Battle.signs` が空）では、何も変わらない（盤も、駒も、CPU の手も）。

## 札

| 札（鍵） | 効果 | 判断が変わるところ |
| --- | --- | --- |
| 天裂の名残り（`haze`） | 後衛の射程が 1（`Seam.HAZE_CUT`）短い（砲台で伸びた射程も。1 より短くはならない） | 後衛を何体出すか。撃ち合いの間合い |
| 糸の満ち（`brim`） | 必殺技のゲージが 150%（`Seam.BRIM_PERCENT`）の速さでたまる | 必殺技を何回使えるか。削られ方 |
| 糸のゆるみ（`loose`） | ターン 2 からの結晶泉の湧き直しが 70%（`Seam.LOOSE_RESPAWN_PERCENT`）の確率になる（いつもは 35%） | 真ん中を通るか。結晶泉に立って止めるか |
| 骨の眠り（`hush`） | 結晶泉に中立の駒が湧き直さない（ターン 1 の湧きだけ） | 最初のコアを倒せば、真ん中が空く |
| 仮縫いのずれ（`shift`） | ポータルの行き先が入れ替わる（対を 1 つずつずらして組み直す） | どのポータルから、どこへ出るか |
| 縫い代の風（`gale`） | 巡航の移動力 +2（`Seam.GALE_CRUISE`。巡航のいつもの移動力は、移動力の 2 倍） | 攻撃を捨てて走るか。拠点と本陣への詰め |
| 天裂の光（`gleam`） | 後衛の射程 +1（`Seam.GLEAM_RANGE`） | 後衛を何体出すか。撃ち合いの間合い |
| 深い茂み（`thicket`） | 森にいる駒が受ける攻撃のダメージが 60%（`Seam.THICKET_RATE_PERCENT`。いつもは 80%） | 森に立って待つか、森から引きずり出すか |
| 張りつめた糸（`taut`。話だけ） | スキルのクールダウンが 1 ターン（`Seam.TAUT_CUT`）短い（1 より短くはならない） | スキルを何回使えるか |

- 名前と効果の文は画面の文の表（`game/text/names.csv` の `sign.<鍵>`。`docs/text.md`）。効果の文は**短く言い切る 1 行**で、比べる元の値（「いつもは 80%」）は書かない（人間の感想。Issue #46 の 11/23）。
- 駒に掛かる札（天裂の名残り・天裂の光・縫い代の風）は、駒の能力値の層（`Unit.sign_bonus`、`Unit.hazed`、`Unit.cruise_bonus`。`docs/player-loadout.md` の層）に入るので、
  動けるマス、射程、予測、脅威範囲、CPU の読みに、そのまま効く。天裂の名残りは、ほかの層を全部足したあとの射程を縮める。
- 中立の駒にも同じに効く（天裂の名残りと天裂の光は、後衛の魔物（骨の弓兵など）に効く。対戦モードの結晶泉の駒と中ボスは後衛でないので、何も起きない）。

## めくり方

`Seam.draw(盤, 種)`。対戦設定（`MatchSetup.signs()`）と対戦（`MatchSetup.create_battle()` が `Battle.signs` に入れる）が同じ札を引く。
戦いの定義が様子を決めていれば（`Scenario.signs`。話のファイルの `signs`）、めくらずにそれを使う。

- めくる数は、種で決まる 0〜2（`Seam.draw_count`。重み 1 : 2 : 1（`Seam.DRAW_WEIGHTS`）。何も付かない日が 4 局に 1 つ、2 つ付く日が 4 局に 1 つ）。
- 札の山は、全部の札から、**話だけの札（`Seam.STORY_ONLY`）と、その盤で効かない札を抜いたもの**（`Seam.applies`）: 仮縫いのずれはポータルの対が 2 つ以上の盤（双子結晶）だけ、
  糸のゆるみと骨の眠りは結晶泉のある盤だけ、深い茂みは森のある盤だけ。
- 話だけの札は、張りつめた糸。使う回数が増えるのが FANTASY のスキル（ファイアボール・ディバインシールド・シャドウステップ）ばかりで、縮める幅は 1 ターンより小さくできないので、
  対戦モードの山から外した（話のファイルの `signs` では使える）。数字は `docs/cpu-ai.md` の「いまの集計」。
- 山を種で混ぜ、上から数だけ。2 枚目は、1 枚目と打ち消し合う札（`Seam.CLASHES`。糸のゆるみと骨の眠り、天裂の名残りと天裂の光）を飛ばして引く。
- めくるのは、対戦の乱数（`Battle.rng`）とは別の乱数。同じ盤と種なら、いつも同じ札（「同じマップで再戦」は同じ様子）。
- 札は、決まりの準備で盤を変える前の盤から引く。仮縫いのずれは、拠点を置いたあとにポータルを組み直す（拠点のマスは動かない）。
- 話のファイルの様子は、重ねず、打ち消し合う 2 つを並べず、2 つまで（読むときに確かめる。`Seam.from_keys`）。

## CPU

- 対戦中は、札の効果を含めたルールで読む（駒の能力値、ダメージ、湧き直しは、ルールの計算をそのまま通す）。
- 部隊は、様子を見て選び直さない（人も選び直せないので）。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| めくる札の数の上限 | 2 | `Seam.DRAWN` |
| 天裂の名残りが縮める後衛の射程 | 1 | `Seam.HAZE_CUT` |
| 糸の満ちのゲージのたまり方（%） | 150 | `Seam.BRIM_PERCENT` |
| 糸のゆるみの湧き直しの確率（%） | 70 | `Seam.LOOSE_RESPAWN_PERCENT` |
| 縫い代の風の巡航の移動力 | 2 | `Seam.GALE_CRUISE` |
| 天裂の光の後衛の射程 | 1 | `Seam.GLEAM_RANGE` |
| 深い茂みの森のダメージ（%） | 60 | `Seam.THICKET_RATE_PERCENT` |
| 張りつめた糸のクールダウン | 1 | `Seam.TAUT_CUT` |

様子ごとの片寄りは、様子を 1 つだけ付けて部隊を変えた 432 局ずつ（6 つの盤に同じ種）で、様子の無い局と比べて決めた（数字は `docs/cpu-ai.md` の「いまの集計」）。
片方の軍だけが損をしていた 2 つを直した: 天裂の名残りは、射程 3 以上の攻撃（スナイパーだけ）から、後衛の射程（天裂の光の裏返し）に変えた。
射程 2 以上の攻撃（回復の射程も）を縮める形は、逆に MILITARY に振れすぎた。張りつめた糸は、対戦モードの山から外した。
