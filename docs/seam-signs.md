# 縫い目の様子

コード: `rules/seam.gd`（`Seam`。札、めくり方、効果の計算）、`rules/cpu_deck.gd`（`pick_for_signs`。CPU の部隊の選び方）。
テスト: `tests/rules/test_seam.gd`。

対戦モードの選べる決まり（`OptionalRules.SEAM`。`docs/match-setup.md` の「選べる決まり」）。**既定は切**。デッキ的な要素の 2 つ目（Issue #47 の手札の案 T3）。

対戦ごとに、その日の縫い代の様子を表す札が 2 枚（`Seam.DRAWN`）めくられる。両方のプレイヤーに同じ札が見え、札を見てから出す部隊を選ぶ。
札は対戦のあいだずっと効く条件で、どちらのプレイヤーにも同じに効く。**対戦中に札を切る操作は無い。**

- 人間の言葉（Issue #47）:「その場でランダムというより、カードゲームの手札のように、ランダム要素を事前に受け取って、それをもとに作戦を立てる、というラインだと理不尽が少ない」。
  ランダムは対戦の前に全部見え、部隊の選び方で受け止められる。
- 世界（`docs/world.md`）: 対戦の場は縫い代。仮縫いの縫い代は、日によって様子が違う（霞が残る、糸がゆるむ、ほころびがずれる）。札はその日の様子で、だれかが切るものではない。
- 札は数値を足すだけにせず、**どの部隊を出すか・どう動くか**の判断を変えるものにしてある。先手・後手のどちらか、片方の軍だけが得をする札は作らない
  （軍の得意・不得意に差が出るのはよい。それが部隊の選び方になる）。
- 決まりが切の対戦（`Battle.signs` が空）では、何も変わらない（盤も、駒も、CPU の手も）。ストーリーの話では入にしない。

## 札

| 札（鍵） | 効果 | 判断が変わるところ |
| --- | --- | --- |
| 天裂の名残り（`haze`） | 射程 3（`Seam.HAZE_FROM`）以上の攻撃は、射程が 1（`Seam.HAZE_CUT`）短い（砲台で伸びた射程も） | スナイパーを何体出すか。撃ち合いの間合い |
| 糸の満ち（`brim`） | 必殺技のゲージが 150%（`Seam.BRIM_PERCENT`）の速さでたまる | 必殺技を何回使えるか。削られ方 |
| 糸のゆるみ（`loose`） | ターン 2 からの結晶泉の湧き直しが 70%（`Seam.LOOSE_RESPAWN_PERCENT`）の確率になる（いつもは 35%） | 真ん中を通るか。結晶泉に立って止めるか |
| 骨の眠り（`hush`） | 結晶泉に中立の駒が湧き直さない（ターン 1 の湧きだけ） | 最初のコアを倒せば、真ん中が空く |
| 仮縫いのずれ（`shift`） | ポータルの行き先が入れ替わる（対を 1 つずつずらして組み直す） | どのポータルから、どこへ出るか |
| 宵闇（`dusk`） | 奇襲の移動力 +1（`Seam.DUSK_MOVE`） | 奇襲を出すか。奇襲の届く距離 |
| 癒やしの糸（`mend`） | 回復役の回復量 +5（`Seam.MEND_HEAL`） | 回復役を出すか。粘るか |
| 深い茂み（`thicket`） | 森にいる駒が受ける攻撃のダメージが 60%（`Seam.THICKET_RATE_PERCENT`。いつもは 80%） | 森に立って待つか、森から引きずり出すか |
| 張りつめた糸（`taut`） | スキルのクールダウンが 1 ターン（`Seam.TAUT_CUT`）短い（1 より短くはならない） | スキルを何回使えるか |

- 名前と効果の文は画面の文の表（`game/text/names.csv` の `sign.<鍵>`。`docs/text.md`）。
- 駒に掛かる札（天裂の名残り・宵闇・癒やしの糸）は、駒の能力値の層（`Unit.sign_bonus`、`Unit.hazed`。`docs/player-loadout.md` の層）に入るので、
  動けるマス、射程、予測、脅威範囲、CPU の読みに、そのまま効く。天裂の名残りは、ほかの層を全部足したあとの射程を縮める。
- 中立の駒にも同じに効く（射程 3 以上の中立の駒はいないので、いまは何も起きない）。

## めくり方

`Seam.draw(盤, 種)`。対戦設定（`MatchSetup.signs()`）と対戦（`MatchSetup.create_battle()` が `Battle.signs` に入れる）が同じ札を引く。

- 札の山は、全部の札から、**その盤で効かない札を抜いたもの**（`Seam.applies`）: 仮縫いのずれはポータルの対が 2 つ以上の盤（双子結晶）だけ、
  糸のゆるみと骨の眠りは結晶泉のある盤だけ、深い茂みは森のある盤だけ。
- 山を種で混ぜ、上から 2 枚。2 枚目は、1 枚目と打ち消し合う札（`Seam.CLASHES`。糸のゆるみと骨の眠り）を飛ばして引く。
- めくるのは、対戦の乱数（`Battle.rng`）とは別の乱数。同じ盤と種なら、いつも同じ札（「同じマップで再戦」は同じ札）。
- 札は、決まりの準備で盤を変える前の盤から引く。仮縫いのずれは、拠点を置いたあとにポータルを組み直す（拠点のマスは動かない）。

## CPU

- 対戦中は、札の効果を含めたルールで読む（駒の能力値、ダメージ、湧き直しは、ルールの計算をそのまま通す）。
- 部隊は、札を見て候補から選ぶ（`CpuDeck.pick_for_signs`）: 駒 1 体ずつ、札が得にする駒を足し、損にする駒を引いた値（`sign_fit`）がいちばん高い候補。
  並べば先の候補。いまの値は、天裂の名残りでスナイパー -1、宵闇で奇襲 +1、癒やしの糸で回復役 +1（`CpuDeck.SIGN_FIT`）。ほかの札は、どの部隊にも同じくらいに効くので数えない。
- 候補の作り方は、画面と集計の道具が決める（`docs/cpu-ai.md` の「縫い目の様子」）。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| めくる札の数 | 2 | `Seam.DRAWN` |
| 天裂の名残りが縮める射程 | 1 | `Seam.HAZE_CUT` |
| 天裂の名残りが縮める、射程の下限 | 3 | `Seam.HAZE_FROM` |
| 糸の満ちのゲージのたまり方（%） | 150 | `Seam.BRIM_PERCENT` |
| 糸のゆるみの湧き直しの確率（%） | 70 | `Seam.LOOSE_RESPAWN_PERCENT` |
| 宵闇の奇襲の移動力 | 1 | `Seam.DUSK_MOVE` |
| 癒やしの糸の回復量 | 5 | `Seam.MEND_HEAL` |
| 深い茂みの森のダメージ（%） | 60 | `Seam.THICKET_RATE_PERCENT` |
| 張りつめた糸のクールダウン | 1 | `Seam.TAUT_CUT` |
| CPU の部隊の選び方の、札に合う駒 1 体ぶん | 1 | `CpuDeck.SIGN_FIT` |

CPU どうしの対戦で、札ごと・札の組ごとに先手と MILITARY の勝率を測って、1 枚で大きく片寄る札が無いことを確かめた（数字は `docs/cpu-ai.md` の「いまの集計」）。
