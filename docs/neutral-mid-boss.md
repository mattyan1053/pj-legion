# 中ボス（エリートミニオン）

コード: `rules/neutral.gd`（現れる時と動き。エナジー・コアと同じ処理）、`rules/board_generator.gd`（置く場所）、
`rules/battle.gd`（倒した陣営の控え。`Battle.remove_unit`）、`rules/events/mid_boss_defeated_event.gd`。
テスト: `tests/rules/test_mid_boss.gd`。

盤に 2 体（中央平原・迷宮回廊では左右、双子結晶では上下に 1 体ずつ）、中立の中ボス「エリートミニオン」がいる。硬く、近づく駒を強く殴り返す。
対戦の中盤に「取りに行くか、相手に取らせないか」の駆け引きを作るためのもの。
倒した陣営は、その中ボスの聖遺物を受け取る（`docs/relic-buff.md`）。

能力値は `docs/unit-roster.md`。コアより硬く、強く、射程が長い。

## 置く場所

盤面が `Board.mid_boss_cells` に持つ（添字が中ボスの番号。0 = 左か上、1 = 右か下。聖遺物は 0 が英知、1 が勇気。`docs/relic-buff.md`）。
どのマップでも、本陣どうしを入れ替える点対称（`本陣1 + 本陣2 - マス`）で、2 体の中ボスが入れ替わる。

| マップ | 0 | 1 | 着くまでの歩数 |
| --- | --- | --- | --- |
| 1 中央平原、2 迷宮回廊 | 左 `(8,14)`（本陣の列から左へ 6（`MID_BOSS_SPREAD`）、真ん中の上の行） | 右 `(20,15)`（右へ同じだけ、真ん中の下の行） | ほぼ同じ（左はプレイヤー2 がわずかに近い。右はその逆） |
| 3 双子結晶 | 上 `(15,8)`（中央の壁から上へ 4（`MID_BOSS_WALL_GAP`）） | 下 `(14,21)`（壁から下へ同じだけ） | 上は、プレイヤー2 が歩いて、プレイヤー1 が近いポータルを抜けて、ほぼ同じ歩数。下はその逆 |

座標は 30 x 30 のとき。ほかの大きさでは、本陣の列・中央の壁からの位置で決まる（`BoardGenerator.mid_boss_cells_for`）。

- **両軍がぶつかる場所の、すぐ脇に置く**（取り合いが起きるように）。マップ 1・2 では、中央の道（結晶泉のある列）の
  すぐ外の左右。中央で戦う駒は、中ボスの届く距離（家から、縄張り + 射程）の縁にいる。マップ 3 では、ポータルを出た軍が相手の本陣へ向かう道の脇。
- **どちらのプレイヤーからも、同じくらいの歩数**。マップ 3 では、ポータルの出口のそばに置かない
  （出口のそばだと、そのポータルに近い側だけが、出てすぐ狩れる）。
- 中ボスの周り（チェビシェフ距離 1（`MID_BOSS_CLEARING`）以内）には、障害物・森・環境オブジェクトを置かない（守るマス。`docs/game-board.md`）。
  樽はその外にはあるので、中ボスが縄張りを動くと、爆発に巻き込める。
- 中ボスのマスは、本陣から歩いて行ける。つながらなければ、盤面を作り直すか、本陣から道を削る（`docs/game-board.md`）。
- 本陣から、中ボスの届く距離（縄張り + 射程）より十分に遠い（`tests/rules/test_mid_boss.gd` で固定）。本陣の周りに置いた軍へは届かない。
- 迷宮回廊の回復の泉は、中ボスの家から、縄張りにいちばん長い射程を足したより遠くに置いてある（`docs/map-objects.md`。泉に立ったまま中ボスと殴り合えない）。

## 現れる時

- 中立のフェーズの終わり、結晶泉の湧きのあとに、`UnitSpawnedEvent`（種類、陣営、マス、家 = 置く場所、HP、最大 HP）で現れる
  （`Neutral.spawn_mid_bosses`。番号の順）。
- 現れるのは、ターン 1（`MID_BOSS_SPAWN_TURN`）の中立のフェーズから。確率は使わない（両プレイヤーに同じ形で始まる）。
- 場所にほかの駒が乗っていれば、その中立のフェーズには現れず、空いた中立のフェーズに現れる。
- 生きている間は、2 体目を置かない。**倒れたら、二度と現れない。**
- 現れたフェーズには動かない（次の中立のフェーズから。エナジー・コアと同じ）。

## 動き方

**エナジー・コアと同じ処理**（`docs/neutral-minion.md` の「縄張り」「中立のフェーズ」）。置く場所を家にする。

- 縄張りは家から `Neutral.TERRITORY_RADIUS`（コアと同じ）。狙うのは、家から縄張り + 射程 以内のプレイヤーの駒のうち、いちばん近いもの。
- 動いて、届けば攻撃する（プレイヤーの攻撃と同じ計算。間に盾があれば届かない。森の軽減、バリアが効き、
  離れたところからの攻撃は煙幕に阻まれる。`docs/combat.md`、`docs/field-effects.md`）。
  射程が 2 あるので、動く先は、間に盾の無い撃てるマスを選ぶ（届くなら、射程に入っても盾越しのマスより先に選ぶ）。
- 狙う相手がいなければ、家へ戻る。
- 中立の駒どうしは味方。支配領域を作らない。回復しない（泉でも）。駒に付く状態は、いまは付かない（敵に付けるスキルが無い）。
- シャドウステップで入れ替われる（敵の駒と同じ）。縄張りの外へ出された中ボスは、次の中立のフェーズから家へ戻る。

## 倒す

- 中ボスの HP を 0 にした駒（**止めを刺した駒**）の持ち主が、**倒した陣営**になる。削った量は問わない。
  - 攻撃: 攻撃した駒。スキル（ファイアボール）: 使った駒。起爆樽の爆発: 樽を攻撃した駒。
  - 中立は倒した陣営にならない（いまのルールでは、中立の駒が中ボスを倒すことは無い。起きたら、倒した陣営なし）。
- 倒れたときのイベントは、`UnitDefeatedEvent` のすぐあとに `MidBossDefeatedEvent`。

  | イベント | 値 |
  | --- | --- |
  | `MidBossDefeatedEvent` | 中ボスの番号 `boss_index`（0 = 左か上、1 = 右か下）、駒の番号、マス、止めを刺した駒 `slayer_id`、倒した陣営 `slayer_side`（いなければ 0 と -1） |

- 対戦は、倒した陣営を中ボスの番号ごとに控える（`Battle.mid_boss_slayers`。`Battle.is_mid_boss_defeated`）。
  複製（`Battle.clone()`）も写す。
- 倒した陣営がいれば、続けて `RelicGainedEvent`（その中ボスの聖遺物を受け取る。`docs/relic-buff.md`）。

## 見返り

- **聖遺物**: 倒した陣営が、番号 0（左か上）なら英知（最大 HP +5（`Relics.WISDOM_MAX_HP`））、番号 1（右か下）なら勇気（攻撃力 +1（`Relics.COURAGE_POWER`））を受け取る。必殺技のゲージもたまる（`docs/relic-buff.md`）。
- **経験値**: 止めを刺した駒に 60（`Growth.MID_BOSS_DEFEAT_EXPERIENCE`）。プレイヤーの駒やコアを倒したときより多い。
  削るたびの「当たった」の 10（`Growth.HIT_EXPERIENCE`）は、ほかの駒と同じに入る。樽の爆発で倒したときは入らない（`docs/experience-levelup.md`）。
- **必殺技のゲージ**: 中ボスに与えたダメージで、ほかの敵と同じにたまる。**中ボスから受けたダメージでは、たまらない**
  （`docs/tactical-ult.md`）。

## CPU

- **危険**: 中立の駒（中ボスもコアも）は、縄張りの中で止まれるマスから射程まで届くものとして数える（`docs/cpu-ai.md` の「危険の見積もり」）。
  縄張りの外に立てば安全、が読める。
- **狩る・狩らない・相手に取らせない**は `docs/relic-buff.md` の「CPU」。倒しきれて、横取りされないと見たときだけ、削り、向かう。
  狩ると決めていない中ボスは削らない。弱った中ボスには、届けば止めを刺す。

## 調整値

ゲーム性で選んだ値。

| 値 | いまの値 | 選んだ理由 |
| --- | --- | --- |
| HP・攻撃力 | 50、10 | 2〜3 体で囲めば数ターンで倒せるが、1 体では、毎ターン殴り返されるので硬い駒でも狩りきれない。互角のうちに狩りに出るかどうかが、損得の分かれ目になるくらいにしてある（`docs/relic-buff.md` の「狩られ方」） |
| 射程 | 2 | 射程 1 だと、射程の長い駒が殴り返されない距離から撃ち、下がり、を繰り返して 1 体で安全に狩れる。移動 + 射程を、いちばん長い射程（スナイパー）とそろえて、撃てば撃ち返されるようにした |
| 移動力 | 2 | コアと同じ。縄張りの中を動く速さで、走って逃げられる |
| 縄張り | 4（コアと同じ `Neutral.TERRITORY_RADIUS`） | コアと同じ動きにそろえる。縄張り + 射程の外は狙わないので、中央の道を押す軍には寄ってこない |
| 置く場所 | 上の表 | 両プレイヤーに公平（点対称で、着くまでの歩数がほぼ同じ）。両軍がぶつかる場所のすぐ脇に置き、戦いの中で「相手を殴るか、中ボスを殴るか」を選ばせる。離れすぎると、寄り道の手数が重く、互角のうちには誰も取りに行かない |
| 現れる時 | ターン 1 から（`MID_BOSS_SPAWN_TURN`） | 最初から見えているほうが計画できる。軍が届くのは、中央でぶつかるのと同じころ |
| 撃破の経験値 | 60（`Growth.MID_BOSS_DEFEAT_EXPERIENCE`） | 削りの「当たった」が、狩りに加わった駒へ散って入る。止めはそれより大きく、プレイヤーの駒の撃破より少し多い |
| 受けたダメージのゲージ | たまらない | 押されている側を助けるための決まり（`docs/tactical-ult.md`）。自分から殴りに行く中ボスで受けたぶんがたまると、狩りがゲージの稼ぎ場になる |

## 名前

**画面では「中ボス」と言わず、その対戦の名前で呼ぶ**（人間の感想。Issue #46 の 11/23:「『中ボスを倒した』はひどい。名前を付けないか」）。世界では番人（`docs/world.md`）。
コード: `game/names.gd`（`set_boss`、`boss`）、`game/text.gd`（`shared`。文の `{boss}` に差し込む）。テスト: `tests/game/test_win_text.gd`、`tests/game/test_episode_data.gd`。

- 名前は、話のファイルの `[episode]` の `boss`（`docs/story.md`）、無ければマップのファイルの `[map]` の `boss`（`docs/hand-map.md`）、どちらも無ければ「番人」（画面の文の表の `default.boss`。生成のマップ）。6 字まで（`game/maps.gd` の `BOSS_NAME_MAX`）。
- 1 つの盤の 2 体は同じ名前で、ログでは場所（左・右。縦に並ぶ盤では上・下）を添える。
- 対戦の画面が、対戦を始めるたびに入れる（`battle_source.gd` の `boss_name`）。出撃準備も、勝ち方の欄を作るときに入れる。
- 呼ぶ所: 勝利条件の名前と文（「峠の番人の撃破」「峠の番人を倒す」）、上の帯の勝ち方の札、ログ、決着の文（「峠の番人を倒した」「敵に峠の番人を倒された」）、
  戦績、駒の情報の名前（`Names.kind` のエリートミニオン）。文書と CPU と集計の道具は、これまでどおり「中ボス」と書く。

## 画面

- 中ボスをクリックして見ると、脅威範囲（`docs/threat-range.md`。`Threat.of()`）を赤で塗る（`docs/battle-view.md`）。
  縄張りの中で止まれるマスからの射程なので、縄張りの見当も付く。
