# ディバインシールド（パラディン）

コード: `rules/skills/divine_shield_skill.gd`。テスト: `tests/rules/skills/test_divine_shield.gd`。
共通の決まり（使える条件、クールダウンの数え方、イベントの順）は `docs/active-skills.md`。
バリアそのものの決まりは `docs/unit-statuses.md` と `docs/combat.md` の「ダメージの解決」（テストは `tests/rules/test_statuses.gd`）。

「自分に使うスキル」（同じ文書）。対象は自分のマスだけ。

## いまの仕様

- **自分にバリアを付ける。バリアは、次に受けるダメージを 1 回だけ 0 にして消える。**
- **どのダメージも防ぐ**: 駒の攻撃（確定クリティカルも）、中立の駒の攻撃、**起爆樽の爆発**、**スキルのダメージ（ファイアボール）**。
  何で受けても、最初の 1 回で消える。弱い攻撃や、わざと爆発させた樽で先にはがせる。
- 煙幕に阻まれた攻撃はバリアまで届かないので、バリアは残る。
- バリアは **2 ターン（`DivineShieldSkill.BARRIER_TURNS`）**。使ったターンの相手の番、次の自分の番、その次の相手の番まで残り、その次の自分の番の始めに消える。
  バリアを張った次の番に、張ったまま前へ出て殴れる。
- 動く前でも、動いたあとでも使える（共通の決まり）。使うと行動を終える。
- 防がれた攻撃にも、「当たった」ぶんの経験値は入る（`docs/experience-levelup.md`）。

### イベント

`SkillUsedEvent`、`StatusAppliedEvent`（バリア、残りは `BARRIER_TURNS`）、`UnitActedEvent`。
防いだときは、ダメージのイベント（`amount` が 0、`blocked_by` がバリア）のあとに `StatusRemovedEvent`（`CONSUMED`）。

## 決めたこと

- **樽の爆発も、ファイアボールも防ぐ。** 例外を作らず「次のダメージを 1 回」にそろえた。画面の見込みも 1 つの読み方で済み、
  樽は「バリアを安くはがす手」として残る。
- **期限を付けた。** 受けるまで残ると、早めに張って損が無く、張る時を選ぶ意味が薄い。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| クールダウン | 4 | `DivineShieldSkill.COOLDOWN` |
| バリアの残りのターン数 | 2 | `DivineShieldSkill.BARRIER_TURNS` |

- クールダウンは期限より長い（張りっぱなしにはできない）。攻撃 1 回ぶんを防ぐかわりに、その番は殴れない。
- CPU は、バリアの駒を避けてほかの駒を撃つので、「この番は撃たれない」効果として働く。

## CPU

`CpuDivineShield.value`（`rules/cpu/divine_shield_cpu.gd`）。

- 次の相手の番に、いまのマスの自分に届く攻撃（危険の見積もり。`docs/cpu-ai.md`）があれば、
  そのうち**いちばん弱い 1 回**を防ぐと見込む（相手は弱い攻撃で先にはがす。0.75（`CpuDivineShield.COVER_RATE`）× ダメージの価値 × そのダメージ。
  自分の HP まで）。攻撃されそうになければ 0。もうバリアが付いていれば、張る手は試さない（価値も 0）。
- バリアの付いた駒の危険の見積もりは、同じく、いちばん弱い 1 回ぶんを引く。
- 相手のバリアは、続けて殴れる味方がいれば、先に動く駒がはがす（`BARRIER_STRIP_RATE`。`docs/cpu-ai.md` の「行動の結果の価値」）。
  動かす順は役割で決まっている（奇襲 → 後衛 → 前衛）ので、「いちばん弱い駒ではがす」ことまでは選ばない。
- 攻撃できる相手がいれば、ふつうは攻撃のほうが価値が高い。前へ出たが殴れる相手がいない、というときに張る。
- 巡航で動いた駒は張れない（共通の決まり）。**「通常の移動で止まって張る」手を、「巡航で寄る」手と比べる**
  （張るために立つマスを探す。`docs/cpu-ai.md`）。試すのは、通常の移動で止まれるマスのうち、次の相手の番に攻撃されうるマスを、
  立つマスの価値の高い順に 3 か所（`CpuDivineShield.TRIES`）と、いまのマス（`CpuDivineShield.targets`）。
