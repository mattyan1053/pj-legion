# 精密照準（スナイパー）

コード: `rules/skills/precision_aim_skill.gd`。テスト: `tests/rules/skills/test_precision_aim.gd`。
共通の決まり（使える条件、クールダウンの数え方、イベントの順）は `docs/active-skills.md`。
照準そのものの決まりは `docs/unit-statuses.md` と `docs/combat.md` の「ダメージの解決」（テストは `tests/rules/test_statuses.gd`）。

## いまの仕様

- **動かずに構える。次の自分の番、構えたマスからの攻撃 1 回が、射程 +3、ダメージ 2 倍（確定クリティカル）になる。**
- 使えるのは、**このターンにほかのマスへ動いていない**駒だけ（動いたあとは使えない。移動を取り消せば使える）。
  使うと行動を終えるので、使ったターンは動かないことになる。
- 使うと、自分に照準が付く（残り 2 ターン）。**射程は、付いた時から伸びる**（その番はもう攻撃できないが、
  相手は、構えたスナイパーの届く範囲を自分の番に見て、外へ出るか、煙幕・盾・バリアで受けるかを選べる）。
- 照準は、次のどれかで消える。
  - **攻撃を 1 回した**（駒・樽・盾のどれでも。煙幕に阻まれても）。伸びた射程と 2 倍は、その 1 回だけ。
  - **ほかのマスへ動いた**（取り消せば戻る）。動いてから撃つ攻撃は、ふつうの射程とダメージ。
  - **期限**: 次の自分の番に撃たなければ、その次の自分の番の始めに消える。
- 2 倍は攻撃力に掛かり、森の軽減はそのあと（`docs/combat.md`）。盾への攻撃にも掛かる。樽の爆発のダメージは変わらない（射程だけ伸びる）。
- バリアには防がれる（0 ダメージで、照準もバリアも消える）。

### イベント

`SkillUsedEvent`、`StatusAppliedEvent`（照準、残り 2）、`UnitActedEvent`。
撃ったときは、`AttackDamagedEvent`（`critical` が真）のあとに `StatusRemovedEvent`（`CONSUMED`）。

## 決めたこと（仕様の食い違い）

- **「移動しなかった場合」は、構えてから撃つまでの間。** 元の仕様は「そのターン移動しなかった場合、次の自フェーズ開始時に付与」で、
  どのターンの移動かが読み取れなかった。こちらでは、スキルを使うと行動が終わる（そのターンは動けない）ので、
  残るのは「次の番に、動いてから撃てるか」だけ。**撃てない**ことにした。
  射程 4 + 3 に移動 3 が足されると、盤のほとんどに 2 倍の攻撃が届いてしまう。構えたマスに縛れば、相手は届く範囲を見て対処できる。
- **射程は、構えた時から伸びる**（元の仕様は、次の自分の番の始めに付く）。届く範囲を相手に見せるため。攻撃できる時は変わらない。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| クールダウン | 3 | `PrecisionAimSkill.COOLDOWN` |
| 照準の残りのターン数 | 2 | `PrecisionAimSkill.AIM_TURNS` |
| 伸びる射程 | 3 | `PrecisionAimSkill.RANGE_BONUS` |
| 確定クリティカルの倍率 | 200% | `PrecisionAimSkill.CRITICAL_PERCENT` |

- 伸びる射程 3 と 2 倍は仕様のまま。射程 7 は、スナイパーが歩いて撃てる距離（移動 3 + 射程 4）と同じで、届く距離そのものは広がらない。
  得るのは「歩かずに届く」ことと、1 回ぶんの手番を次の番へ持ち越して 1 発にまとめること（9 + 9 を 18 に）。
- クールダウン 3 は、構える → 撃つ → 1 ターン空く、の周期。
- CPU どうしの対戦（軍の違う 240 局、シード 1〜240。`docs/unit-roster.md` の「軍の釣り合い」）での MILITARY の勝率。
  ディバインシールドと一緒に入れて測った。

  | 伸びる射程、倍率 | 予算どおり | 同じ 6 体 |
  | --- | --- | --- |
  | 入れる前（スキル 4 種） | 55.0% | 26.7% |
  | **3、200%（いま。仕様のまま）** | **59.6%** | **24.8%** |
  | 2、200% | 60.3% | 20.6% |
  | 3、150% | 58.2% | 19.3% |
  | 3、200% で、CPU が精密照準を使わない | 58.1% | - |
  | 3、200% で、CPU がディバインシールドを使わない | 59.4% | - |

  弱めても予算どおりは動かず（240 局での 3〜4 ポイントは、ぶれの中）、同じ 6 体が FANTASY へ寄るだけだったので、仕様の値のままにした。
  予算どおりの 59.6% は枠（40〜60%）の上の端。別のシード（241〜480）では、入れる前 59.0%、いま 63.0%。
- CPU のスナイパー 1 体が 1 局に 2.4 回（予算どおり）、1.9 回（同じ 6 体）使う。

## CPU

`CpuPlayer.SKILL_VALUES` の `_aim_value`。

- 次の自分の番に、構えたマスから強めた攻撃を当てられそうな敵のうち、いちばん価値の高い 1 体ぶんを見込む。
  当てたときのダメージは、構えたあとの複製にルールで聞く（確定クリティカル、森、煙幕、バリアを通った値）。
  - いま伸びた射程の中にいる敵: その攻撃の価値の `AIM_RATE`（0.4）倍。
  - 相手が 1 回動けば入ってくる距離の敵: `AIM_WATCH_RATE`（0.2）倍。
  - **いまの位置から攻撃できる敵は数えない**（構えるより、いま撃つほうが早い）。
- 歩いて撃てる相手がいれば、ふつうはそちらを選ぶ。歩くと危ない、歩いても届かない、次の 1 発で倒せる、というときに構える。
- 構えている駒は、いまのマスからは伸びた射程で、ほかのマスからはもとの射程で、攻撃する手を比べる（`Statuses.stat_after_move`）。
- 相手の構えたスナイパーの危険（2 倍のダメージ）は、危険の見積もりに入れていない。
