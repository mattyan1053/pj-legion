# 精密照準（スナイパー）

コード: `rules/skills/precision_aim_skill.gd`。テスト: `tests/rules/skills/test_precision_aim.gd`。
共通の決まり（使える条件、クールダウンの数え方、イベントの順）は `docs/active-skills.md`。
照準そのものの決まりは `docs/unit-statuses.md` と `docs/combat.md` の「ダメージの解決」（テストは `tests/rules/test_statuses.gd`）。

## いまの仕様

- **動かずに構える。次の自分の番、構えたマスからの攻撃 1 回が、射程 +3（`PrecisionAimSkill.RANGE_BONUS`）、
  ダメージ 200%（`PrecisionAimSkill.CRITICAL_PERCENT`。確定クリティカル）になる。**
- 使えるのは、**このターンにほかのマスへ動いていない**駒だけ（動いたあとは使えない。移動を取り消せば使える）。
  使うと行動を終えるので、使ったターンは動かないことになる。
- 使うと、自分に照準が付く（残り 2 ターン（`PrecisionAimSkill.AIM_TURNS`））。**射程は、付いた時から伸びる**（その番はもう攻撃できないが、
  相手は、構えたスナイパーの届く範囲を自分の番に見て、外へ出るか、煙幕・盾・バリアで受けるかを選べる）。
- 照準は、次のどれかで消える。
  - **攻撃を 1 回した**（駒・樽・盾のどれでも。煙幕に阻まれても）。伸びた射程と確定クリティカルは、その 1 回だけ。
  - **ほかのマスへ動いた**（取り消せば戻る）。動いてから撃つ攻撃は、ふつうの射程とダメージ。
  - **スキルで入れ替えられて、ほかのマスへ移った**（シャドウステップ。移動の取り消しでは戻らない）。
  - **期限**: 次の自分の番に撃たなければ、その次の自分の番の始めに消える。
- 確定クリティカルの倍率は攻撃力に掛かり、森の軽減はそのあと（`docs/combat.md`）。盾への攻撃にも掛かる。樽の爆発のダメージは変わらない（射程だけ伸びる）。
- バリアには防がれる（0 ダメージで、照準もバリアも消える）。

### イベント

`SkillUsedEvent`、`StatusAppliedEvent`（照準、残りは `AIM_TURNS`）、`UnitActedEvent`。
撃ったときは、`AttackDamagedEvent`（`critical` が真）のあとに `StatusRemovedEvent`（`CONSUMED`）。

## 決めたこと

- **強めた攻撃は、構えたマスからだけ。** 次の番に動いてから撃てると、伸びた射程に移動が足され、盤のほとんどに強めた攻撃が届いてしまう。
  構えたマスに縛れば、相手は届く範囲を見て対処できる。
- **射程は、構えた時から伸びる**。届く範囲を相手に見せるため。攻撃できる時（次の自分の番）は変わらない。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| クールダウン | 3 | `PrecisionAimSkill.COOLDOWN` |
| 照準の残りのターン数 | 2 | `PrecisionAimSkill.AIM_TURNS` |
| 伸びる射程 | 3 | `PrecisionAimSkill.RANGE_BONUS` |
| 確定クリティカルの倍率 | 200% | `PrecisionAimSkill.CRITICAL_PERCENT` |

- 伸びた射程は、スナイパーが歩いて撃てる距離（移動 + 射程）と同じで、届く距離そのものは広がらない。
  得るのは「歩かずに届く」ことと、1 回ぶんの手番を次の番へ持ち越して、2 回ぶんの攻撃を 1 発にまとめること。
- クールダウンは、構える → 撃つ → 1 ターン空く、の周期。

## CPU

`CpuPlayer.SKILL_VALUES` の `_aim_value`。

- 次の自分の番に、構えたマスから強めた攻撃を当てられそうな敵のうち、いちばん価値の高い 1 体ぶんを見込む。
  当てたときのダメージは、構えたあとの複製にルールで聞く（確定クリティカル、森、煙幕、バリアを通った値）。
  - いま伸びた射程の中にいる敵: その攻撃の価値の 0.4 倍（`CpuPlayer.AIM_RATE`）。
  - 相手が 1 回動けば入ってくる距離の敵: 0.2 倍（`CpuPlayer.AIM_WATCH_RATE`）。
  - **いまの位置から攻撃できる敵は数えない**（構えるより、いま撃つほうが早い）。
  - もう構えていれば 0。
- 歩いて撃てる相手がいれば、ふつうはそちらを選ぶ。歩くと危ない、歩いても届かない、次の 1 発で倒せる、というときに構える。
- 構えている駒は、いまのマスからは伸びた射程で、ほかのマスからはもとの射程で、攻撃する手を比べる（`Statuses.stat_after_move`）。
- 相手の構えたスナイパーは、危険の見積もりで、構えたマスから伸びた射程と 2 倍のダメージで数える（`docs/cpu-ai.md`）。
