# シャドウステップ（スペルブレード）

コード: `rules/skills/shadow_step_skill.gd`、`rules/events/unit_teleported_event.gd`、`rules/events/units_swapped_event.gd`。
テスト: `tests/rules/skills/test_shadow_step.gd`。
共通の決まり（使える条件、クールダウンの数え方、イベントの順）は `docs/active-skills.md`。
最初の「行動を終えないスキル」（同じ文書の「行動を終えないスキル」）。

## いまの仕様

- **縦・横・斜めの 8 方向に 3 マス以内のマスへ、間を通らずに移る。続けて攻撃できる。**
- **見るのは、着くマスだけ。** 間のマスにある壁、駒（敵も味方も）、盾、樽、敵の支配領域（ZOC）は関係ない。
- 着けるマスは、駒が立てるマス（盤の中で、障害物・樽・盾でない。森でもよい）で、
  - **空いている**: そこへ移る。
  - **敵がいる**（相手の陣営の駒と、中立の駒）: **その駒と位置を入れ替える。** ダメージは無い。
  - 味方のいるマスは選べない。
- **使っても行動を終えない。** 1 回の行動は「移動（1 回まで）→ シャドウステップ → 攻撃・待機」になる。
  - 歩いたあとでも、歩かずにでも使える。**跳んだあとは歩けない。** 巡航で動いた駒は使えない（共通の決まり）。
  - 跳んだあとは、攻撃（駒・樽・盾）を 1 回するか、待機して行動を終える。
  - **跳んだら、取り消せない。** 歩いてから跳んだときも、歩く前には戻れない。
- 位置が変わった駒（跳んだ駒、入れ替えられた駒）の、動くと外れる状態（照準）は外れる。
  構えた相手のスナイパーと入れ替われば、照準を解ける（`docs/unit-statuses.md`）。

### ほかの決まりとの関係

- **ポータル**: 着いたマスがポータルでも、転移しない（ポータルが働くのは、移動の道の中だけ）。入れ替えられた駒も同じ。
- **本陣の占拠**（`docs/win-conditions.md`）: 位置が変わった時点で、ほかの移動と同じに見る。
  - 敵の本陣に乗っていた駒が跳んで出ると、占拠の数は 0 に戻る（取り消せないので、戻らない）。
  - **自分の本陣に乗っている敵と入れ替わると、その敵の占拠は 0 に戻る**（かわりに自分が本陣に乗る）。
  - 敵の本陣にいる敵（将でも）と入れ替われば、自分が敵の本陣に乗る。数えるのは、いつもどおりフェーズの終わり。
- **回復の泉、聖域、煙幕**: マスにあるものなので、着いた先・入れ替えられた先のものを、ふつうに受ける。
- **相手の駒の行動の状態**は変わらない（入れ替えられても、次の自分の番にふつうに行動できる）。

### イベント

`SkillUsedEvent` のあとに、

- 空いたマスへ: `UnitTeleportedEvent`（駒、もとのマス、着いたマス）
- 敵のいるマスへ: `UnitsSwappedEvent`（跳んだ駒ともとのマス、入れ替えられた駒ともとのマス）

続けて、動くと外れる状態が外れた `StatusRemovedEvent`（`MOVED`。跳んだ駒、入れ替えられた駒の順）。
**`UnitActedEvent` は出ない。** 本陣の占拠が途切れたら、最後に `CaptureProgressEvent`。

## 決めたこと（仕様の食い違い）

- **「発動で行動済み」の例外にした**（Issue #8 の「決めること 6」）。元の仕様は、共通の決まりで「スキルの発動は行動済みになる」、
  シャドウステップで「ワープ直後に通常攻撃を 1 回行える」と書いていた。跳んで終わりでは、囲まれに行くだけの手になる。
  跳んで斬る・入れ替えて斬るところまでが 1 つの手、とした。
- **歩いてから跳べる。跳んでからは歩けない**（元の仕様の「移動後のスキル発動は可能」「ワープ後は移動力を使い果たした扱い」のとおり）。
- **跳んだら取り消せない。** 元の仕様には無い。取り消せると、入れ替えた相手・解けた照準・クールダウンを全部戻すことになり、
  「跳んで、攻撃の見込みを見てから戻す」下見にも使えてしまう。跳ぶ前に、対象を選ぶ間の見込みで確かめる。
- **入れ替えられるのは敵だけで、中立の駒も入る**（元の仕様は「敵ユニット」）。攻撃できる相手と同じ範囲にそろえた。
- **将とも入れ替われる。** 例外を作っていない。将を前へ引きずり出せるが、入れ替わった自分は敵の本陣の側に 1 体で残る。

## 脅威範囲

`docs/threat-range.md`。跳べるマスから、続けて攻撃が届く（`threat_origins`）。歩いてから跳ぶので、止まれるマスのそれぞれから跳ぶ先を数える。

## 調整値

| 値 | いま | 場所 |
| --- | --- | --- |
| クールダウン | 3 | `ShadowStepSkill.COOLDOWN` |
| 跳べる距離（8 方向に） | 3 | `ShadowStepSkill.RANGE` |

- 距離 3 とクールダウン 3 は、仕様の距離と、ほかのスキルの周期に合わせた値。**弱めていない**
  （予算どおりの対戦を FANTASY の側へ戻すスキルなので。下の表）。
- 届く距離: 歩いて 6 + 跳んで 3（斜めなら、歩数にして 6）+ 攻撃 1。壁も戦線も越えるので、後ろのスナイパーに
  1 手で届く。かわりに、跳んだ先に 1 体で残る。
- CPU どうしの対戦（軍の違う 240 局。`docs/unit-roster.md` の「軍の釣り合い」）での MILITARY の勝率。
  アドレナリン注射と一緒に入れて測った。

  | 予算どおり | シード 1〜240 | シード 241〜480 |
  | --- | --- | --- |
  | 入れる前（スキル 6 種） | 59.6% | 63.0% |
  | **いま（8 種）** | **51.0%** | **58.9%** |
  | CPU がシャドウステップを使わない（アドレナリン注射は、反動が次の番からの形） | 65.7% | 74.1% |
  | CPU がアドレナリン注射を使わない | 49.4% | 55.3% |

  シャドウステップだけで、FANTASY へ 8〜10 ポイント。同じ 6 体は 22.9% / 26.8%（入れる前はシード 1〜240 で 24.8%）。
- CPU のスペルブレード 1 体が 1 局に 1.3 回（予算どおり）、1.4 回（同じ 6 体）使う。プレイヤーの駒を倒した数は 1 体あたり 0.25 → 0.45。
- **上の数字は、スキルの強さを低く出している。** 測ったときの CPU の奇襲は、1 体で敵の本陣へ向かって囲まれ、スペルブレードの 86〜89% が
  倒されていた。跳ぶのも「歩いた先でたまたま届いた」ときだけだった。
- **CPU を強くしたあと**（奇襲が軍のそばからやわらかい駒を狙い、跳ぶために立つマスを探す。`docs/cpu-ai.md` の「いまの集計」）は、
  スペルブレード 1 体が 1 局に 1.8 回跳び、プレイヤーの駒を 1.6 体倒す（0.45 → 1.6）。倒される割合は 74〜75%。
  予算どおりの MILITARY の勝率は 40.0% / 40.7% まで下がった。跳んだあとの帰り道は、いまも考えていない。
  **人が使えば、もっと強い**: 戦線の後ろのスナイパーへ 3 ターンに 1 回、届かれない距離から斬り込める（レベル 1 どうしなら、HP 13 に 12 で、一撃では落ちない。`docs/unit-roster.md` の「スナイパーと奇襲」）。構えたスナイパーの照準を解ける。
  本陣の占拠を切れる。将を 3 マス引きずり出せる。強すぎたら、先に触るのは距離（3 → 2）か、「歩いたあとは跳べない」にすること。

## CPU

`CpuPlayer.SKILL_VALUES` の `_shadow_step_value`。

- 跳んだあとの複製の上で、続けてできる攻撃（駒・樽・盾）を全部やってみて、いちばん良いものの価値を取る。
  それに、立つマスの価値の差（跳んだ先 − いまのマス。危険、目標への近さ、本陣）を足す。
- **攻撃できる相手がいなければ跳ばない**（逃げる・近づくだけには使わない）。例外は 2 つ:
  敵の本陣のマスに着く手と、自分の本陣に乗っている敵と入れ替わる手（占拠を切る。`OCCUPIER_KILL_BONUS` を足す）。
- 跳んだあとは、動いたあとの駒と同じに、いまの位置からの攻撃か待機を選ぶ（見積もりと同じ計算なので、見込んだ攻撃をする）。
- **跳ぶために立つマスを探す**（共通の決まり。`docs/cpu-ai.md`）。歩いて 6 + 跳んで 3 の先の敵を狙う。
  試す跳び先は（`_shadow_step_targets`）、歩いては攻撃が届かない敵を攻撃できるマス、空いている敵の本陣、
  自分の本陣に乗っている敵のマス。歩いて届く敵は、歩いて攻撃する手が比べているので、跳び先に入れない。
  **中立の駒を殴るためには跳ばない**（跳べるのは 3 ターンに 1 回。相手のプレイヤーの駒のために取っておく。
  跳んだ先から中立の駒も殴れるなら、続けてできる攻撃としては比べる）。
- 相手のスペルブレード（スキルが明けているもの）が跳んで届くマスは、危険の見積もりに入れる（`docs/cpu-ai.md`）。
