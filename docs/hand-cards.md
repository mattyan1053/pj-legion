# 手札（試し）

コード: `rules/card.gd`（`Card`。札の種類と調整値、軍ごとの山）、`rules/hand.gd`（`Hand`。配る・引く・使う）、`rules/actions/play_card_action.gd`、
`rules/events/card_drawn_event.gd`・`card_played_event.gd`・`card_healed_event.gd`・`unit_pushed_event.gd`、`rules/cpu/cpu_cards.gd`（CPU）、
`game/battle_hud/hud_hand.gd`（手札の帯）、`game/battle_screen/screen_input.gd` の `press_card`。
テスト: `tests/rules/test_hand.gd`、`tests/game/test_steady_frames.gd`（帯の大きさ）、自動の対戦の場面 `hand`（`game/autoplay/board_checks.gd`）。

**試しの決まり。** 人間の「カードゲームの手札的な要素が少ない。いったん愚直に、手札の要素をそのまま戦闘に付けてみる」（Issue #47 の 11/26）を、
触って確かめるためのもの。入れるか・形を変えるか（引く形か、対戦の前に持ち込む形か）は、遊んでから人間が決める。
対戦設定の選べる決まり `hand`（`OptionalRules.HAND`。`docs/match-setup.md`）で、**既定は切**。切のとき、対戦は 1 手も変わらない。ストーリーには入れない。

画面では「手札」、1 枚ずつは「札」と呼ぶ。

## いまの仕様

- 軍ごとに札の山を持つ（下の表）。対戦を作るとき、対戦の種で混ぜる（`Hand.arm`。対戦の乱数 `Battle.rng` は進めない。同じ種なら同じ並び）。
- 始めに 3 枚（`START_CARDS`）。自分の番の始めに 1 枚（`DRAW_PER_PHASE`）引く（`CardDrawnEvent`。必殺技のゲージがたまったあと）。
  先手の最初の番は、番の始めが無いので引かない（後手は最初の番から引く）。
- 手札は 5 枚（`HAND_LIMIT`）まで。5 枚あるときは引かない（その札は山に残る）。山が尽きたら引かない。
- 自分の番に 1 枚（`PLAYS_PER_PHASE`）だけ使える（`PlayCardAction`）。**兵の行動は使わない。** 行動の途中の兵（動いたが、攻撃も待機もしていない）がいる間は使えない。
- 使った札は無くなる（山へは戻らない）。
- 起きることの順: `CardPlayedEvent`（陣営、札、相手の兵、マス、動かす先、残りの手札の枚数）→ 札の効果の出来事。
- **脅威範囲と CPU の危険の読みは、手札を数えない**（試しのうちの決め）。相手の手札は見えないので、「次の番に届くマス」は、札を使わないものとして出す。
  相手の進軍（移動 +2）・転移・号令で、表示より遠くから届くことがある。相手の手札の枚数は、帯の右に出る。
- 戦績と MVP には入れない（札の回復は、誰の回復量にも数えない）。

## 札

相手を選ぶ札は、兵を 1 体選ぶ。押し出しと転移は、続けて、動かす先のマスを選ぶ。

| 札 | 効果 | 相手 | 連邦の山 | 騎士領の山 |
| --- | --- | --- | --- | --- |
| 進軍（`MARCH`） | 移動力 +2。次の自分の番の始めまで（状態の「進軍」。`Status.Type.HASTE`） | まだ行動していない味方（絡みの兵は除く） | 4 | 3 |
| 強打（`MIGHT`） | 攻撃力（回復役は回復量）+3。次の自分の番の始めまで（状態の「強打」。`Status.Type.MIGHT`）。攻撃力に足すので、ダメージの段の前（`docs/combat.md`） | まだ行動していない味方 | 4 | 4 |
| 手当て（`MEND`） | HP を 8 回復（`Mend.give`。`CardHealedEvent`） | HP の減っている味方 | 3 | 3 |
| 押し出し（`SHOVE`） | 隣の空いたマス（上下左右）へ 1 マス動かす（`UnitPushedEvent`。動くと外れる状態は外れる。本陣から出れば、占拠の数は戻る） | 味方と隣り合う、相手の兵（中立は除く） | 3 | 3 |
| 号令（`ENCORE`） | 行動前に戻す。反動が付く（アドレナリン注射と同じ出来事と状態。`UnitReactivatedEvent`） | 行動済みの味方 | 3 | - |
| 補給（`RESUPPLY`） | 味方の全員の HP を 3 回復 | 選ばない | 3 | - |
| 加護（`WARD`） | バリアを付ける（ディバインシールドと同じ状態と期間） | バリアの無い味方 | - | 4 |
| 転移（`BLINK`） | 3 歩以内の空いたマスへ移す（`UnitTeleportedEvent`。行動済みの兵も移せる） | 味方 | - | 3 |

## 調整値

| 値 | いま | 意味 |
| --- | --- | --- |
| `Hand.START_CARDS` | 3 | 始めの手札の枚数 |
| `Hand.HAND_LIMIT` | 5 | 手札の上限 |
| `Hand.DRAW_PER_PHASE` | 1 | 自分の番の始めに引く枚数 |
| `Hand.PLAYS_PER_PHASE` | 1 | 1 つの番に使える枚数 |
| `Card.PILE_SIZE` | 20 | 山の枚数（軍ごとの内訳は上の表。`Card.PILES`） |
| `Card.MARCH_MOVE` | 2 | 進軍で上がる移動力 |
| `Card.MIGHT_POWER` | 3 | 強打で上がる攻撃力 |
| `Card.BOOST_TURNS` | 1 | 進軍・強打の残りのターン数（次の自分の番の始めに外れる） |
| `Card.MEND_HEAL` | 8 | 手当ての回復量 |
| `Card.RESUPPLY_HEAL` | 3 | 補給の回復量（1 体あたり） |
| `Card.BLINK_RANGE` | 3 | 転移で移せる歩数 |

数は仮。CPU どうしの実測は `docs/cpu-ai.md` の「いまの集計」の「手札（試し）」。

## CPU

`CpuCards.pick`（`rules/cpu/cpu_cards.gd`）。`CpuPlayer` が、兵を動かす前に毎回聞く。複製の上で読み比べず、札ごとの単純な決まりで選ぶ。自分の手札だけを見る。

- 手当て: 8（`CpuCards.MEND_MISSING`）以上減っている味方（将は半分で）。補給: 戻る HP の合計が 6（`CpuCards.RESUPPLY_TOTAL`）以上。
- 加護: 相手の兵が次の番に届きそうな味方（将を先に、次に HP の少ない兵）。
- 強打: まだ行動していない戦う兵で、敵に手が届くもの。進軍: あと 2 歩で敵に手が届くもの。
- 号令: 全員が動いたあと、敵に手が届く行動済みの戦う兵。
- 押し出し: 自分の本陣・拠点・回復の泉に乗っている敵をどかす。転移: 狙われていて HP が 40%（`CpuCards.BLINK_HP_PERCENT`）以下の味方を、敵からいちばん遠いマスへ。
- 手札が 4 枚（`CpuCards.SPEND_AT`）以上なら、条件をゆるめて使う（進軍・押し出し・転移を、前へ出る・寄せる向きに）。

## 画面

- **対戦設定**に「手札」の行（あり・なし）。
- **手札の帯**: 下の帯のすぐ上、情報の枠の右。札の欄は 5 つで、枚数が変わっても帯の大きさは同じ（空の欄が残る。`Steady` の印 `battle.hand`）。
  左に山の残り、右に相手の手札の枚数。欄の上の線の色は札の種類（強める = 金、治す・守る = 緑、動かす = 水色、相手に使う = 赤）。
  使えない札は沈める（相手の番、この番にもう使った、行動の途中の兵がいる、相手がいない）。
- **札にマウスを乗せる**と、帯の上に名前と効果の 1 文（使えないときは、その理由）。
- **使う**: 札を押す → 選べる兵のマスが塗られる → 兵にマウスを乗せると予測のパネル → クリックで使う。
  押し出しと転移は、兵をクリックすると、動かす先のマスが塗られる（もう 1 度クリックで使う）。右クリックで 1 段戻る。
  補給（相手を選ばない札）は、1 回目は確かめるだけで、もう一度押すと使う（その間、予測のパネルが出る）。
- 人どうしの対戦では、番の人の手札を出す。CPU との対戦では、いつも人の手札。
- **再生**: 使った札の名前を、相手の兵の上に出す（相手を選ばない札は中央の知らせ）。続く効果は、いつもの再生（状態・回復・再行動）。押し出しは隣へ滑る。
- **ログ**: 「青が◯◯に札「進軍」を使った」（続く効果は同じ行の細目）。引いたときは「青が札を引いた（手札 4 枚）」。どの札かは書かない。

## 札を足すとき

1. `rules/card.gd`: `Id` に 1 つ、`aim`（相手の選び方）、`summary_args`、`PILES` の枚数（合わせて `PILE_SIZE`）。
2. `rules/hand.gd`: `_suits`（選べる兵）と `play`（効果）。回復は `Mend.give`、状態は `Statuses.add`（`docs/unit-statuses.md` の「状態を足すとき」）。
3. 文: `game/text/names.csv` の `card.<名前>` と `card.<名前>.summary`。帯の線の色は `hud_hand.gd` の `card_color`。
4. CPU: `rules/cpu/cpu_cards.gd` の `_choose`。足さないと、CPU はその札を使わない（検査は落ちない）。
5. 新しい出来事が要るなら `docs/battle.md` の「出来事を 1 つ足すとき」。
