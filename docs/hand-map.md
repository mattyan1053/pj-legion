# 手で作ったマップ

コード: `rules/hand_map.gd`（`HandMap`）、`game/maps.gd`（マップのファイルを読む）。マップは `game/maps/`（1 マップ 1 ファイル）。テスト: `tests/rules/test_hand_map.gd`。

文字の格子（1 文字 1 マス、1 行が盤の 1 行、上の行から）から盤面（`Board`）を作る。
自動生成（`docs/game-board.md`）と並ぶ、盤のもう 1 つの出どころ。戦いの定義（`docs/scenario.md`）の `hand_map` に渡して使う。
マップが持つのは盤の形だけ。初期位置と部隊は戦いの定義が持つ（同じマップを使い回すため）。
対戦モードで選べるかは、マップではなく対戦モードの一覧（`game/versus_fields.gd`。`docs/map-select.md` の「選べる盤」）が決める。

## 文字

| 文字 | マス |
| --- | --- |
| `.` | 平地 |
| `#` | 障害物 |
| `F` | 森 |
| `*` | 結晶泉（`Board.font_cells` にも入る。中立の駒が湧く） |
| `1`、`2` | プレイヤー1・プレイヤー2 の本陣（地形は平地） |
| `M` | 中ボスの場所（地形は平地）。上の行から、左の列からの順に番号 0、1 が付く（聖遺物が番号で決まる。`docs/neutral-mid-boss.md`） |
| `B` | 起爆樽（地形は平地） |
| `S` | 回復の泉（地形は平地） |
| `C` | 砲台（地形は平地。`docs/map-objects.md` の「砲台」）。マップの物なので、書けば、そのマップを使うどの対戦にもある（対戦モードも、話も） |
| `H` | 拠点の場所（地形は平地。1 つまで）。拠点が入の対戦（対戦モードの既定）でだけ拠点になる（`docs/map-objects.md` の「拠点」）。書かなければ、両方の本陣からの道のりで選ぶ。ほかの対戦では、ただの平地 |
| `a`〜`z` | ポータル（地形は平地）。同じ文字の 2 マスが対になる |

文字は、テストで盤を書く道具（`tests/support/maps.gd`）とそろえてある。ただしポータルは、数字を本陣に使うので英小文字。

## 検査

`HandMap.problems()` が空でないマップは盤にしない（`make_board()` が `null`。対戦設定では `NO_BOARD`）。

| 理由（`HandMap.Problem`） | 条件 |
| --- | --- |
| `EMPTY` | 行が無い、または空の行がある |
| `RAGGED` | 行の長さがそろっていない |
| `UNKNOWN_CHAR` | 上の表に無い文字がある |
| `HQ_COUNT` | 本陣（`1` と `2`）が 1 つずつでない |
| `MID_BOSS_COUNT` | 中ボスが 0 か 2 でない |
| `PORTAL_PAIR` | ポータルの文字が、ちょうど 2 マスずつでない |
| `HQ_NOT_CONNECTED` | 本陣どうしが、入れるマスを上下左右にたどってつながっていない（樽はふさぐ。ポータルは使わない） |
| `MID_BOSS_UNREACHABLE` | プレイヤー1 の本陣から歩いて行けない中ボスがいる |
| `STRONGHOLD_COUNT` | 拠点の場所（`H`）が 2 つ以上ある |
| `STRONGHOLD_UNUSABLE` | 拠点の場所に拠点を置けない（中ボスの家から 4（`Stronghold.BOSS_CLEARANCE`）マス以内か、どちらかの本陣から歩いて行けない） |

形の理由（`EMPTY`〜`PORTAL_PAIR`）があれば、つながりは調べない。
`game/maps/` のマップは、どれもテストが検査し、両方の軍（既定の編成）がいつもの置き方で全員置けることも確かめる。
長い検査（`test_long_`）は、どのマップでも CPU どうしの対局（先手と後手の軍を入れ替えて 2 局）が 60 ターンまでに決着することを確かめる。

## マップのファイル

`game/maps/` に 1 マップ 1 ファイル（テキスト。ファイルの名前がマップの id）。話のファイル（`docs/story.md`）は `map = <id>` で、対戦モードの一覧（`game/versus_fields.gd`）は id で指す。
一覧はここには置かない（`game/maps/` を見る。どのマップも、ファイルの頭に形と作ったねらいの説明がある。どの話が使うかは、ファイルの頭に一覧を書かず、`game/story/<物語>/` を `map =` で探す）。ストーリーのチュートリアルの話には、教えることだけが起きる小さな盤（中立の駒の無い盤、中立の駒を教える盤）を置いている（`docs/story.md`）。

```
# 説明（# で始まる行は読み飛ばす）
[map]
title = 練兵場
look = stone_walls

[rows]
....2....
...#.#...
....1....
```

- 書式は話のファイルと同じ（`game/story_file.gd`）。`[map]` に名前（`title`。戦いの定義の名前、決着の画面の「マップ」）と見た目（`look`。景色。`stage_look.gd` の見た目の名前。`docs/battle-view.md` の「マップの見た目」）、`[rows]` に文字の格子。
  **景色はマップが決める**（対戦モードでも、ストーリーでも、そのマップの景色になる）。`look` を書かなければ草原。話のファイルが `look` を書けば、その話だけ別の景色にできる（同じ盤を別の場所として使う話）。
  **`[rows]` の中では `#` で始まる行も読み飛ばさない**（`#` は障害物の文字）。説明は `[map]` より前に書く。
- 読むのは `game/maps.gd`（ルールはファイルを読まない。読んだ `HandMap` を戦いの定義に渡す）。書き間違い（`title` が無い、知らない見た目、行の長さの違い、上の「検査」の理由）は「ファイル:行:」で出す。
  拠点の場所の間違いは、その `H` のある行で言う（2 つ目の `H` の行、置けない `H` の行と列）。
- 書き出した exe に入れるため、`export_presets.cfg` の `include_filter` に `game/maps/*` がある。

## マップを作るときのめやす

CPU どうしの実測から分かったこと（数字は `docs/cpu-ai.md` の「いまの集計」と、それぞれの PR の本文）。対戦モードのマップにも、ストーリーの話のマップにも効く。

- **釣り合いは、部隊を変えて測る。** 手で作ったマップは種を変えても盤が同じで、乱数は中立の駒の湧き直しだけ。
  決まった部隊どうしだと、ほとんど同じ局を何度も数えることになり、形や部隊を少し変えただけで勝者がまるごと入れ替わる
  （集計の道具の `--squads=random`。中立の駒の無いマップは、決まった部隊ならどの種でも同じ 1 局になる）。
  試しの形は `game/maps/` に足す前に、`--map=<ファイル>` で測れる。
- **盤が小さいこと自体は、偏りの元にならない。** 生成のマップよりずっと小さい盤でも、部隊を変えれば同じくらいの釣り合いになる。
  駒の数値と CPU は、小さい盤のために変えない。
- **先に相手の届く所へ入った側が、先に撃たれる。** 後衛（スナイパーの射程 4、ソーサラーの射程 2）は、待つ側が先に当てる。
  小さい盤では、両軍がぶつかるまでの手数が短く、後手（相手の動きを見てから動く側）が得をしやすい。
  - **相手の陣地のただ中へ出るポータルは置かない。** 先に跳んだ側が、待つ側の後衛にまとめて撃たれる（結晶の岩山では、ポータルを平地にすると先手の勝率が大きく振れた）。
  - **本陣どうしは離す。** 結晶の岩山で、本陣を盤の角へ寄せて遠くすると、先手の勝率が釣り合いのほうへ動いた。
    大岩の峠は、縦に長い盤の上下の端に本陣を置いている。
- **道は広めに。** 大岩の峠は、左右の道を幅 7 にした。幅 2 の道（結晶の岩山の端の回り道）が釣り合いをどう動かすかは、まだ測っていない。
- **中立の駒は、本陣から同じ歩数に。** 点対称にすれば自然にそろう。中ボスは 2 体（0 か 2 しか置けない）、結晶泉は 1〜2 つで足りる。
  中立の駒を無くしても、釣り合いは大きくは動かない（結晶の岩山で確かめた）。
- **奇襲が早く本陣へ届く。** 小さい盤では、スピードブーツを重ねた奇襲が数ターンで空いた本陣へ乗ることがある
  （部隊を変えて測ると、本陣の占拠の決着が、生成のマップより多い）。
- **拠点の場所（`H`）は、測って決める。** 両方の本陣から道のりが同じでも、先手・後手のどちらかに大きく傾くことが多い。
  特に、拠点へ向かう道で片方だけが中ボスのそばを通ると、その側が着くのに遅れる（大岩の峠）。真ん中から外れたマスも候補にして、部隊を変えて測る。
- **点対称にする。** 本陣どうしを入れ替えて同じ形なら、軍の違い（先手・後手を入れ替える）だけを測れる。
