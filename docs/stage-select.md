# ステージ選択

コード: `game/stage_select_screen.gd`（場面）、`game/stage_card_map.gd`（カードの縮図。ノードに依存しない）。
テスト: `tests/game/test_stage_card_map.gd`、`tests/game/test_scene_flow.gd`、自動の対戦（タイトル → ステージ選択 → 対戦の設定と戻る道）。
盤の形は `docs/game-board.md`、置かれるものは `docs/map-objects.md`。

## 場面

タイトルの「始める」のあと、対戦の設定の前（`docs/scene-flow.md`）。

- 見出し「作戦領域を選ぶ」（SELECT BATTLEFIELD）と、3 枚のカード（中央平原・迷宮回廊・双子結晶）を横に並べる。
- カードには、そのステージの**盤の縮図**、番号と名前、置かれているもの（「広場 ・ 起爆樽」など）を載せる。
- マウスを乗せたカードは明るくなり（金の縁）、少し大きくなって、下の欄にステージの説明が出る。乗せていなければ、選び方の案内を出す。
- カードをクリック（1〜3 のキーでも）すると、選んだステージを対戦の設定（`context.match_choice`）に入れて、対戦の設定へ進む。
- 「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ。対戦の設定の「ステージ選択へ戻る」（右クリック・Esc でも）で、ここへ戻る。
- 背景はタイトルと同じ景色（`backdrop.gd`）。曲もタイトルと同じ（途切れない）。

対戦の設定のパネルにも、ステージの行を残している（対戦の途中で開く設定画面と同じものなので）。ステージ選択で選んだものが、そこに選ばれた状態で出る。

## カードの縮図

絵は描かず、ルールが作る盤（`BoardGenerator.generate`。種は `MAP_SEED` で固定）を、マスごとに色で塗る（1 マス `CELL` px。表示は拡大）。

| もの | 色 |
| --- | --- |
| 平地・森・岩（障害物）・結晶泉 | ステージの色合い（`stage_look.gd`）。岩は暗くする |
| 本陣 | 陣営の色。周りの 8 マスは暗い陣営の色 |
| 中ボス | 紫 |
| 起爆樽・回復の泉・ポータル | マスの真ん中の点（橙・水色・明るい紫） |

対戦の盤は、始めるときに種を決めて作り直すので、縮図と同じ形にはならない（ステージの性格が分かればよい）。

## 元の仕様（`stage-select`）と違うところ

- 元は対戦の設定でステージを選び直せない。ここでは対戦の設定にもステージの行が残る。
- 1〜3 のキーでも選べる。右クリック・Esc で 1 つ戻る（ほかの場面と同じ）。
