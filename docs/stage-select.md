# ステージ選択

コード: `game/stage_select_screen.gd`（場面）、`game/versus_fields.gd`（選べる盤の一覧）、`game/stage_card_map.gd`（カードの縮図。ノードに依存しない）。
テスト: `tests/game/test_versus_fields.gd`、`tests/game/test_stage_card_map.gd`、`tests/game/test_match_choice.gd`、`tests/game/test_scene_flow.gd`、
自動の対戦（タイトル → ステージ選択 → 対戦の設定と戻る道。カードが画面に収まるか。手で作ったマップでの対戦の始め）。
盤の形は `docs/game-board.md`（生成）と `docs/hand-map.md`（手で作ったマップ）、置かれるものは `docs/map-objects.md`。

## 選べる盤

対戦モードで選べる盤は、`game/versus_fields.gd` の `FIELDS` に並べる。盤は**鍵**（`StringName`。`plain`、`ridge_path` など）で持つ。
ストーリーの話（`game/story/episodes/` のファイルの名前）や見た目（`stage_look.gd` の名前）と同じ持ち方。

| 出どころ | 形 | 見た目 |
| --- | --- | --- |
| 生成のステージ（`BoardGenerator.Stage`） | 対戦を始めるたびに、種から作り直す（毎回ちがう形） | `StageLook.OF_STAGE` |
| 手で作ったマップ（`game/maps/` のファイルの id） | 種によらず、いつも同じ形 | 項目の `LOOK` |

- どちらも、対戦モードの決まりのまま: 勝ち方は将の撃破と本陣の占拠、初期位置は本陣の前、部隊は両方とも対戦の設定で選ぶ（予算と 6 体）。
  戦いの定義は `VersusFields.scenario_of(鍵)`（生成は `Scenario.versus`、手で作ったマップは `Scenario.on_map`）。
- 項目が持つもの: 鍵、出どころ、ひとことの特徴（`TAGS`。カードに載せる）、説明（`NOTE`。マウスを乗せると出す）、手で作ったマップの見た目（`LOOK`）。名前は戦いの定義の名前（生成は `MatchSetup.stage_name`、手で作ったマップはファイルの `title`）。
- **盤を 1 つ足すのは、`FIELDS` に 1 項目**（手で作ったマップなら、`game/maps/` のファイルと）。画面（カード、対戦の設定のパネル、番号のキー）と集計の道具は一覧から作る。
- 並びが画面の並びと番号。生成のステージを先に並べる（F1〜F3 と番号 1〜3 は、生成のステージのまま）。
- **対戦モードの画面に出すのは、CPU どうしの釣り合いがめやすに入る盤だけ。** めやすは、軍の違う対戦（先手・後手を入れ替える）で、両軍の部隊を局ごとに変えて、MILITARY の勝率と先手の勝率がどちらも 40〜60%（`tools/cpu_matches.gd -- --pairings=mixed --squads=random --stage=<鍵>` で 200 局以上）。
  部隊を変えるのは、手で作ったマップは種を変えても盤が同じで、CPU の決まった編成どうしだと、ほとんど同じ局を何度も数えることになるため（中立の駒の湧き直しのほかに乱数が無い）。
  外れる盤は `HIDDEN` を立てて一覧に残す（画面には出ず、番号も付かない。集計の道具では測れる）。
  いまは、どの盤もめやすに入っていて、出していない盤は無い（実測は `docs/cpu-ai.md` の「いまの集計」）。
  ストーリーの話が使うマップは、話の難しさが変わるので、対戦モードのために形を変えない。変えるなら、別のマップとして足す。

## 場面

タイトルの「対戦」のあと、対戦の設定の前（`docs/scene-flow.md`）。

- 見出し「作戦領域を選ぶ」（SELECT BATTLEFIELD）と、カードの段。
- **カードは 2 段**: 上の段が生成のステージ（見出し「生成のステージ ─ 対戦のたびに、形が変わる」）、下の段が手で作ったマップ（「手で作ったマップ ─ いつも同じ形」）。出す盤の無い段は作らない。段は上下の真ん中に寄せる。
  段の幅（3 枚）に収まらないほど増えたら、その段を横に送れる（つまみとホイール）。
- カードには、そのステージの**盤の縮図**（左）、番号と名前、置かれているもの（`TAGS`）、形の札（「毎回ちがう形」は青緑、「いつも同じ形」は金）を載せる。
- マウスを乗せたカードは明るくなり（金の縁）、少し大きくなって、下の欄に「番号 名前 特徴（形）」と説明が出る。乗せていなければ、選び方の案内を出す。
- カードをクリック（1〜9 のキーでも。番号のカード）すると、選んだ盤の鍵を対戦の設定（`context.match_choice` の `field`）に入れて、対戦の設定へ進む。
- 「タイトルへ戻る」（右クリック・Esc でも）でタイトルへ。対戦の設定の「ステージ選択へ戻る」（右クリック・Esc でも）と「ステージを選び直す」で、ここへ戻る。
- 背景はタイトルと同じ景色（`backdrop.gd`）。曲もタイトルと同じ（途切れない）。

ステージを選ぶのはここだけ。対戦の設定のパネルは、選んだステージの名前を出すだけで、「ステージを選び直す」でここへ戻る（対戦の途中で開いたパネルからも。`docs/battle-view.md` の「対戦の設定」）。

## 手で作ったマップでの対戦

- 決着の画面の「新しい盤面: ○○」と F1〜F3 は、**生成のステージだけ**（`MatchChoice.new_board_fields()`）。手で作ったマップは種を替えても同じ形なので、「新しい盤面」に入れない。
  手で作ったマップの対戦でも、ほかの行き先はいつもと同じ（同じ盤面でもう一度、新しい盤面: 生成のステージ、対戦の設定へ、タイトルへ）。ほかのマップへは対戦の設定から。
- 「同じ盤面でもう一度」は、どの盤でも同じ種で始め直す。

## カードの縮図

絵は描かず、ルールが作る盤（`VersusFields.card_board`。生成のステージは種 `MAP_SEED` で固定）を、マスごとに色で塗る（1 マス `CELL` px。表示は拡大）。

| もの | 色 |
| --- | --- |
| 平地・森・岩（障害物）・結晶泉 | ステージの見た目（`stage_look.gd`）の地面の色。岩は暗くする |
| 本陣 | 陣営の色。周りの 8 マスは暗い陣営の色 |
| 中ボス | 紫 |
| 起爆樽・回復の泉・ポータル | マスの真ん中の点（橙・水色・明るい紫） |

生成のステージの対戦の盤は、始めるときに種を決めて作り直すので、縮図と同じ形にはならない（ステージの性格が分かればよい）。手で作ったマップは縮図のとおり。
