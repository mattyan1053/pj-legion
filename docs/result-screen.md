# リザルトの画面

コード: `game/result_summary.gd`（何を出すか。ノードに依存しない）、`game/result_screen.gd`（段階的に出す）。
テスト: `tests/game/test_result_summary.gd`、自動の対戦（`game/autoplay.gd` の `_queue_result_checks`）。
数えるのは `BattleStats`（`docs/battle-stats.md`）。

## 出し方

決着すると、対戦の画面（盤面）の上に重ねて、次の順に出す。時刻は `result_screen.gd` の先頭の定数にまとめてある。

1. **勝敗の見出し**が画面の中央に大きく出る（少し大きいところから縮んで止まる）。下に決着の理由。
   - CPU 戦: 人が勝てば金色の `VICTORY`、負ければ青白い `DEFEAT`、引き分けは `DRAW`。理由の行に、どちらが勝ったかも添える。
   - 人どうし: どちらにも肩入れせず、勝った側の名前（「プレイヤー2（赤） の勝ち」。陣営の色）、引き分けは「引き分け」。
2. 見出しが**上へ退いて**小さくなり、**戦績**が 1 行ずつ出る（1 行ごとに小さくクリックの音）。
   作戦領域（ステージの名前）、経過ターン、敵軍撃破（敵のプレイヤーの駒と中立の駒（中ボスを含む）を倒した数）、聖遺物（持っていなければ出さない）。
3. **MVP** が拡大しながら出る（鈴の音）。名前（進化先・レベル）と、与えたダメージ・撃破。ダメージを与えた駒がいなければ「該当なし」。
4. **行き先のボタン**と、明滅する入力の案内が出る。

全部が出るまで、約 3.4 秒。

- **出そろうまで、行き先は選べない。** その間のクリック（Enter・Space でも）は、演出を飛ばして全部を出すだけ。
  飛ばした直後の少しの間（`SKIP_GUARD`）もボタンは押せない（飛ばしたクリックが、そのまま行き先を選ばないように）。
- 出そろったあとの Enter はタイトルへ（ボタンの「タイトルへ」と同じ）。
- 決着の曲（`docs/sound.md`）は、見出しが出るのと同時に鳴る。

## 誰の戦績を出すか

- CPU 戦は人の側。人どうしは勝った側。人どうしの引き分けはプレイヤー1。
- MVP の決め方は `BattleStats.mvp`（将を除き、敵のプレイヤーの駒に与えたダメージがいちばん多い駒。`docs/battle-stats.md`）。
- 両方の陣営の詳しい戦績（`stats_text.gd`。与えたダメージ、撃破、倒された数、回復、スキル・必殺技、レベルアップ、進化、聖遺物、陣営ごとの MVP）は、
  **畳んでおき**、「詳しい戦績（両軍）」で開く（「戦績の要点へ戻る」で閉じる）。

## 行き先

- 「同じ盤面でもう一度」、「新しい盤面: <ステージ>」（どちらも、いまの設定のまま。同じ対戦の場面で始め直す）、
  「対戦の設定へ」（対戦の設定の場面へ）、「タイトルへ」。遷移は `docs/scene-flow.md`。

## 元の仕様（`result-presentation`）と違うところ

- 元は別の場面で、行き先は「タイトルへ」だけ（全部をリセット）。ここでは対戦の場面の上に重ね、行き先を 4 つ残している（すぐもう一度遊べるように）。
- 元は出そろう前の入力を捨てる。ここでは、クリックで演出を飛ばせる（待たされない。飛ばしても、行き先は出そろってからしか選べない）。
- 撃破の数に、敵のプレイヤーの駒も含める（元はミニオンと中立の数）。
