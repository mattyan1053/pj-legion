# 決着の画面

コード: `game/result_summary.gd`（何を出すか。ノードに依存しない）、`game/stats_text.gd`（陣営の 1 行と表の列）、`game/result_screen.gd`（段階的に出す）。
テスト: `tests/game/test_result_summary.gd`、`tests/game/test_stats_text.gd`、`tests/game/test_result_table.gd`（詳しい戦績の表）、自動の対戦（`game/autoplay.gd` の `_queue_result_scene`）。
数えるのは `BattleStats`（`docs/battle-stats.md`）。

## 出し方

決着すると、対戦の画面（盤面）の上に重ねて、次の順に出す。時刻は `result_screen.gd` の先頭の定数にまとめてある。

1. **勝敗の見出し**が画面の中央に大きく出る（少し大きいところから縮んで止まる）。下に決着の理由。
   - CPU 戦: 人が勝てば金色の `VICTORY`、負ければ青白い `DEFEAT`、引き分けは `DRAW`。理由の行に、どちらが勝ったかも添える。
   - 人どうし: どちらにも肩入れせず、勝った側の名前（「プレイヤー2（赤） の勝ち」。陣営の色）、引き分けは「引き分け」。
2. 見出しが**上へ退いて**小さくなり、**戦績**が 1 行ずつ出る（1 行ごとに小さくクリックの音）。
   マップ（戦いの定義の名前。対戦モードではマップの名前、ストーリーではマップの名前）、経過ターン、敵軍撃破（敵のプレイヤーの駒を倒した数）、中立撃破（中立の駒（中ボスを含む）を倒した数。0 なら出さない）、聖遺物（持っていなければ出さない）。
3. **MVP** が拡大しながら出る（鈴の音）。名前（進化先・レベル）と、与えたダメージ・撃破（敵の駒へのダメージも撃破も無い MVP は、中立の駒へのダメージと撃破、回復。`StatsText.mvp_numbers`）。候補の駒がいなければ「該当なし」。
4. **行き先のボタン**と、明滅する入力の案内が出る。

全部が出るまでの時間は、戦績の行の数で変わる（`_stage`）。

- **出そろうまで、行き先は選べない。** その間のクリック（Enter・Space でも）は、演出を飛ばして全部を出すだけ。
  飛ばした直後の少しの間（`SKIP_GUARD`）もボタンは押せない（飛ばしたクリックが、そのまま行き先を選ばないように）。
- 出そろったあとの Enter は、「次へ」があればそれ。無ければ、ストーリーの話で負けた（引き分けも）ときは「同じマップで再戦」
  （`docs/battle-source.md` の `retries_on_enter`。話を進めるには勝つしかないので、まずはそのまま挑み直す）、それ以外は流れの外への行き先（対戦モードはマップ選択、ストーリーは話の一覧）。
  Enter で選ぶボタンは、いちばん大事なボタンの見た目（金の地。`BUTTON_PRIMARY`）にする。「次へ」と、ストーリーで負けたときの「同じマップで再戦」は、文字も大きくする。入力の案内も、行き先の名前を書く。
  「詳しい戦績」は控えめなボタン（`BUTTON_GHOST`）。
- 戦績の行がいちばん多い（5 行）ときも、入力の案内が対戦の画面の下の帯にかからないよう、戦績の行の間を詰めてある（自動の対戦の `result` が確かめる）。
- 決着の曲（`docs/sound.md`）は、見出しが出るのと同時に鳴る。

## 誰の戦績を出すか

- CPU 戦は人の側。人どうしは勝った側。人どうしの引き分けはプレイヤー1。
- MVP の決め方は `BattleStats.mvp`（将を除き、敵のプレイヤーの駒に与えたダメージがいちばん多い駒。無ければ中立の駒へのダメージや回復で決める。`docs/battle-stats.md`）。
- MVP は、名前の左に駒の額（`game/unit_frame.gd`。縁は陣営の色、役割の印、進化後の形。`docs/unit-icons.md`）。
- 戦績の板と MVP の板は、上の縁が太い（MVP は金の縁）。板の見出し（「〜の戦績」「★ M V P ★」）は、左右に細くなる線（`game/ui_taper.gd`）で真ん中に立てる。戦績の値は太字。
- 両方の陣営の詳しい戦績は **畳んでおき**、「詳しい戦績」で開く（「要約へ戻る」で閉じる）。開くと、戦績の要点と MVP のかわりに**表**を出す:
  - 上に全体の 1 行（マップ・ターン・決着の仕方）と、陣営の切り替え（2 つのボタン。開いたときは戦績を出している陣営）。
  - 陣営の 1 行（敵軍撃破、倒された数、中ボス撃破、必殺技、聖遺物。`StatsText.side_summary`）。
  - 表は、**行が駒**（将から並びの順。アイコン、名前とレベル、進化先）、**列が数**（`StatsText.COLUMNS`: 与えたダメージ、受けたダメージ（敵のプレイヤーの駒から。中立の駒からのものは数えない。`docs/battle-stats.md`）、撃破、中立撃破、回復、スキル）と、倒れた駒の印。0 は「-」。
  - 見出しの行の下に区切りの線。行は 1 行おきに薄く塗る。数は太字で、0 の「-」は沈める。駒のアイコンは額（縁は陣営の色）。
  - MVP の行は「★」と金の文字で、行を金で薄く塗り、左に金の線。倒れた駒は額を薄く、名前を補足の色にし、「倒れた」は危険の色を落とした色。
  - 行が多ければ、表の中で縦に送る（`TABLE_HEIGHT`）。列の幅は中身で広げない（見出しと数がずれない）。

## 行き先

- 「次へ」は、ストーリーの話の対戦で、人が勝ったときだけ、「同じマップで再戦」の左に出す（流れの次の場面、あとの会話へ。`docs/story.md`）。
  出すかは対戦の画面が、渡されたもの（`docs/battle-source.md` の `can_continue`）に聞いて、決着の画面を出すたびに決める。
- 「同じマップで再戦」、「新しいマップ（<マップ>）」（どちらも、いまの設定のまま。同じ対戦の場面で始め直す。「新しいマップ」は、生成のマップを種を替えて作り直す。生成のマップだけ。手で作ったマップは形が変わらないので出さない。`docs/map-select.md`）、
  「対戦設定へ」（対戦設定の場面へ）、流れの外への行き先（対戦モードは「マップ選択へ」、ストーリーは「話の一覧へ」。`docs/battle-source.md` の `leave`）。遷移は `docs/scene-flow.md`。
  決着の画面に「タイトルへ」は出さない（タイトルへは、システムメニューの「タイトルへ戻る」から）。
- 「部隊変更」は、ストーリーの話の対戦で、勝っても負けても「話の一覧へ」の左に出す（出撃準備へ戻る。対戦の前の会話は、もう出さない。`docs/battle-source.md` の `can_choose_squad`）。

## 後ろの光と粒

`game/result_glow.gd`（幕と見出しの間に置く。絵は使わない）。光と粒は段階の時刻（上）に合わせて出すだけで、出そろうまでの長さには関わらない。

- **勝ち**（VICTORY と、人どうしの「〜 の勝ち」）: 見出しの後ろの上から、見出しの色の光が広がり、紙吹雪のような粒（見出しの色・白・真鍮）がゆっくり降る。
- **負け**（DEFEAT）: 画面を冷たい藍へ沈め、灰のような粒を、まばらに、ゆっくり降らせる。
- **引き分け**: 何も出さない。
- 入力は通す。決着の画面が見えていない間は、粒を出さない。
