# 音（BGM と効果音）

コード: `game/sound.gd`（鳴らすところ）、`game/sound_catalog.gd`（音の表）、`game/scene_flow.gd` の `music`（場面ごとの曲）。
音量の設定は `game/settings.gd`（`docs/system-menu.md` の「オプション」）。
テスト: `tests/game/test_sound.gd`。

## 方向

- BGM も効果音も、**ファンタジー寄り**。ビット音源（チップチューン、8bit 風）と電子音は使わない（Issue #51 の人間の決定）。
- 元のゲームの音は持ち込まない。ライセンスに問題の無い、ありものの素材を使う（`CLAUDE.md` の「素材」）。いま入れているものは全部 CC0。
- 出どころ・作者・ライセンス・元のファイル名は、置いたディレクトリ（`assets/audio/<作者>/`）の `README.md` と `LICENSE*` に書く。
  何人かの音をまとめたパックから取ったものは、まとめた人のディレクトリに置き、元の作者を表に書く。
  何人かの曲をこちらで集めたもの（対戦の曲）は、`assets/audio/oga-battle/` に置き、曲ごとの作者を表に書く（作者ごとにディレクトリを分けない）。
- 効果音は短く（長いものは後ろを切ってフェードで消す）、モノラルにする。

## 鳴らす場面

### BGM

| 場面 | 曲の名前 | 鳴らし方 |
| --- | --- | --- |
| タイトル・物語選択・話の一覧・出撃準備・部隊編成・マップ選択・対戦設定 | `menu` | ループ。これらの場面を行き来しても途切れない |
| ストーリーの会話（対戦の前と後） | `talk` | ループ。話のファイルの `talk_music` で選び直せる |
| 対戦 | 盤の見た目ごと（下の表）。ストーリーは、話のファイルの `music` があればその曲 | ループ |
| 決着（人が勝った。人どうしなら、いつも） | `victory` | 1 回だけ鳴らして止まる |
| 決着（CPU に負けた、引き分け） | `defeat` | 1 回だけ |

対戦の曲は、どれもオーケストラの戦いの曲（`assets/audio/oga-battle/`）。メニューと会話は落ち着いた中世の曲のまま、対戦は熱く、と差を付ける。
盤の見た目ごと（`sound_catalog.gd` の `LOOK_MUSIC`。盤の見た目は `stage_look.gd`）:

| 盤の見た目 | 曲の名前 | 曲 |
| --- | --- | --- |
| 草原（中央平原・大岩の峠など）、見た目の分からない対戦 | `battle` | 弦と金管の勇ましい曲（Battle Theme A のループ版） |
| 石の遺跡（迷宮回廊・尾根の小道など） | `battle_ruins` | 重く暗い 3 拍子の曲（Great Labyrinth） |
| 結晶の森（双子結晶・結晶の岩山など） | `battle_crystal` | 打楽器の刻みが続く、異国風の曲（Sigil） |

手で作ったマップのための見た目（採掘場など）は、曲を足さず、上の 3 つのうち近い景色の曲を使う（どの見た目がどの曲かは `LOOK_MUSIC` が正）。

ストーリーの特別な話は、話のファイルの `music` で選ぶ（どの話が使うかは、話のファイルが正。`game/story/episodes/`）:

| 話 | 曲の名前 | 曲 |
| --- | --- | --- |
| 守り切る | `battle_tense` | 弦の速い刻みと金管。時間に追われる曲（Determined Pursuit） |
| 中ボスの撃破 | `battle_boss` | 巨大な魔物に挑む曲（The Fire Dragon） |
| 全滅させる | `battle_rout` | 攻め込む行進の曲。4 分あり、途中で形が変わる（QaziJamJam） |
| 魔物（骸骨の軍） | `battle_undead` | 不気味な軍の行進（The March of Devils Dome） |

**終盤**: 対戦の途中で、どちらかの将の HP が半分以下になったら（倒れたときも）、終盤の曲 `battle_climax`（Epic Boss Battle）へフェードで替わる
（`sound_catalog.gd` の `CLIMAX_MUSIC` と `CLIMAX_KING_HP`、判定は `climax_reached`）。

- 1 対戦に 1 回だけ。替えたら戻さない（新しい対戦を始めると、その対戦の曲に戻る）。決着がついたあとは替えない（決着の曲を消さない）。
- どちらの将かは問わない。曲が形勢（どちらが優勢か）を告げると気が散るので、「戦いが山場に来た」ことだけを知らせる。
- 必殺技が使えるようになったことは合図にしない（ゲージは両陣営で何度もたまり、山場と重ならない）。

- 曲は、どの場面で鳴らすかを次の順で決める: 流れが渡すもの（対戦の `battle_source.gd` の `music`、会話の辞書の `"music"`）が決めていればその曲、
  決めていなければ場面の表の曲（`scene_flow.gd` の `music_for`）。対戦の画面は、新しい対戦を始めるたびに `music` の曲にする
  （「新しいマップ」で見た目が替われば曲も替わる。同じ曲なら鳴らし直さない）。
- 曲の大きさは、曲の平均の大きさ（EBU R128 の積分ラウドネス）を測ってそろえた。対戦の曲（終盤の曲も）は -21.5 LUFS、会話の曲は -20 LUFS ほど
  （`volume_db` = ねらい - 測った値）。効果音（下の「対戦の音」）が埋もれないよう、対戦の曲を上げすぎない。耳では確かめていない。
- 曲が替わるときは、消える曲と入る曲を `Sound.FADE_TIME` 秒重ねてつなぐ（場面の切り替えの暗転と同じころ）。**同じ曲なら鳴らし直さない。**
- 決着の画面の「同じマップで再戦」「新しいマップ: <マップ>」では、対戦の曲へ戻る。
- 優勢・劣勢で曲を替えることはしない（じっくり考えるゲームで、曲が形勢を告げると気が散る）。替えるのは上の「終盤」だけ。
- 曲ごとの大きさの釣り合いは、表の `volume_db` で取る。

### 効果音

操作の音と、対戦の音。どちらも控えめな大きさで、BGM の下に置く。

#### 操作の音

| 名前 | 鳴るとき |
| --- | --- |
| `ui_click` | ボタンを押した（どの画面のボタンも）。同じフレームにほかの音が鳴るなら、そちらに譲る |
| `ui_confirm` | 決めた: 盤の上で駒を選んだ、タイトルの「ストーリー」「対戦」、物語・話・マップのカード、対戦設定の「対戦開始」、出撃準備の「出撃」、部隊編成の「編成完了」、決着の画面の「次へ」「同じマップで再戦」「新しいマップ」、会話を最後まで送った |
| `ui_back` | 1 つ戻した: 盤の上の右クリック・Esc で何かを戻した、システムメニューの中で戻った（確かめ・オプション → メニュー）、会話で 1 つ前の文へ戻った、物語選択・話の一覧・マップ選択・出撃準備を右クリック・Esc で戻った |
| `ui_denied` | 押せない（灰色の）ボタンを押した |
| `menu_open` / `menu_close` | システムメニュー・ログを開いた、閉じた |

- 同じフレームに同じ音は 1 回だけ鳴らす。

#### 対戦の音

対戦の再生（`battle_playback.gd`）と演出の起点（`battle_effects.gd`）が、演出の出る瞬間に鳴らす。**再生の待ち時間は、音のために変えない。**

| 名前 | 鳴るとき |
| --- | --- |
| `hit_slam` / `hit_slash` / `hit_shot` / `hit_magic` / `hit_plain` | 攻撃が当たった瞬間。当たり方（`battle_effects.gd` の `Style`）ごとに、叩く・斬る・撃つ・魔法・そのほか |
| `critical` | クリティカル。当たった音に重ねる |
| `blocked` | 状態（バリアなど）が攻撃を防いだ。当たった音に重ねる |
| `defeated` | 駒が倒れた |
| `explosion` | 樽が爆発した |
| `heal` | 回復した（回復役・泉・再生・聖域） |
| `skill_fire` / `skill_guard` / `skill_holy` / `skill_wind` / `skill_focus` | スキルの形が対象に届いた瞬間。系統ごと（`battle_effects.gd` の `SKILL_SOUNDS`）: 炎、守り（バリケード・ディバインシールド）、聖（聖域）、風と影（スモークグレネード・シャドウステップ）、集中（照準・アドレナリン注射） |
| `ult` | 必殺技を使った（画面が光る瞬間に 1 回。音の山が、続く光の柱に重なる） |
| `ult_ready` | 必殺技のゲージがいっぱいになった |
| `portal` | ポータルで転移した |
| `relic` | 聖遺物を手に入れた |
| `capture` | 拠点の占拠が進んだ（途切れたときは鳴らさない） |
| `level_up` / `evolved` | レベルが上がった、進化した |
| `boss_roar` | 中ボスが現れた（ふつうの中立の駒が湧いたときは鳴らさない） |
| `phase` | 陣営の番が始まった（中立の番は鳴らさない） |

- 決着は、決着の曲（BGM の `victory` / `defeat`）が知らせるので、別の効果音は鳴らさない。
- 移動（足音）と待機は鳴らさない。駒が何体も続けて動くので、足音は鳴り続けてうるさくなる。
- **重ならないように**: 必殺技の効果（駒ごとの状態）、スキルと爆発のダメージ（駒ごとの被弾）には、駒ごとの音を付けない（スキル・爆発・必殺技の音が 1 回鳴る）。
  そのうえで、表の `gap` の秒数の間は同じ音を鳴らし直さない（泉の回復が何体も続く、など）。
- 大きさは、BGM より少し下、操作の音より少し上にそろえた（素材ごとの大きさを測って `volume_db` で合わせた）。必殺技だけ少し大きい。

## 音量

オプションの区分「音」: 全体・BGM・効果音（0〜100%、5% 刻み）と「音を消す」。値はその場で効き、`user://settings.json` に残る。

- 音のバスは 3 つ: `Master`（全体）の下に `Music`（BGM）と `Effects`（効果音）。設定の値はバスに掛ける。
- 割合は 2 乗してから dB にする（50% で約 -12 dB）。耳で半分くらいに聞こえるようにするため。0% はバスを消す。
- 「音を消す」は `Master` を消す（音量の値はそのまま）。

## 足し方

- **効果音を足す**: 素材を `assets/audio/<作者>/` に置いて `README.md` に書き、`sound_catalog.gd` の `EFFECTS` に 1 行足す。
  鳴らす側は `context.play_sound(&"名前")`（場面）か `Sound.play(&"名前")`。続けて起きる出来事の音には、表に `gap`（同じ音を鳴らし直さない秒数）を書く。
  **表に無い名前・素材の無い名前は、黙って何もしない**。書き間違いで黙らないよう、画面の側のコードが名前で鳴らす音は表にあることを、テストが確かめる。
- **ボタンの音を替える**: ボタンに `set_meta(&"sound", &"名前")`。何も書かなければ `ui_click`。
- **曲を差し替える**: `sound_catalog.gd` の `MUSIC` の `path` を替える。対戦の曲の次点（試聴できる配布元の URL）は `assets/audio/oga-battle/README.md`。
- **場面の曲を替える・足す**: `scene_flow.gd` の場面の `music` に、`sound_catalog.gd` の `MUSIC` の名前を書く。曲を差し替えるだけなら、`MUSIC` の `path` を替える。
- **盤の見た目を足す**: `sound_catalog.gd` の `LOOK_MUSIC` に、見た目の名前と曲の名前を 1 行足す（無ければ `battle`）。
- **話の曲を選ぶ**: 話のファイル（`game/story/episodes/`）の `[episode]` に `music`（対戦）か `talk_music`（会話）を書く（`docs/story.md`）。
- 形式は Ogg Vorbis にそろえる（MP3 はループの継ぎ目に隙間が出やすく、WAV は大きい）。ループは表の `loop` で決める（取り込みの設定ではなく）。

## 検査

- 画面なし（`--headless`。CI、コンテナ）では、どの曲・どの音を選ぶかまでを同じに動かし、**鳴らしはしない**（`Sound._audible`）。
  画面なしの音のドライバは音を流さないので、止めた再生が片付かずに残り、終わるときにエラーになるため。
- アプリを終えるときは、音を止めて手放してから終える（`context.quit`）。鳴らしたまま終えると、再生が残ったと言われる。
- Windows の書き出し（CI の `windows`）は、すべての資源を入れる（`export_presets.cfg` の `all_resources`）ので、`assets/audio/` の音も入る。
