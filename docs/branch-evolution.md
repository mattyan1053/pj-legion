# 進化

コード: `rules/evolution.gd`（16 の進化先の表、特性、調整値）、`rules/actions/evolve_action.gd`（選ぶ行動）、
`rules/events/evolution_offered_event.gd`、`rules/events/unit_evolved_event.gd`、`rules/events/regeneration_healed_event.gd`。
進化先の能力値と特性を読むのは `rules/unit.gd`、選ぶまで対戦を待たせるのは `rules/battle.gd`。
テスト: `tests/rules/test_evolution.gd`。

レベルが上限（`Growth.MAX_LEVEL`）に届いた駒は、2 つの進化先のどちらかを選んで別の型になる。

## 進化する駒

- 進化するのは、**雇う 8 種**（前衛・後衛・奇襲・回復 × MILITARY / FANTASY）。それぞれに進化先が 2 つ（A・B）で、**16 ルート**。
  将と中立の駒は進化しない（そもそも育たない。`docs/experience-levelup.md`）。
- 進化しても、種類（`Unit.kind`。役割と軍）は変わらない。進化先は `Unit.evolution` に持つ。
  駒の呼び名（`game/names.gd` の `unit`）は進化先の名前になる。
- 進化は 1 回だけ。選び直せない。進化した駒には、もう経験値は入らない（レベルが上限のまま）。

## 選び方

- **上限のレベルに届いたその場で、駒の持ち主が選ぶ。** 届くのは自分の行動（攻撃・回復・ダメージのあるスキル）なので、いつも自分のフェーズの中。
- 届いた駒は「進化先を選ぶのを待っている」状態になる（`Unit.evolution_ready`。`Battle.evolving_unit()` がその駒を返す）。
  **選ぶまで、ほかの行動はどれも断る**（ほかの駒の行動も、ターン終了も）。待つ駒は、いつも 1 体だけ。
- 選ぶ行動は `EvolveAction.new(駒の番号, 進化先)`。その駒の種類の進化先でなければ断る。
- 選べる進化先は `Battle.options(駒の番号).evolutions`（A、B の順）。待っている間は、この駒の `evolutions` だけが載り、
  ほかの駒の選べることは空になる。`actions()` は `EvolveAction` を 2 つ並べる。
  **CPU も同じ入口で選ぶ**（`Battle.evolving_unit()` がいれば、その駒の `options().evolutions` から 1 つを選び、`EvolveAction` を `apply` する。
  どちらを選ぶかは `docs/cpu-ai.md` の「進化先」）。
- 駒の行動は、進化の前にもう終わっている。進化しても、そのフェーズでもう一度は行動できない。
- 上限に届いた行動で決着したら（将を倒した）、選ばずに終わる。
- 見込み: `Growth.preview(駒, 量).evolution_ready` が、その経験値で進化先を選ぶことになるかを答える（状態は変えない）。

## イベント

- 上限に届いた行動: …、`ExperienceGainedEvent`、`LevelUpEvent`、**`EvolutionOfferedEvent`**、`UnitActedEvent`
- 選ぶ行動: **`UnitEvolvedEvent`**
- 自分のフェーズの始め: `PhaseStartedEvent`、泉の `SpringHealedEvent`、**`RegenerationHealedEvent`**（再生の駒ごと。上の行から、左の列から）

| イベント | 値 |
| --- | --- |
| `EvolutionOfferedEvent` | 駒、選べる進化先 `choices`（A、B の順） |
| `UnitEvolvedEvent` | 駒、選んだ `evolution`、進化したあとの `max_hp`・`hp`・`power`・`move_range`・`attack_range` |
| `RegenerationHealedEvent` | `UnitHealedEvent` の子（`cause` は `REGENERATION`）。駒、増えた量、あとの HP |

## 進化先の中身

進化先は、**能力値の増減**と**特性**を持つ。

- 能力値の増減は、実効値の層 1（基礎 + 成長 + 進化 + 装備。`docs/player-loadout.md`）に足す。種類の基本の値は書き換えない。
  レベルアップの伸び（役割ごと。`Growth.GAINS`）は進化先で変えず、進化のぶんは進化先が別に持つ。
- 最大 HP が伸びたら、伸びたぶんだけいまの HP も増える（レベルアップと同じ）。
- 特性は、いまあるルールの例外。4 つある。同じ特性を、装備も与える（`docs/player-loadout.md` の「装備」。駒は `Unit.has_trait` で、進化先と装備の両方を見る）。

  | 特性 | 中身 |
  | --- | --- |
  | 支配領域 | 前衛でなくても、周り 8 マスに支配領域（ZOC）を作る（`docs/movement.md`） |
  | 浸透 | 敵の支配領域で止まらない（敵の駒のいるマスには、これまでどおり入れない） |
  | 森歩き | 森に、平地と同じ移動力 1 で入る（森で受けるダメージの軽減は、これまでどおり） |
  | 再生 | 自分のフェーズの始めに HP を 5（`REGENERATION_HEAL`）回復する（最大 HP まで。泉に乗っていれば、泉の回復のあとに重なる） |

### 選びが分かれる場面

- **前衛**: 本陣や通路を塞ぐならブルワーク / セイクリッド。奇襲を追う、本陣を踏みに行くならジャガーノート / クルセイダー
  （どちらも支配領域は持ったまま）。
- **スナイパー**: 相手に奇襲が残っていれば、逃げ足と HP のあるスカウト。壁の後ろから撃ち続けられる盤面ならマークスマン
  （遠くから撃てるかわりに、移動が減り、詰められると逃げられない）。
- **コマンドー**: 相手に前衛がいれば、支配領域を抜けて後衛と将へ届くインフィルトレーター。いなければ、アサルト
  （育っていない相手なら、アサルトの一撃はコマンドーを 1 回、ソーサラー・スペルブレードと将を 2 回で倒す。インフィルトレーターでは、コマンドーと将に 1 回多くかかる）。
- **衛生兵**: 前衛を 1 体ずつ厚く戻すならサージョン。巡航に頼らず奇襲・ジャガーノートに付いていくならコンバットメディック。
- **ソーサラー**: 射程の伸びたアークメイジか、自分の周りで奇襲を止め、通路を塞げるエンチャンター
  （支配領域は、浸透を持つインフィルトレーターには効かない）。
- **スペルブレード**: 前衛の頭越し・壁越しに後ろを斬るアークブレードか、森の多い盤面で回り込むフェイウォーカー。
- **プリースト**: 奇襲の届かない後ろから回復するビショップか、前に出ても倒れにくいセイント。

### 軍の色

- **MILITARY は能力値が尖る。** 射程・移動・火力・回復量のどれかが大きく伸び、特性は 1 つ（浸透）だけ。
- **FANTASY は性質が変わる。** 再生（聖性）、支配領域（結界）、森歩き（妖精の道）と、特性が 3 つ。
- 役割の持ち味は、どちらの進化先でも残る（前衛は支配領域、後衛は射程、奇襲は移動、回復役は回復）。
  A と B は、その持ち味のどこを伸ばすかの違い。

## 入れていない効果

次の効果は入れていない。いまは、その効果が無いぶんを能力値の増減で持たせている。

- ブルワーク / セイクリッド: 隣の味方への攻撃を身代わりで受ける。
- ジャガーノート / クルセイダー: 攻撃した相手を 1 マス押し出す（ノックバック）。

足すときの置き場所は `docs/combat.md` の「後で足すものの置き場所」。足したら、ここの能力値の増減を見直す。

## 調整値

ゲーム性で選んだ値。すべて `rules/evolution.gd` の表（`_TABLE`）と `REGENERATION_HEAL` にある。

| 値 | いまの値 | 選んだ理由 |
| --- | --- | --- |
| 選ぶ時機 | 上限に届いたその場。選ぶまで、ほかの行動を待たせる | 進化は得しかないので、後回しにする理由が無い。保留の状態を増やさずに済み、CPU も画面も「待っている駒がいれば選ぶ」だけで足りる |
| 増減の大きさ | レベルアップ数回ぶん（役割ごとの伸び `Growth.GAINS` で数えて） | 進化 1 体で対戦が決まらない。アサルトでも、将と前衛は 1 回では倒せない |
| ブルワークの最大 HP | 進化先の中でいちばん大きい伸び（16 ルートの表） | 身代わりが無いぶん、厚くした |
| マークスマンの移動 | 減らす（16 ルートの表） | 伸びた射程と、もとの移動を両方持つと、スカウトを選ぶ理由が無くなる |
| 浸透の移動 | 少しだけ伸ばす（16 ルートの表） | 支配領域を抜けること自体が強い。攻撃は伸ばさない |
| 支配領域（エンチャンター） | 攻撃は伸ばさず、最大 HP だけ | 前に出て塞ぐ役なので、倒れにくさだけ足す |
| `REGENERATION_HEAL` | 5 | 回復の泉（`docs/map-objects.md`）の回復量の半分より少し下。毎ターン効くので小さくした。エナジー・コアの一撃は打ち消すが、プレイヤーの駒の一撃には追い付かない |
| レベルアップの伸び | 進化先で変えない（`Growth.GAINS` は役割ごとのまま） | 進化の時点でレベルは上限なので、変えても効く場面が無い |

進化まで届く駒の数の見積もり（`docs/experience-levelup.md` の値で）: 進化には、レベルアップ 2 回ぶんの経験値が要る。
当たりだけでは遠く、撃破が何度か要る。エナジー・コアの撃破だけ、回復だけでも届くが、何度も重ねることになる。
相手の雇う駒は多くて 6 体（`Deck.MAX_UNITS`）なので、撃破を 1 体に寄せて、対戦の終わりごろに 1 体届くかどうか。
