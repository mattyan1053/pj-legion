# クラシックの編曲（楽譜のデータから、スクリプトで作った曲）

オプションの「BGM の組」を「編曲」にしたとき、「編曲の版」の「管・管2・電・電2・重・夏・旧」で鳴る曲（`game/sound_catalog.gd` の `ARRANGEMENT_SETS`）。既定（いまの組）では鳴らない。
**曲は聴いていない。** 下の測りだけで確かめた。

原曲を頭から流さない。原曲から強い所（同音の刻みが積み上がる合奏、独奏の速い走句、終わりの総奏）を小節の単位で切り出して並べ直し、
戦闘曲の型（低音のオスティナート、打楽器の拍、金管の短い打ち込み、短いループ）の層を足した（`tools/classical_bgm/arrange.py`）。

### 不協和音と強打（管2・電2）

ボス曲によくある「濁り」と「スタッカートのダダダンッ」を、区切りの頭と終わりにだけ置いた（原曲の和声と旋律はそのまま。`arrange.py` の `dark` と `hits`）。
管と電は足さない版として残してあり、聴き比べられる。

- 区切りの頭の小節（1 拍目）: 金管が、根音・その半音上・増 4 度上のクラスター（例: F・G♭・B、C・D♭・G♭）を短く打つ。第 1・第 2 ヴァイオリンが高い所で根音の半音上を短く重ねる。
  その小節の低音の 8 分の裏（オクターブ上の音）を、根音の半音上にする（短 2 度のぶつかりが 8 分で続く）。
- 区切りの終わりの小節（4/4 の 3 拍目の裏から）: 総奏（弦・低音・金管・ティンパニ、電2 は歪んだギターも）とスネア・大太鼓（キック）が、16 分 3 つ（3 拍目の 2〜4 つ目の 16 分）+ 4 拍目の強打（シンバル付き、8 分より短く切る）。
  強打のあと、小節の終わりまで（約 0.3 秒）は何も鳴らさない（残響だけ）。その間はほかの層の音を消し、かかる音は切る。
  和音は、次の区切りの頭の根音の半音下に立てた減七（例: 次が F なら E・G・B♭・D♭）。次の頭で解決する。ループの継ぎ目も同じ（最後の区切りの終わり → 頭の F）。

| 版 | 区切りの頭（クラスター。元の小節） | 区切りの終わり（ダダダンッ。元の小節 → 減七の根） |
| --- | --- | --- |
| 管2 | 3（F）、19（F）、26（F）、32（C）、46（C）、55（C） | 10 → E、25 → E、31 → B、37 → B、54 → B、61 → E（ループ） |
| 電2 | 3（F）、19（F）、46（C）、26（F）、32（C）、55（C） | 10 → E、25 → B、54 → E、31 → B、37 → B、61 → E（ループ） |

（区切りの頭の根音は、楽譜のその拍のいちばん低い音。55 小節の頭はチェロが休みなので、ヴィオラの C になる。）

どの組でも、終盤（`battle_climax`）・中ボス（`battle_boss`）・物語の終わりの 2 話（`battle_eve`・`battle_last`）・締めの話の終盤（`battle_final`）に当てる。
大きさは、書き出しで -16 LUFS にそろえ、`volume_db` を -5.5（対戦のねらい -21.5 LUFS との差）にした。

- 前の版は、頭が曲の中ほどより 13〜16 LU 弱く（原曲の静かな出だし）、谷も同じだけ深い（ループの頭で一度しぼむ）。立ち上がりの強さが 1.3 と低い（音の数は多いが、拍の頭がはっきりしない）。
- 今回の版は、頭から曲の中ほどと同じ大きさで、谷は 1.4〜3 LU。立ち上がりの強さは 2.2〜3.2 で、いまの対戦の曲（2.3）と同じかそれより上。
  60 Hz 未満（太い低音・大太鼓・キック）は、前の版の 0.2% から 3〜20% になった。
- 立ち上がり / 秒は、前の版のほうが多い。前の版は細かい音（弦の 16 分やトリル）の一つひとつが数えられ、今回は打楽器と低音の拍が上に立つので、細かい音が山として数えられにくい。
  この数は「刻みの多さ」の目安にならなかったので、「立ち上がりの強さ」で見る。
- 切れ / 分: 強打のあとの一瞬の無音（溜め）の数。管2・電2 は 1 周に 6 つ置いたので 5〜7。足さない管・電は 0〜2.5。
  重の 7.0 は、遅いテンポで 16 分の刻みの切れ目が数えられたもので、溜めではない。
  3 秒の窓の測り（幅・谷・頭）は、0.3 秒の溜めではほとんど動かない（管2・電2 も谷 3.2〜3.5 LU、頭 ±0.1 LU）。
- 不協和音は数字で測っていない（置いた所は上の表）。
