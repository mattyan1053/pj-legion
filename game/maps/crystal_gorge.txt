# 手で作ったマップ「結晶の岩山」（docs/hand-map.md）。20 x 20。
# どの話が使うかは game/story/ を「map =」で探す。対戦モードに出すかは game/versus_fields.gd。
#
# 盤の中ほどを、結晶の岩山（2 行の障害物。画面では、結晶の生えた岩山が横たわって見える）が横切る。越え方は 3 つ:
# - 左右（東西）の端の回り道（幅 2）。岩山の両端の切れ目。
# - 真ん中のポータルの対（a）。岩山の上と下を結ぶ。速いが、出た先は相手の陣地のただ中。
# 本陣は対角（プレイヤー1 は左下、プレイヤー2 は右上）。盤の中心で点対称（本陣どうしを入れ替えると、同じ形になる）。
# 岩山の上と下は、それぞれ森と結晶の岩が散らばる広場。中ボスと結晶泉は、広場ごとに 1 つずつ（点対称）。
# 「尾根の小道」（左右の 2 本道を押し合う）と違い、遠い回り道と、近道のポータルのどちらで攻め、どこを守るかを選ぶ盤。
# 拠点の場所は H（対戦モードの拠点が入のときだけ拠点になる。話では平地）。岩山の真ん中の上下は片方に大きく傾くので、上の道の左寄りに置いた（docs/map-objects.md の「拠点」）。
# 対戦モードだけの砲台は V（話では平地。話の盤と難しさを変えない）。両方の本陣から同じ道のりの、拠点の斜め下と、点対称のマスに置いた（docs/map-objects.md の「砲台」）。
# 文字の意味は HandMap の定数。
# 書き方は docs/hand-map.md（[rows] は 1 文字 1 マス。この節の中では # も障害物の文字として読む）。
