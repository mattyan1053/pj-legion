# 手で作ったマップ「結晶の渓谷」（docs/hand-map.md）。20 x 20。ストーリーの話 gorge_rout（game/story/episodes/）と、対戦モードに使う。
#
# 盤の中ほどを、結晶の裂け目（2 行の障害物）が横切る。渡り方は 3 つ:
# - 左右の端の橋（幅 2）。左の橋はプレイヤー1 の本陣の側、右の橋はプレイヤー2 の本陣の側に寄っている。
# - 真ん中のポータルの対（a）。裂け目の上と下を結ぶ。速いが、出た先は相手の陣地のただ中。
# 本陣は対角（プレイヤー1 は左下、プレイヤー2 は右上）。盤の中心で点対称（本陣どうしを入れ替えると、同じ形になる）。
# 裂け目の上と下は、それぞれ森と結晶の岩が散らばる広場。中ボスと結晶泉は、広場ごとに 1 つずつ（点対称）。
# 「尾根の小道」（左右の 2 本道を押し合う）と違い、遠回りの橋と、近道のポータルのどちらで攻め、どこを守るかを選ぶ盤。

# 書き方は docs/hand-map.md（[rows] は 1 文字 1 マス。この節の中では # も障害物の文字として読む）。
