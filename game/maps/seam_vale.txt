# 本陣は上下の中央。盤の中心で点対称（本陣どうしを入れ替えると、同じ形になる）。
# ポータルの多い盤（3 対）。a と b は、自分の本陣の脇と、相手の本陣の脇を斜めに結ぶ（速いが、出た先は相手の陣地のただ中）。
# c は盤の中ほどの左右を結ぶ。岩の帯が 2 本、盤を横切る（切れ目は左右と真ん中）。
# 相手の陣地へ出るポータルは、対戦モードの盤には置かない（docs/hand-map.md の「マップを作るときのめやす」）。
# ここはストーリーの盤で、奥にいる敵の将へ跳び込む道と、自分の本陣へ跳び込まれる怖さを作るために置いた。
# 結晶泉は左右に 1 つずつ（点対称）。中ボスは置かない。

# 書き方は docs/hand-map.md（[rows] は 1 文字 1 マス。この節の中では # も障害物の文字として読む）。
