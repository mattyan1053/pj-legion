# 新しい魔物「大蝙蝠」の見本の話。大蝙蝠は脆いが速く、盾の脇（支配領域）で止まらず、森も平地と同じに飛ぶ（docs/monsters.md）。
# 前衛の壁で止められないので、後ろの狙撃手と衛生兵を守る並び方を考える。
# 敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。人の勝ち方は「敵を全滅させる」だけ（wins）。
# 手で作ったマップ「結晶の岩山」（game/maps/crystal_gorge.txt）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 墓守を退けたあと、偵察隊は岩山の縫い代を見回る。結晶の光に引かれた大きな蝙蝠の群れが、盾の脇を越えて後ろへ降りてくる。
# 伝わること: 速く脆い群れは、盾で止まらない。狙撃手と衛生兵のそばに盾と刃を残す。
# 知る・変わる: 縫い代には、亡者のほかにも光る石に寄ってくるものがいると知る。ピップが、抜け道の商人から聞いた話をする（石の割れ目には寄るな）。ドーソンが守り方を問い、少尉が答える（見回りの始め。隊はまだ元気）。
