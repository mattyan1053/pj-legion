# ストーリーの話「石喰いの採掘場」。番外「縫い代の見回り」の 4 話目。台詞は下書き。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 新しい魔物「糸喰い」と「糸蜘蛛」の見本の話（docs/monsters.md）。どちらも骸骨ではない。
# 糸喰いは、倒れると腹の石が弾けて、周り 8 マスを焼く（敵も味方も）。隣から叩いて倒すと巻き込まれるので、離れて撃つか、群れの中で倒す。
# 糸蜘蛛は、当てた相手を次の番に動けなくする。前に出すぎた兵が群れの中で足を止められる。
# 盤には起爆樽が多く、樽と糸喰いの弾けるのが重なる（樽で糸喰いを倒せば、続けて弾ける）。
# 敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。人の勝ち方は「敵を全滅させる」だけ（wins）。
# 手で作ったマップ「結晶の採掘場」（game/maps/crystal_quarry.txt）。本編の「縫い目の発破」と同じ盤（墓守のあと、掘るのを止めた採掘場）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 見回りの帰りに、掘るのを止めた採掘場へ寄る。石を喰う翼の小さな竜と、石の糸を張る蜘蛛が棲みついている。
# 伝わること: 竜は倒れると腹の石が弾けるので、離れて撃つ。蜘蛛の糸に掛かると足が止まるので、前に出すぎない。
# 知る・変わる: 人が掘るのを止めた所に、石を喰うものが来る。連邦の隊は、石を燃料としか見てこなかったことに、少しだけ引っ掛かる（少尉は、報告の書き方に詰まる）。隊に疲れが出はじめ、ピップは先に出ない。
