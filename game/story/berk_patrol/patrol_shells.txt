# 新しい魔物「殻蟹」と「糸茸」の見本の話（docs/monsters.md）。どちらも骸骨ではない。
# 殻蟹は、結晶の殻で、離れた所からの攻撃では狙えない。隣へ寄って叩く（爆発や弾けるのは当たる）。
# 糸茸は、周り 8 マスにいる敵の攻撃を弱める。殻蟹の隣に茸が付くと、寄って叩くのも重くなる。茸は離れて撃って先に倒す。
# 人の勝ち方は「守り切る」だけ（hold_turns と wins）。敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。
# 群れは、いつもの勝ち方（将の撃破、本陣の占拠）で攻めてくる。ポータルが、人の本陣の脇へ群れを運ぶ。

# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 見回りを終えた偵察隊は、縫い目の谷で本隊の迎えの荷車を待つ。谷の水場から、結晶の殻の蟹と、糸に生える茸が上がってくる。迎えが着くまで、旗を守る。
# 伝わること: 殻蟹は撃っても通らないので、寄って叩く。茸の隣では腕が鈍るので、茸は先に離れて撃つ。
# 知る・変わる: 石の糸にくっついて生きるものは、蝙蝠や竜のほかにもいる。見回りが終わり、偵察隊は本隊へ戻る。
