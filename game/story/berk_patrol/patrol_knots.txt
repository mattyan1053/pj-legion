# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 倒れると何か起きる魔物（docs/monsters.md）の見本の話。ほつれは倒れると結び目を残し、だれかが上に立たないと立ち直る。
# 骸骨旗手は倒れると、周りの亡者を奮い立たせる。どこで、どの順に倒すかを考える話。
# 縫い目の様子（signs）の見本も兼ねる: 天裂の名残り（haze。後衛の射程が 1 縮む）が、いつも付く。狙撃手が近くへ出る。
# 敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。人の勝ち方は「敵を全滅させる」だけ（wins）。
# 手で作ったマップ「古戦場」（game/maps/old_battlefield.txt）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 古戦場の外れで、地面から青白い塊が湧き、旗を掲げた骸骨が亡者を集めている。塊は倒しても、跡を踏まないと起き上がる。
# 伝わること: 塊は離れて撃って倒し、近くの者が跡を踏む。旗持ちは、群れから離れたときに倒す。
# 知る・変わる: 古戦場の亡者は、墓守を退けても出てくると知る。旗の骸骨の掲げる旗は、20 年前の連邦の旗だった（ドーソンは何も言わない）。少尉は、見たものはそのまま報告に書くと決める。
