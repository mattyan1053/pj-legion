# ストーリーの話「針の峠」。番外「縫い代の見回り」の 3 話目。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 新しい魔物「糸針」の見本の話。糸針は動けないが、遠くまで撃つ。番人のまわりに生えていて、番人を狩りに行く道をふさぐ。
# 番人の名前（boss）の見本も兼ねる: 名も無い峠なので、この話だけ番人を「針の番人」と呼ぶ（マップの「峠の番人」の代わり）。
# 敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。人の勝ち方は番人の撃破だけ（wins）。
# 大蝙蝠が、針の間を抜けて狩りに出た隊の背中を突く。
# 手で作ったマップ「大岩の峠」（game/maps/boulder_pass.txt）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 見回りの最後に、名も無い峠へ出る。番人のまわりに光る石の針が生え、近づく者を撃つ。番人を倒して、峠を通れるようにする。
# 伝わること: 動かない針は、届かない所を回るか、盾で寄って叩く。針を全部倒さなくても、番人を倒せば終わる。
# 知る・変わる: 光る針は、番人のまわりにだけ生えている。番人を守っているように見えるが、連邦の隊には、それが何かは分からない。
