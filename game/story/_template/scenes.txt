# 話のファイルの見本、その 2: 場面をいくつも並べる書き方（docs/story.md の「場面の節」）。写して使う。
#
# first_battle.txt の書き方（[before]・[after]）は「出撃準備 → 会話 → 対戦 → 会話」の決まった形。
# こちらは、会話の場面「[talk 名前]」をいくつでも書けて、[sortie]（出撃準備）と [battle]（対戦）を挟む所も選べる。
# **節を書いた順が、場面の順。** ほかの節（[episode]・[cast]・[cues]・[lost]・[ally]・[enemy]・[unlock]）は first_battle.txt と同じ
# （どこに書いても場面の順には入らない）。
#
# - [battle] を書かなければ、対戦の無い話（読むだけの話。最後の会話を読み終えたらクリア）。
#   そのときは [sortie]・[cues]・[lost]・[ally]・[enemy] を書かず、[cast] に enemy の話し手がいなくてよい。map は、背景の景色と話の一覧の絵に使う。
# - [sortie] を書かなければ、出撃準備は話の最初。
# - 対戦は 1 つの話に 1 つまで。会話の場面（[talk 名前]・[cut 名前]・[board 名前]）は、合わせて 8 つまで。

[episode]
title = 見本の話（場面をいくつも）
map = ridge_path
# before_music・after_music は書かない（曲は、会話の場面ごとに music で選ぶ）。

[cast]
レオ = ally
新兵 = ally, sniper
敵将 = enemy, paladin evolved

# 会話の場面。「talk」のあとの名前は、話の中で重ならなければ何でもよい（台本の見出しに出る。画面には出ない）。
# 頭に、設定を「キー = 値」で書ける（どれも無くてよい。会話の行より前に書く）:
#   place: 背景にする別の場所（game/maps/ のマップの名前）。その場所の景色だけを映す（兵は立たない）。
#          書かなければ、この話の盤（対戦の前は初期位置の兵、対戦のあとは生き残った兵が立つ）。
#   look:  place の景色を替える（stage_look.gd の見た目の名前）。place と組で書く。
#   music: 曲（sound_catalog.gd の MUSIC の名前）。どの会話にも書く（検査が確かめる）。
#          対戦の曲（battle で始まる名前）を書けるのは、対戦より前の会話に、その話の対戦の曲だけ。
# 文の中の {hero} は、主人公の名前の差し込み（物語のファイルの hero。遊ぶ人が変えられる。文の中で主人公を名前で呼ぶときは、こう書く）。
# 会話の行の書き方は [before] と同じ（「話し手: 文」、頭に > で地の文。10 行まで、1 行は 60 字まで）。
# 立つ人物は、その場面で話す人（[cast] の姿）。
# (name): ここで主人公の名前を聞く（どの会話の節にも書ける。[before]・[after] にも）。すぐ前の行が、名を問う行になる。
#         名前の窓が出るのは、まだ名乗っていないときだけ（名乗ったあとは、何もせずに次の行へ進む）。
#         これより前の行では、主人公を名前で呼ばない（{hero} を書かない。まだ名乗っていないので）。物語に 1 か所、最初の話に置く。
[talk 練兵場]
place = drill_field
music = talk
> 出発の前の晩。練兵場には、まだ灯りが残っていた。
新兵: 少尉。お名前を、まだ聞いていませんでした。
(name)
レオ: {hero}だ。覚えておけ。
新兵: {hero}少尉、明日は尾根ですね。
レオ: ああ。今夜は早く寝ておけ。

# カットシーン: 地の文だけの場面。文の枠も話し手も出さず、背景の上に、文を 1 行ずつ真ん中に出す（上下に黒い帯）。
# 時間や場所が大きく飛ぶ所、物語の節目に。6 行まで、1 行は 60 字まで。台詞・選択肢は書けない。
#   place / look: 背景の景色（[talk 名前] と同じ）。書かなければ、この話の盤の景色。
#   color:        景色のかわりに、色の幕にする（black = 黒、night = 夜の藍）。place とは、どちらかだけ。
#   music:        曲（[talk 名前] と同じ）。
[cut 夜の行軍]
color = night
music = talk_calm
隊は、夜のうちに谷を抜けた。
だれも、口をきかなかった。

# 盤のカットシーン: 盤の上で、兵が台本どおりに動く（docs/story.md の「盤のカットシーン」）。
# 兵が動いている間は文が出ず、文を読んでいる間は盤が止まる（台本の行と文の行を、書いた順に交互に）。
#   place / look / music: [talk 名前] と同じ（書かなければ、この話の盤の景色。立つのは台本の兵だけ）。
# 台本の行（座標は「x,y」。左上が 0,0。名前は兵の名前で、[cast] の話し手と同じ名前なら、その人の形で立つ）:
#   unit 名前 陣営 種類 x,y      始めの盤に置く兵（台本の頭に）。陣営は ally・enemy・neutral、種類は駒の種類（king、sniper、skeleton など）
#   camera x,y | camera 名前    カメラを寄せる（unit のすぐあとなら、始めからそこを映す）
#   move 名前 x,y [x,y …]       歩く（書いたマスを順に通る。間は近い道を埋める）
#   attack 名前 相手 [量]       攻撃する（量を書かなければ、その兵の攻撃力。HP が 0 になれば倒れる）
#   fall 名前                   倒れる
#   appear 名前 陣営 種類 x,y    光とともに現れる          put 名前 陣営 種類 x,y   光を出さずに置く
#   leave 名前 [x,y …]          歩いてから、倒れずに去る    face 名前 x,y | 相手      向きを変える
#   status 名前 状態            状態が付く（バリア など）    pace slow | normal | fast  このあと歩く速さ
#   wait 秒                     間を置く（5 秒まで）
# 文の行は「話し手: 文」と「> 地の文」（1 から 10 行。選択肢と条件は書けない）。
[board 尾根の朝]
music = talk_calm
unit レオ ally king 8,19
unit 新兵 ally sniper 10,19
unit 骸骨 enemy skeleton 7,12
camera 8,17
> 霧の向こうで、何かが動いた。
move 骸骨 7,16
face レオ 骸骨
face 新兵 骸骨
新兵: {hero}少尉、骸骨です。
レオ: 撃て。
attack 新兵 骸骨 20
> 骸骨は崩れて、動かなくなった。
pace fast
move 新兵 9,17

# 選択肢（どの会話の節にも書ける。[before]・[after] にも）。括弧で始まる行が指示:
#   (choice 名前)         ここで選ばせる。すぐ前の行が問いになる。名前（英小文字・数字・_）で答えを覚える。物語の中で重ねない。
#   (answer 鍵) 画面の文   答え。2 つか 3 つ。画面の文は 22 字まで。次の (answer)・(end) までの行は、この答えを選んだときだけ出る（無くてもよい）。
#   (end)                 選択肢の終わり。ここから元の流れに戻る。
#   (if 名前 = 鍵) 行      その答えを選んでいたときだけ出る行（あとの会話でも、あとの話でも書ける）。「!=」なら、選んでいなかったとき。
# 選んだ答えはセーブに残る。行の数は、いちばん長い答えで数える（10 行まで）。[cues] と [lost] には書けない。
[talk 尾根の下]
place = ridge_path
look = crystal_night
music = talk_calm
> 翌朝、隊は尾根の下に着いた。
新兵: {hero}少尉、どちらから登りますか。
(choice template_route)
(answer left) 左の岩場から行く
レオ: 左だ。岩場なら、身を隠せる。
(answer right) 右の坂を急ぐ
レオ: 右だ。日が高くなる前に登りきる。
新兵: 走るんですね……。
(end)
レオ: ここから先は、声を落とせ。

# 対戦。途中の台詞 [cues] と負けたときの台詞 [lost] は、この対戦のもの。

# 対戦のあとにも、場面をいくつでも並べられる（会話・別の場所の会話・カットシーン・盤のカットシーン。勝って、決着の画面の「次へ」を押すと、書いた順に出る）。
# 負けたときは出ない（決着の画面に [lost] の台詞）。クリアの記録は、決着の画面が出た時点で書く（あとの場面を読まずに抜けても残る）。
# place の無い会話は、盤の前で話す（決着したときに生き残っていた兵が立つ）。
[talk 決着のあと]
music = talk_bright

# カットシーンで、時間と場所を飛ばす。

# 最後の場面は、カットシーンでもよい（そのときの知らせは、あとに知らせだけの場面を足して出す）。
