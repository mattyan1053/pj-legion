# 話のファイルの見本、その 2: 場面をいくつも並べる書き方（docs/story.md の「場面の節」）。写して使う。
#
# first_battle.txt の書き方（[before]・[after]）は「出撃準備 → 会話 → 対戦 → 会話」の決まった形。
# こちらは、会話の場面「[talk 名前]」をいくつでも書けて、[sortie]（出撃準備）と [battle]（対戦）を挟む所も選べる。
# **節を書いた順が、場面の順。** ほかの節（[episode]・[cast]・[cues]・[lost]・[ally]・[enemy]・[unlock]）は first_battle.txt と同じ
# （どこに書いても場面の順には入らない）。
#
# - [battle] を書かなければ、対戦の無い話（読むだけの話。最後の会話を読み終えたらクリア）。
#   そのときは [sortie]・[cues]・[lost]・[ally]・[enemy] を書かず、[cast] に enemy の話し手がいなくてよい。map は、背景の景色と話の一覧の絵に使う。
# - [sortie] を書かなければ、出撃準備は話の最初。
# - 対戦は 1 つの話に 1 つまで。会話の場面は 8 つまで。

[episode]
title = 見本の話（場面をいくつも）
map = ridge_path
# before_music・after_music は書かない（曲は、会話の場面ごとに music で選ぶ）。

[cast]
少尉 = ally
新兵 = ally, sniper
敵将 = enemy, paladin evolved

# 会話の場面。「talk」のあとの名前は、話の中で重ならなければ何でもよい（台本の見出しに出る。画面には出ない）。
# 頭に、設定を「キー = 値」で書ける（どれも無くてよい。会話の行より前に書く）:
#   place: 背景にする別の場所（game/maps/ のマップの名前）。その場所の景色だけを映す（兵は立たない）。
#          書かなければ、この話の盤（対戦の前は初期位置の兵、対戦のあとは生き残った兵が立つ）。
#   look:  place の景色を替える（stage_look.gd の見た目の名前）。place と組で書く。
#   music: 曲（sound_catalog.gd の MUSIC の名前）。どの会話にも書く（検査が確かめる）。
#          対戦の曲（battle で始まる名前）を書けるのは、対戦より前の会話に、その話の対戦の曲だけ。
# 会話の行の書き方は [before] と同じ（「話し手: 文」、頭に > で地の文。10 行まで、1 行は 60 字まで）。
# 立つ人物は、その場面で話す人（[cast] の姿）。
[talk 練兵場]
place = drill_field
music = talk
> 出発の前の晩。練兵場には、まだ灯りが残っていた。
新兵: 少尉、明日は尾根ですね。
少尉: ああ。今夜は早く寝ておけ。

[talk 尾根の下]
place = ridge_path
look = crystal_night
music = talk_calm
> 翌朝、隊は尾根の下に着いた。
少尉: ここから先は、声を落とせ。

# 出撃準備を、ここに挟む（書かなければ、話の最初）。
[sortie]

# 設定を書かない会話は、この話の盤を前にして話す（first_battle.txt の [before] と同じ見え方）。
[talk 盤の前]
music = talk
新兵: 少尉、前に騎士がいます。
敵将: かかってこい。
