# 話のファイルの見本（docs/story.md の「話のファイル」）。写して使う。
#
# - ファイルの名前（.txt を除く）が話の id。クリアの記録に書くので、配ったあとは変えない。ほかの物語の話とも重ねない。
# - 話を足すには、このファイルを物語のフォルダに別の名前で写して直し、物語のファイル（story.txt）の [episodes] に id を 1 行足す。
# - # で始まる行と空の行は読み飛ばす。[名前] の行で節を始める。
# - 上の半分が台本（話の名前、話し手、会話）、下の半分が戦いの設定（部隊、初期位置、クリアで増えるもの）。
# - 会話の場面をいくつも並べる（別の場所の会話、対戦の無い話）なら、同じフォルダの scenes.txt の書き方。
# - 書き間違いは、起動したときと検査（tools/check.sh）が「ファイル:行: 何がおかしいか」で知らせる。書き間違いのある話は、話の一覧に並ばない。

[episode]
# 話の名前（会話の見出しと、話の一覧のカードに出る）。
title = 見本の話
# 戦うマップ（game/maps/ のファイルの名前。.txt を除く）。景色もマップが決める。

#   old_battlefield（古戦場）, boulder_pass（大岩の峠）, mist_forest（リュエルの森）, crystal_quarry（結晶の採掘場）, seam_vale（縫い目の谷）
map = ridge_path
# 前の会話の曲と、あとの会話の曲（sound_catalog.gd の MUSIC の名前。docs/sound.md）。どの話も書く（テストが、話ごとに選んであることを確かめる）。
# 書かなければ、対戦の曲（会話の間は小さく鳴らし、そのまま対戦へつながる）と、落ち着いた曲（talk_calm）になる。
# 前の会話に対戦の曲（battle で始まる名前）を書くなら、その話の対戦の曲と同じにする（検査が確かめる）。

# 勝ったときの調子。bright（明るい。ファンファーレのあと静かな曲）か quiet（静か。ファンファーレを鳴らさない）。書かなければ bright。
# 弔いや敵討ちのあとなど、明るくない話は quiet。
# victory_mood = quiet
# 出撃準備に出す「この話で覚えること」（48 字まで）。書くと、話の一覧で「（演習）」と付く。
# lesson = 駒をクリックして動かし、隣の敵を攻撃する。
# 勝ち方。書かなければ、いつもの勝ち方（敵の将を倒すか、敵の本陣を占拠する）。
#   hold_turns: 人がこのターンの終わりまで将と本陣を守り切れば勝ち。
#   wins: 人の勝ち方を「,」で区切って書く（書けば、いつもの勝ち方を置き換える）。
#     king_defeated（将の撃破）, hq_captured（本陣の占拠）, routed（全滅させる）, boss_slain（どちらかの中ボスを倒す）,
#     turns_held（守り切る。hold_turns と組で書く）
# hold_turns = 10
# wins = routed
# 中ボスの名前（6 字まで）。画面では「中ボス」と言わず、この名前で呼ぶ（勝ち方・ログ・決着の文）。
# 書かなければ、マップのファイルの boss（大岩の峠なら「峠の番人」）。どちらも無ければ「番人」。
# boss = 峠の番人
# 縫い目の様子（マップに付く、気候のような効果。docs/seam-signs.md）。2 つまで、「,」で区切って書く。書かなければ付かない。
# 対戦の始めの「対戦ルール」に、勝ち方と並んで出る。効く札は、マップに合うものを選ぶ（結晶泉の無いマップに loose を書いても何も起きない）。
#   haze（天裂の名残り）, brim（糸の満ち）, loose（糸のゆるみ）, hush（骨の眠り）, shift（仮縫いのずれ）,
#   gale（縫い代の風）, gleam（天裂の光）, thicket（深い茂み）, taut（張りつめた糸）
#   loose と hush、haze と gleam は打ち消し合うので並べない。
# signs = gale, taut

# 話し手。1 行に 1 人で「名前 = 陣営, 姿」。
#   陣営: ally（遊ぶ人の軍。会話で左に立ち、名前の札は青）か enemy（敵の軍。右に立ち、札は赤）。どちらも 1 人は要る。
#   姿:   会話の場面に立たせる駒の形（駒の種類の名前。king や、魔物の skeleton なども書ける）。書かなければ将（king）。
#         後ろに evolved を付けると進化後の形。最後に crown を付けると、頭の上に将の印（将の姿でない将。paladin evolved crown）。
#   部隊の中の人でも、部隊の外の人（教官、伝令）でもよい。それぞれの陣営で最初に書いた人が主な話し手
#   （敵の主な話し手の姿は、話の一覧のカードの顔になる）。同じ側に何人いても、話した人に入れ替わって立つ。
[cast]
少尉 = ally
新兵 = ally, sniper
敵将 = enemy, paladin evolved

# 対戦の前の会話。1 行が 1 つの文で「話し手: 文」（話し手は [cast] に書いた名前）。10 行まで、1 行は 60 字まで。
# 出撃したあと、盤を前にして話している。書き方のこつは docs/story.md の「会話の書き方」。
# 頭に > を付けた行は地の文（話し手のいない行。場面の説明や時間の経過）。名前の札なしで、真ん中に明朝で出る。
# 話の頭の場面や、物語の最後の締めに 1 行だけ。入れすぎない。
[before]

# 無くてよい節: 対戦の途中の台詞（盤の上の札に出す）。「(きっかけ) 話し手: 文」。3 つまで、文は 40 字まで。地の文は書けない。
#   (turn 3)           ターン 3 の、人の番の始め（turn 1 は対戦の始め）
#   (fallen ally)      人の軍の駒（将を除く）が初めて倒れた。敵の軍なら (fallen enemy)
#   (king_half enemy)  敵の将の HP が半分を切った。人の将なら (king_half ally)
#   (ult_ready ally)   人の軍の必殺技が使えるようになった
#   (relic ally)       人の軍が聖遺物を受け取った（中ボスを倒した）
[cues]

# 決着の画面の見出しの下に、戦績と並べて出す（会話の場面は挟まない）。次にどうすればよいかを、世界の中の言葉で。
