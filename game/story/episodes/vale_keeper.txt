# ストーリーの話「墓守の眠り」。FANTASY の物語の本編 9 話目（物語の最後の話。2 つの物語の締め）。
#
# 世界と登場人物は Issue #49 の案 A「空の縫い目」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 発破は止まったが、起きた骨は戻らない。縫い目の谷で、墓守が最後の骨を率いて立つ。墓守は骨を起こす者ではなく、
# 起きた骨を谷に留めてきた古い番人で、体は結晶に従い、心は眠りを願っている。倒して、番人として送る。
# 手で作ったマップ「縫い目の谷」（game/maps/seam_vale.txt。ポータルの多い盤）。
# 人の勝ち方は将の撃破だけ（wins）。旗を取っても終わらない。敵は軍に属さない魔物の群れ（army = none）で、将（墓守）がいる。
# 骸骨術師と骸骨鼓手がいるので、群れを減らしきることはできない。ポータルは墓守の脇へ出るが、骨も同じ輪で人の本陣へ来る。
# あとの会話に、ハーデンの隊が味方の側で出る（2 つの物語が交わる所）。
# 書き方は docs/story.md の「話のファイル」（欄の説明つきのひな形は game/story/template.txt）。

[before]
ティオ: 光る輪だらけだ……。こんなに、ほころびてたの？
ウル: 縫い目の谷じゃ。糸を抜かれて、いちばん傷んだ所よ。輪は、向こうの旗の脇へも通じておる。
墓守: 来たか、祈りの子ら。鉄の子らにも一度倒された。だが結晶が、わしを寝かせてくれぬ。
イェルダ: 墓守どの。貴殿は骨を起こす者ではない。起きた骨を、谷に留める番人であった。
墓守: 留めきれなんだ。……この体は結晶に従う。手加減は、できぬぞ。
セリス: 自分を倒せって言ってるよ。旗を取っても終わらないね、これは。
ティオ: ……ぼく、焼くよ。魔物じゃなくて、番人として。ちゃんと送る。
イェルダ: うむ。杖の骨が起こし、太鼓の骨が急き立てる。群れに構わず、墓守へ届け。

[after]
墓守: ……ああ。結晶の声が、遠くなる。20 年ぶりの、眠気じゃ……。
ティオ: おやすみなさい、番人さん。
ウル: 番人の務めは、わしらが継ごう。もう糸は抜かせぬ。
ハーデン: 連邦も加わる。少佐は樽を下ろした。採掘場は、今日で閉じる。
セリス: へえ。じゃあ今日から同じ側ってわけ、鉄の人。
ドーソン: はっは。騎士と並んで縫い目の番か。長生きはするもんだ。
イェルダ: ハーデン。尾根で貴公は、退く私を追わなかった。あれが、最初の一針であった。
ハーデン: ……なら、続きを縫おう。騎士長。
ウル: 縫い目は裂くより、縫うためにある。……やっと言えたのう。よう縫うた、皆。
