# ストーリーの話「古戦場の亡者」。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 敵は軍に属さない魔物の群れ（army = none。必殺技は無い。docs/unit-roster.md の「魔物」）で、将がいない（king = none。旗の下は空）。
# 骸骨術師が骸骨兵を起こして数を増やす（骨起こし）。先に術師を倒すと、群れが増えなくなる。
# 手で作ったマップ「古戦場」（game/maps/old_battlefield.txt）。見た目は石の壁（崩れた壁と柱）のテーマ。
# 人の勝ち方は「敵を全滅させる」だけ（wins）。亡者の群れを倒しきるまで終わらない。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 谷へ下りる古戦場で、亡者が立ち上がる。率いる者がいない。
# 伝わること: 将のいない群れ。杖の骸骨が起こす。
# 知る・変わる: 盾の紋から、亡者は両国の兵らしいと分かる（紋の塗りは、昨日まで使っていたように新しい）。術師の「墓守さまが、尾根へ行かせてくれぬ」という言葉で、亡者を起こして従える者が別にいると**思い違える**（ほんとうは、墓守が谷に留めている）。
