# ストーリーの話「縫い目の発破」。MILITARY の物語の本編 9 話目（物語の最後の話）。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# ヴァルト少佐の本隊が、結晶の採掘場に起爆樽を並べ、山ごと発破で崩そうとしている。ハーデンの隊は 2 手に分かれて挟み、少佐を止める。
# 手で作ったマップ「結晶の採掘場」（game/maps/crystal_quarry.txt。起爆樽の多い盤）。
# 味方は 2 か所に分かれて始まる（deploy）: 将のいる正面の組は本陣のそば、脇の組は西の端の中ほど。
# 脇の組をもっと北（敵の陣地のそば）に置くと、合流の前に敵のスナイパーに撃たれて、既定の編成が負ける局が出た。
# 敵は MILITARY の本隊（連邦どうしの戦い。盾持ちの盾役・スナイパー 2・衛生兵）。スナイパーは樽も撃つ。勝ち方はいつもどおり（将の撃破、本陣の占拠）。
# 同じ時、尾根の砦ではイェルダの隊が亡者を止めている（FANTASY の物語の「尾根の亡者」）。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 試しの 1 発は、もう撃たれた。偵察隊は 2 手に分かれて本隊を挟み、少佐を止める。
# 伝わること: 2 か所から始まる戦い。樽は敵にも味方にも危ない。
# 知る・変わる: 少佐の理由は冬（最初の冬に、燃料の車列を率いた）。ハーデン「連邦の兵だから、呑まれた連邦の兵を、これ以上起こさせない」。ドーソンが初めて、同期が尾根の下にいると口にする。少佐は樽を下ろし、責めは自分が負う（「報告書は、私が書く」）。止まるのは、この谷の採掘場だけ。冬の燃料は片付いていない。尾根の砦を騎士が守ったと知り、谷の奥へ向かう（墓守は、結び直ってまた立っている）。
