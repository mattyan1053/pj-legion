# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。

# 1・2 話と同じマップ「尾根の小道」（game/maps/ridge_path.txt）を、勝ち方を変えて使い回す（Issue #49 の「マップの使い回し」）。
# 人は守る側: 決められたターンが終わるまで、将と本陣を守り切れば勝ち（hold_turns。docs/win-conditions.md の「守り切る」）。
# 敵は数で押す。尾根の奥（敵の本陣の前）から始まり、いつもの勝ち方（将の撃破、本陣の占拠）で攻めてくる。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 影刃セリスの追っ手に囲まれ、少佐の本隊が着くまで守る。ヴァルト少佐が本隊を尾根に上げ、石壁を砦にする。
# 伝わること: 守り切る勝ち方。少佐の人となり（結晶は燃料、騎士には渡さない。退く騎士を「追いなさい」と言う）。
# 知る・変わる: ノエが「ひよっこ」を卒業する。**本隊が仮縫いの尾根に上がるのは、20 年、どちらの国も恐れてやらなかったこと（大勢の重みで、足もとがゆるむ）。少佐の最初の一歩。** 気付くのはドーソンとマルタ（「相変わらずだな」）と、退くセリスだけ。
