# FANTASY の物語の「森の守り」で敗れて退いたハーデンの隊が、イェルダに言われて峠の番人（中ボス）に会う。
# 手で作ったマップ「大岩の峠」（game/maps/boulder_pass.txt）。FANTASY の物語の「峠の番人」と同じマップを、敵を変えて使う。
# 人の勝ち方は中ボスの撃破だけ（wins）。敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。
# 群れは番人のまわりから始まる（deploy）。骸骨術師が骸骨兵を起こし、骸骨鼓手が周りを突撃させるので、
# 群れを片付けてから番人、とはいかない。群れを払いながら番人を倒す話。
# クリアで増えるのは持ち物 1 つ（獣道の地図。手を組んだ印に、相手の国の持ち物）。コスト上限は動かさない。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: イェルダに「峠の番人は 2 体いる。自分の目で見よ」と言われ、峠へ。騎士が倒したはずの番人も、結び直って立っている。番人を倒して、覚えていることを受け取る。
# 伝わること: 亡者に構わず番人を狙う。番人は倒されても、糸があるかぎり立つ。
# 知る・変わる: **連邦が初めて知る。** 結晶は降ってきた石ではなく、縫い目を留める糸。掘るたびにゆるみ、呑まれた兵が出てくる。「亡者を起こしていたのは、俺たちだ」。少佐が採掘場に樽を並べ、山ごと発破で崩すと知る。聖遺物を証に、報告へ行く。
