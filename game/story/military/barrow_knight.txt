# ストーリーの話「墓守」。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 前の話（barrow_rout）と同じマップ「古戦場」を、敵の初期位置と勝ち方を変えて使い回す。
# 敵は軍に属さない魔物の群れ（army = none）。前の話より多く、盤の中ほどの霊廟のまわりから始まる。
# 勝ち方はいつもどおり（将の撃破、本陣の占拠）。群れを相手にせず、敵の将（墓守）を狙ってもよい。
# 両脇の骸骨兵は、脇から人の本陣へ回り込んでくる。右の 1 体を 1 マス奥（14,8）に置き、まっすぐ本陣へ届かないようにした
# （14,9 では、既定の編成が本陣を空けて取られる負け方が 3 割ほどあった）。ターン 4 の台詞で、本陣を空けるなと伝える。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 墓守を倒す。少佐から「騎士領の森へ回れ、結晶の出どころを押さえろ」と命令が届く（森の奥には、騎士領の 300 年ものの太い縫い目がある）。
# 伝わること: 亡者は両国の兵。墓守は、眠らせてやれなかった、留めていただけだと言う。
# 知る・変わる: 墓守は起こす者ではなかった（ここでは半分しか分からない。墓守の言う「糸」が何かを、連邦の者はまだ知らない）。ハーデンが初めて、命令に自分の条件を付ける（「先に騎士長イェルダと話す」）。
