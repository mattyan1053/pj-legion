#
# チュートリアルの話は、1 つの話で 1〜2 個だけ教える（docs/story.md の「チュートリアル」）。
# 部隊は決まっていて（[ally] の unit）、敵は少なく、まず負けない。教え方は、出撃準備の文（lesson）と、対戦の途中の台詞（[cues]）。
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
# 教えること: 進化の選び方（レベル 3 に上がった駒は、2 つの進化先から 1 つを選ぶ。docs/branch-evolution.md）。
# パラディンとソーサラーは、あと 1 撃でレベル 3 に上がるところから始める（駒の行の level・exp。docs/story.md の「始めのレベル」）。
# 敵の盾役は手の届く所で待つので、最初の番に 2 体とも攻撃でき、続けて 2 回、進化先を選ぶことになる。
# 敵の顔ぶれは、どちらの進化先の違いも直後の数手で出るようにした:
#   コマンドーは速く、後ろのソーサラー・プリースト・将へ跳び込んでくる（エンチャンターの支配領域が止める。クルセイダーは追える）。
#   スナイパーは壁の陰から撃ってくる（アークメイジの射程 3 なら、前へ出すぎずに撃ち返せる。セイクリッドの再生は削られても戻る）。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 一人前になる者が、2 つの道から 1 つを選ぶ。
# 伝わること: 進化。選んだら戻らない（縫い代に長くいると、糸が人にも入る）。
# 知る・変わる: 岩山の向こうに連邦の斥候が出たと知らせが来る。修練の終わり。

(fallen enemy) イェルダ: 道は選んだな。もう迷うな、その型で押せ。

[after]

[lost]
