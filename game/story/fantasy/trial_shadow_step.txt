# ストーリーの話「影渡り」。FANTASY の物語のチュートリアル（4 / 6）。1 話 1 ファイル。
#
# チュートリアルの話は、1 つの話で 1〜2 個だけ教える（docs/story.md の「チュートリアル」）。
# 部隊は決まっていて（[ally] の unit）、敵は少なく、まず負けない。教え方は、出撃準備の文（lesson）と、対戦の途中の台詞（[cues]）。
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
# 教えること: スペルブレードのシャドウステップ（間を通らずに跳ぶ。敵と入れ替わる。跳んだあとに攻撃できる）。クリアでスペルブレードを雇えるようになる。
# 敵の将は、盾役 2 体に前と横をふさがれて始まる（deploy）。勝ち方は将の撃破だけ（wins）。歩いて回り込むより、跳び込むほうが早い。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 雇われの影刃セリスが、盾の奥の将を跳んで斬ってみせる。
# 伝わること: シャドウステップ。影刃は騎士の家の者ではなく、技も騎士の技ではない（ほころびを自分で開けて閉じる。縫い目を傷めるので、騎士の家では教えない）。
# 知る・変わる: セリスが隊に入る（「まっすぐすぎて放っておけない」）。

セリス: だろうね。あたしは好き。「シャドウステップ」で、盾も壁も跳び越えるから。

セリス: 10 年早いよ、坊や。
