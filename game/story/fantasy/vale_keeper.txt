# ストーリーの話「墓守の眠り」。FANTASY の物語の本編 9 話目（物語の最後の話。2 つの物語の締め）。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 発破は止まったが、起きた亡者は戻らない。縫い目の谷で、墓守が最後の亡者を率いて立つ。墓守は亡者を起こす者ではなく、
# 起きた亡者を谷に留めてきた古い番人で、体は結晶に従い、心は眠りを願っている。倒して、番人として送る。
# 手で作ったマップ「縫い目の谷」（game/maps/seam_vale.txt。ポータルの多い盤）。
# 人の勝ち方は将の撃破だけ（wins）。旗を取っても終わらない。敵は軍に属さない魔物の群れ（army = none）で、将（墓守）がいる。
# 骸骨術師と骸骨鼓手がいるので、群れを減らしきることはできない。ポータルは墓守の脇へ出るが、亡者も同じ輪で人の本陣へ来る。
# あとの会話に、ハーデンの隊が味方の側で出る（2 つの物語が交わる所）。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 発破は止まったが、出てきた亡者は戻らない。糸を抜かれていちばん傷んだ谷で、墓守を番人として送る。ハーデンの隊も並ぶ。
# 伝わること: 群れに構わず、墓守へ。ほころびは、こちらにも敵にも近道。
# 知る・変わる: 墓守は起こす者ではなく、留めてきた番人だった。その務めを、両国の隊が継ぐ（1 つの谷の、隊どうしの約束。国は、まだ何も決めていない）。番人は倒されても結び直るが、墓守は「交代」と聞いて眠る（務めを継ぐ者が来たと分かったから。亡者の軍曹と同じ）。ハーデンは「この谷の採掘場は止まった。先のことは、冬までに議会が決める」とだけ言う。ウルが初めて、ことわざを言い切る（「縫い目は裂くより、縫うためにある」）。
