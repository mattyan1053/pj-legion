#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# 手で作ったマップ「大岩の峠」（game/maps/boulder_pass.txt。対戦モードのために作ったマップを、ストーリーでも使う）。
# 人の勝ち方は中ボスの撃破だけ（wins）。敵の将を倒しても終わらない。敵はいつもの勝ち方（将の撃破、本陣の占拠）で攻めてくる。
# 中ボスを先に狩るか、敵を退けてから狩るかを選ぶ話。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 番人を倒して、覚えていることを受け取る。少佐の隊も番人を狙っている。少佐は聞く耳を持たず、偵察隊を騎士領の森へ回す。
# 伝わること: 番人を倒せば勝ち。番人は、その縫い目で起きたことを覚えている。
# 知る・変わる: **騎士領が、自分の落ち度を知る。** 番人が見せるのは呑まれた日。仮縫いがずれ、両軍が縫い込まれた。骨はその兵。そして、若い縫い目から糸を引いてきたのは騎士領も同じだった（300 年の習いが、ここでは通らない）。

[before]
ウル: 大岩の脇の、あの大きいの。あれが峠の番人じゃ。縫い目の結び目に立って、起きたことを覚えておる。
ティオ: 番人って、あれ！？ でっかい……。
ウル: 倒せば、糸の端を渡してくれる。聖遺物じゃ。番人の覚えておることも、共にな。
ヴァルト: また騎士！ 番人は連邦が頂くわ。あれは良い燃料になるもの。
セリス: 燃料、ね。話の通じない鉄の人もいるもんだ。
イェルダ: 少佐を討っても番人は残る。狙うは番人だ。ただし、本陣を空けすぎるな。

[cues]
(turn 1) ウル: 番人は大岩の脇じゃ。近いほうを狙え。
(turn 5) セリス: 鉄の人に構いすぎ。番人を倒せば、こっちの勝ちだよ。

[after]
ウル: ……見えた。番人の覚えておることが。呑まれた日じゃ。
ウル: 仮縫いがずれて、両軍が縫い込まれた。骨は、その兵よ。糸を抜かれるたびに、出てくる。
イェルダ: 糸を抜く……。連邦の採掘のことでありますか、導師。
ウル: それだけではない。わしらも引いた。300 年そうしてきたからと、仮縫いの糸までな。
イェルダ: ……掘るなと言ってきた、われらも。
ヴァルト: 世迷い言を！ ……偵察隊を森へ回しなさい。燃料の出どころを押さえるのよ！
セリス: 森って、うちの森じゃないか。
イェルダ: 森へ戻る。番人の根もとにあった古竜の鱗を持て。急ぐぞ。

[lost]
ウル: 番人に急ぐあまり、旗が空いておったのう。
