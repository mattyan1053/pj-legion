# ストーリーの話「尾根の亡者」。FANTASY の物語の本編 8 話目（森の守りの次）。
#
# 世界は docs/world.md、登場人物は docs/story.md の「世界と登場人物」。会話は、人物どうしの掛け合いで書く（docs/story.md の「会話の書き方」）。
#
# ヴァルト少佐の試しの発破で、谷じゅうの亡者が起き、昔の旗のあった尾根へ歩き出す。尾根の砦に残るのは連邦の怪我人と、
# ハーデンに負けたばかりの教導隊（MILITARY の物語の「最後の演習」）。亡者を追ってきたイェルダの隊が砦に入り、
# ハーデンが発破を止めるまで守る（MILITARY の物語の「縫い目の発破」と同じ時）。
# 手で作ったマップ「尾根の小道」（game/maps/ridge_path.txt）。「尾根の砦」では本陣を奪った盤で、今度は守る。
# 人の勝ち方は守り切るだけ（hold_turns と wins）。敵は軍に属さない魔物の群れ（army = none）で、将がいない（king = none）。
# 骸骨術師が骸骨兵を起こし、骸骨鼓手が周りを突撃させる。倒しても終わらないので、将と旗を守る位置取りの話。
# クリアで増えるのは持ち物 1 つ（遠眼鏡。手を組んだ印に、相手の国の持ち物）。コスト上限は動かさない。
# 書き方は docs/story.md の「話のファイル」（書き方の見本は game/story/_template/）。
#
# 仕上げの書き手へ（この話の背骨。docs/story-outline.md の写し。台詞をどう直しても、ここは崩さない）
# 起きること: 少佐の試しの発破で、谷じゅうの亡者が出て、昔の旗のあった尾根へ歩く。砦には連邦の怪我人と教導隊員しかいない。ハーデンが発破を止めるまで、砦を守る。
# 伝わること: 守り切る勝ち方。太鼓と杖の骸骨を先に。
# 知る・変わる: ハーデンの知らせで、番人の記憶のもう半分（掘るのも引くのも同じ）と、少佐の発破を知る。**かつて奪った砦を、連邦のために守る。**墓守が、出てきた亡者をひとりで谷に留めていると分かる。
