# 呼び方と一人称の表（docs/story.md の「口調の見本」）。だれが、だれを、何と呼ぶか。
#
# 人間が直してよいファイル。直したら、台詞のほう（各物語の話のファイル）を合わせる。
# 検査（tests/tools/test_voice_check.gd。道具は tools/voice_check.gd）が、全部の話の台詞をこの表に掛けて、
# 表に無い呼び方・一人称、言わないことにした言葉、名前と結びつく前に肩書きだけで呼んだ所を落とす。
# 手元で一覧を見るには: godot --headless --path . -s res://tools/voice_report.gd
#
# 書き方: [話し手] の節に「キー = 言い方, 言い方, …」。
#   self  = その人の一人称
#   you   = 相手を選ばない二人称（[watch] の words のうち、その人が使ってよいもの）
#   avoid = その人が言わないことにした言葉（台詞に入っていたら落とす）
#   <人の名前> = その人を呼ぶ言い方（呼びかけでも、その場にいない人の話でも）。名前そのままで呼ぶなら、名前も書く
# 話し手の節が無い人は見ない。節があってキーが無い相手は、その相手を名前でも肩書きでも呼ばない人。
