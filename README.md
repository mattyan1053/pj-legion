# pj-legion（プロジェクト・レギオン）

1vs1 のタクティクスボードゲーム。2D で作っていた [pj-region](https://github.com/mattyan1053/pj-region)（非公開）を、
Godot で**ゲーム性はそのまま、見た目を俯瞰 3D に**作り直す趣味プロジェクト。

## 動かし方

1. [Godot 4.7 の通常版](https://godotengine.org/download/)（.NET 版ではないほう）を入れる
2. このリポジトリを clone し、Godot の「インポート」で `project.godot` を開く
3. F5 で実行する

いまは、ルール（`rules/`）の最初の部分（盤面・駒・ターン・移動・攻撃・回復・支配領域・勝敗・環境オブジェクト・中立の駒・成長と進化）、CPU の思考、それにつないだ見た目の試作（`prototype/`）が入っている。
1 人で CPU を相手に、または 2 人が 1 台で交代しながら、対戦を最後まで遊べる。自分はプレイヤー1（青）。編成は仮の決め打ち。ルールの仕様と画面の作りは [`docs/`](./docs/)。

Godot を入れずに遊ぶなら、GitHub Actions の `build` の成果物 `pj-legion-windows`（Windows 用の exe）をダウンロードする。

| 操作 | 内容 |
| --- | --- |
| 左クリック（駒） | 駒を選ぶ。相手の駒や行動済みの駒を選ぶと、移動範囲だけが見える |
| 左クリック（青いマス） | 選んでいる駒を移動する |
| 左クリック（黄のマス） | 巡航で移動する（2 倍動けるが、その行動では攻撃できない） |
| 左クリック（赤いマスの相手） | 攻撃する（動く前でも、動いたあとでもよい） |
| 左クリック（緑のマスの味方） | 回復役で回復する（動く前でも、動いたあとでもよい） |
| 左クリック（赤いマスの樽） | 樽を攻撃して爆発させる（マウスを乗せると、巻き込む橙のマスと見込みが出る） |
| Space / 「待機」 | 選んでいる駒の行動を終える |
| Esc / 右クリック / 「移動を取り消す」 | 動いたあとなら移動を取り消す。そうでなければ選択をやめる |
| 1・2 / 進化先のボタン | レベル 3 に届いた駒の進化先を選ぶ（選ぶまで、ほかの操作はできない） |
| Enter / 「ターン終了」 | 相手の番にする（未行動の駒が残っていれば、もう一度押すと終わる） |
| F1 / F2 / F3 | 新しい盤面で最初から（ステージ 1 / 2 / 3） |
| F4 / 右上のボタン | 相手（プレイヤー2）を CPU にするか、人にするかを切り替える（始めは CPU） |
| WASD / 矢印 | カメラの移動 |
| Q / E | 90 度回転 |
| R | 見下ろす角度の切り替え（3 段階） |
| ホイール | 拡大・縮小 |

敵の将を倒すか、敵の本陣（旗のあるマス）に自分の駒を乗せたままターン終了を 3 回続けると勝ち。
樽の爆発で両方の将が同時に倒れると引き分け。

ステージごとに環境オブジェクトがある。

- ステージ 1: 起爆樽。入れない。攻撃すると爆発して、周り 8 マスの駒すべて（味方も自分も）に 15 ダメージ。
- ステージ 2: 回復の泉（緑の十字の札）。乗ったまま自分の番を迎えると 12 回復する。
- ステージ 3: ポータル（同じ色の輪の 2 つがつながっている）。行き先を選ぶと、近道になるときは自動で通る。
  出口に駒がいる間は通れない。

## 検査

```bash
tools/check.sh /path/to/godot
```

画面なしでプロジェクトを取り込み、テスト（`tests/`）を実行し、メインシーンで自動の対戦を最後まで進めて、スクリプトのエラーが無いことを確かめる。
CI（`.github/workflows/ci.yml`）も同じスクリプトを回す。

作業の決まりごとは [`CLAUDE.md`](./CLAUDE.md)、文書の置き方は [`docs/README.md`](./docs/README.md)。
