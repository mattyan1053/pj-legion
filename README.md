# pj-legion（プロジェクト・レギオン）

1vs1 のタクティクスボードゲーム。2D で作っていた [pj-region](https://github.com/mattyan1053/pj-region)（非公開）を、
Godot で**ゲーム性はそのまま、見た目を俯瞰 3D に**作り直す趣味プロジェクト。

## 動かし方

1. [Godot 4.7 の通常版](https://godotengine.org/download/)（.NET 版ではないほう）を入れる
2. このリポジトリを clone し、Godot の「インポート」で `project.godot` を開く
3. F5 で実行する

いまは、ルール（`rules/`）、CPU の思考、それにつないだ画面の側（`game/`）が入っている（機能ごとの仕様は [`docs/`](./docs/)）。
1 人で CPU を相手に、または 2 人が 1 台で交代しながら、対戦を最後まで遊べる。起動するとタイトルが出る。「対戦」でステージを選び、対戦の設定で相手（CPU / 人）、自分の手番（先手 / 後手）、両方の軍（MILITARY / FANTASY）と部隊を選んで対戦する。決着の画面から、もう一度・対戦の設定へ・タイトルへ進める。部隊は、タイトルの「部隊の編成」で組んで、名前を付けて取っておける（選ばなければ軍ごとの既定の編成）。ルールの仕様と画面の作りは [`docs/`](./docs/)。

タイトルの「ストーリー」では、CPU を相手に話を順に遊べる（会話 → 出撃の準備 → 対戦 → 会話。いまは仮の文で 4 話）。話をクリアすると雇える駒が増え、ストーリー用の部隊（「部隊の編成」の「ストーリー用」。対戦用とは別）を組める（[`docs/story.md`](./docs/story.md)）。

Godot を入れずに遊ぶなら、GitHub Actions の `build` の成果物 `pj-legion-windows`（Windows 用の exe）をダウンロードする。

マウスのクリックだけで遊べる。駒に属する操作は、駒を選ぶとそのそばに出るメニューから選ぶ。

| 操作 | 内容 |
| --- | --- |
| 左クリック（自分の駒） | 駒を選ぶ。届くマスと、そばにメニュー（攻撃・回復・スキル・待機）が出る |
| 左クリック（ほかの駒） | その駒を見る（選んでいる駒と行動の途中はそのまま）。動ける範囲（白）と、相手なら次の番に攻撃が届く範囲（赤）が見える。右クリックで元の行動へ戻る |
| 左クリック（青・黄のマス） | 選んでいる駒を移動する。黄は巡航（2 倍動けるが、その行動では攻撃できない） |
| 左クリック（赤いマスの相手・樽） | 攻撃する（動く前でも、動いたあとでもよい）。メニューの「攻撃」を押すと、相手だけが塗られる |
| 左クリック（緑のマスの味方） | 回復役で回復する。メニューの「回復」からでもよい |
| メニューのスキルの名前 | スキルの対象を選び始める（紫のマスをクリックで使う）。スキルを持つ駒と中身は [`docs/skills/`](./docs/skills/) |
| メニューの「待機」 | 選んでいる駒の行動を終える |
| メニューの「移動を取り消す」 | 動く前のマスへ戻す |
| 右クリック | 1 つ戻す（必殺技の確かめ、駒を見ている、対象を選ぶ途中、移動、選択の順にやめる） |
| Esc | 戻すものがあれば右クリックと同じ。何も無ければシステムメニューを開く |
| 左クリック（駒のいないマス） | そのマスの情報（地形、環境オブジェクトなど）を左下に出す |
| 駒のいないところを左ドラッグ | 視点を動かす（横で回す、縦で見下ろす角度を変える） |
| ホイール | 拡大・縮小 |
| WASD / 矢印 | 視点の移動 |
| 下の帯の「敵の攻撃範囲」 | 敵の全員の次の番の攻撃範囲を、赤い斜線で重ねる・消す（出したまま動かせる） |
| 右下の「ターン終了」 | 相手の番にする（未行動の駒が残っていれば、足元が光り、少し間を置いてもう一度押すと終わる） |
| 右下の必殺技のボタン | ゲージがいっぱいのとき、もう一度押すと使う |
| 進化先のボタン | レベル 3 に届いた駒の進化先を選ぶ（選ぶまで、ほかの操作はできない） |
| 右上の「相手: CPU / 人」 | 相手を CPU にするか、人にするかを切り替える（対戦モードだけ） |
| 右上の「ログ」 | 対戦で起きたことを、ターンごとにさかのぼって読む（開いている間は止まる。行を押すと、その場所と駒を示す。右クリックで閉じる） |
| 右上の「メニュー」 | システムメニューを開く（対戦へ戻る・設定・対戦の設定へ・タイトルへ戻る・ゲームを終える）。設定ではマウスの感度や音量などを変えられ、次に起動したときも残る |
| メニューの「対戦の設定へ」 | 対戦の設定画面を開く。「対戦へ戻る」か右クリックで、いまの対戦へそのまま戻る。「新しい対戦を始める」を押すと、選んだ設定で最初から |

キーボードでも操作できる（画面には出していない）: Space 待機 / F スキル / G 必殺技 / T 敵の攻撃範囲 / Enter ターン終了 / 1・2 進化先 /
Q・E 90 度回転 / R 見下ろす角度（3 段階を順に）/ F1〜F3 新しい盤面（ステージ 1〜3）/ F4 相手の切り替え（F1〜F4 は対戦モードだけ）。

敵の将を倒すか、敵の本陣（旗のあるマス）に自分の駒を乗せたままターン終了を 3 回続けると勝ち。
樽の爆発で両方の将が同時に倒れると引き分け。
ストーリーの話には、決められたターンを守り切れば勝ち、敵を全滅させれば勝ち（将を倒しても終わらない）のものもある（[`docs/win-conditions.md`](./docs/win-conditions.md)）。

ステージごとに環境オブジェクトがある（数値は [`docs/map-objects.md`](./docs/map-objects.md)）。

- ステージ 1: 起爆樽。入れない。攻撃すると爆発して、周り 8 マスの駒すべて（味方も自分も）にダメージを与える。
- ステージ 2: 回復の泉（緑の十字の札）。乗ったまま自分の番を迎えると回復する。
- ステージ 3: ポータル（同じ色の輪の 2 つがつながっている）。行き先を選ぶと、近道になるときは自動で通る。
  出口に駒がいる間は通れない。

## 素材

3D のモデルと音（BGM と効果音）は、ライセンスに問題の無いありものを使っている。
作者の一覧と出どころ・ライセンスは、置いたディレクトリ（`assets/` の下）の `README.md` と `LICENSE*` にある。

## 検査

```bash
tools/check.sh /path/to/godot
```

画面なしでプロジェクトを取り込み、テスト（`tests/`）を実行し、メインシーンで自動の対戦を最後まで進めて、スクリプトのエラーが無いことを確かめる。
CI（`.github/workflows/ci.yml`）も同じスクリプトを回す。
`tools/check.sh --full /path/to/godot` は時間の掛かるものも含めた長い検査で、CI では main に入ったあとに回す（`docs/README.md` の「検査の分け方」）。

作業の決まりごとは [`CLAUDE.md`](./CLAUDE.md)、文書の置き方は [`docs/README.md`](./docs/README.md)。
